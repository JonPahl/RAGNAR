### 🔴 2. Unnecessary Allocations in `LoadQuestionsAsync`

### 🟡 4. LINQ & Loop Overhead in `StreamContextAsync`
**Issue:** 
- `.Select(p => p.Payload)` creates an intermediate enumerable.
- String interpolation inside the loop allocates multiple strings per iteration.
- No capacity pre-allocation for `StringBuilder`.

**Fix:**
```csharp
private static async Task<string> StreamContextAsync(IReadOnlyList<ScoredPoint> searchResult)
{
    // Pre-allocate based on expected payload size to avoid reallocations
    var sb = new StringBuilder(searchResult.Count * 120); 
    sb.AppendLine("[CONTEXT CODE]");
    
    foreach (var scoredPoint in searchResult)
    {
        var payload = scoredPoint.Payload;
        sb.Append("File Name: ").Append(payload.GetValueOrDefault(FILE_NAME)?.StringValue ?? string.Empty)
          .Append(" Type: ").Append(payload.GetValueOrDefault(ELEMENT_TYPE)?.StringValue ?? string.Empty)
          .Append(" Element Name: ").Append(payload.GetValueOrDefault(ELEMENT_NAME)?.StringValue ?? string.Empty)
          .AppendLine();
    }

    sb.AppendLine("[/CONTEXT CODE]");
    return await Task.FromResult(sb.ToString()); // Or just return sb.ToString() if async isn't strictly needed here
}
```

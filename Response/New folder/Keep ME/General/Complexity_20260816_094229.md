### 🛠️ Targeted Refactoring Suggestions

#### 1. `ConfigurationBasedQuestionLoader.LoadFromConfig`
**Current CC: 4** | *Issue*: Nested `if/else` based on category creates branching that's hard to extend.
```csharp
// Before
if (question.IsEnabled) {
    if (question.Category == QuestionCategory.XML) { /* filter logic */ }
    else { /* active logic */ }
} else { /* disabled logic */ }

// After: Strategy Pattern / Dictionary Dispatch
private static readonly Func<Question, Question> CategoryHandlers = new Dictionary<QuestionCategory, Func<Question, Question>>
{
    [QuestionCategory.XML] = q => q.SetFilter(BuildXmlFilter()),
    _ = q => q // default active
};

public List<Question> LoadFromConfig(IEnumerable<QuestionConfiguration> configs)
{
    ArgumentNullException.ThrowIfNull(configs);
    return configs.Select(cfg => factory(cfg.Text, cfg.FileName, cfg.Category))
                  .Where(q => q.IsEnabled)
                  .Select(q => CategoryHandlers.GetValueOrDefault(q.Category, q).SetFilter(null)) // simplified
                  .Concat(configs.Where(cfg => !factory(...).IsEnabled).Select(q => Question.IsDisabled(...)))
                  .ToList();
}
```
✅ **Benefit**: Reduces branching, makes adding new categories O(1), and aligns with Open/Closed Principle.

#### 3. `FileValidator.IsValid`
**Current CC: 4** | *Issue*: Single-line boolean expression with multiple short-circuit operators is hard to debug.
```csharp
public bool IsValid(FileInfo file, in FileLoadOptions filter)
{
    var hasAllowedExtension = filter.AllowedFileExtensions.Any(ext => 
        string.Equals(file.Extension, ext, StringComparison.OrdinalIgnoreCase));
    
    var isNotExcludedByFile = !filter.ExcludedFiles.Contains(file.Name);
    var isNotExcludedByDir = file.DirectoryName != null && 
                             !filter.ExcludedDirectories.Any(dir => 
                                 file.DirectoryName!.Contains(dir, StringComparison.OrdinalIgnoreCase));

    return hasAllowedExtension && isNotExcludedByFile && isNotExcludedByDir;
}
```
✅ **Benefit**: Zero change to CC, but dramatically improves readability, testability, and debugging.

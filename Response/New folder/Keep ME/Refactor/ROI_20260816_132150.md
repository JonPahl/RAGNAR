### 🥈 2. Tightly Coupled Console UI/Streaming in Core Pipeline
- **Impact:** 🔴 High (Testability, Scalability, Deployment)
- **Remediation Effort:** 🟡 Medium-High (Days to Weeks)
- **Code Evidence:**
  - `OllamaResponse.GenerateResponse` uses `AnsiConsole.Live`, `Markup`, and custom `Styles.GreenBlink` for streaming progress.
  - `RagOrchestrator.SaveResponseAsync` calls `writer.MarkupLine($"[red underline]{path}[/]")`.
- **Why it's debt:** Business logic is directly coupled to a terminal UI framework. This breaks headless/server deployments, makes unit/integration testing nearly impossible without mocking console infrastructure, and violates separation of concerns.
- **Remediation:**
  - Extract streaming/progress into an `IProgressReporter` or use standard `IProgress<T>` events.
  - Replace direct `AnsiConsole` calls with a pluggable `ILogger` + optional `IPresentationLayer` interface.
  - Move console styling to a dedicated `PresentationModule` that's conditionally registered in DI only for CLI hosts.

  - Add integration tests that verify payload round-tripping and schema mismatch handling.

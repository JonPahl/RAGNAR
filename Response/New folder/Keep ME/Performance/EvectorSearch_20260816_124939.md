### 🔍 Vector Dimensionality
- The `EmbeddingOption.Dimension` property is only used in `FileParser.SplitMarkdown()` to control text chunking/tokenization limits, **not** for configuring the actual embedding vectors.
- The true vector dimension is determined at runtime by the model specified in `OllamaOptions.EmbeddingModel`. While Qdrant supports dynamic vector dimensions, optimal performance and storage require explicitly setting a fixed vector size during collection creation that matches your embedding model (e.g., `768` for BGE-m3, `1536` for text-embedding-ada-002).


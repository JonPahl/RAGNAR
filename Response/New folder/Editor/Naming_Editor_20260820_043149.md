Here's a production-ready `.editorconfig` tailored for modern C# (.NET 10 / C# 14) that enforces common naming, formatting, and code-style conventions. Place this file at the **root of your solution** so it applies to all projects automatically.

```editorconfig
# ==========================================
# .NET / C# EditorConfig
# Enforces common naming & formatting conventions
# Optimized for .NET 10 / C# 14
# ==========================================

root = true

# ------------------------------------------
# Global Settings (All files)
# ------------------------------------------
[*]
charset = utf-8-bom
end_of_line = lf
insert_final_newline = true
trim_trailing_whitespace = true

# ------------------------------------------
# C# Files Formatting & Code Style
# ------------------------------------------
[*.cs]
# Indentation
indent_size = 4
tab_width = 4

# Braces & Spacing
csharp_new_line_before_open_brace = all
csharp_space_after_cast = false
csharp_space_between_method_call_parameter_parens_and_empty_parameter_list_parentheses = false
csharp_space_between_method_call_name_and_invocation_operator = false
csharp_space_between_method_declaration_parameter_list_parens = false
csharp_space_before_open_square_brackets = false
csharp_space_after_keywords_in_control_flow_statements = true

# Modern C# Code Style (C# 10/11/12+)
csharp_style_namespace_declarations = file_scoped:suggestion
csharp_using_directive_placement = outside_namespaces:silent
csharp_prefer_static_local_function = true:suggestion
csharp_style_throw_expression = true:suggestion
csharp_style_null_propagation = true:suggestion
csharp_style_inlined_variable_declaration = true:suggestion
csharp_style_var_elsewhere = true:silent
csharp_style_var_for_built_in_types = false:silent

# ------------------------------------------
# Naming Conventions (Roslyn Analyzers)
# ------------------------------------------
# Public types & members: PascalCase
dotnet_naming_rule.public_types_members_pascal.severity = suggestion
dotnet_naming_rule.public_types_members_pascal.symbols = public_symbols
dotnet_naming_rule.public_types_members_pascal.style = pascal_case

# Private fields: _camelCase
dotnet_naming_rule.private_fields_underscore_camel.severity = suggestion
dotnet_naming_rule.private_fields_underscore_camel.symbols = private_field_symbols
dotnet_naming_rule.private_fields_underscore_camel.style = underscore_camel_case

# Local variables & parameters: camelCase
dotnet_naming_rule.locals_params_camel.severity = suggestion
dotnet_naming_rule.locals_params_camel.symbols = local_symbols
dotnet_naming_rule.locals_params_camel.style = camel_case

# Interfaces: IPascalCase
dotnet_naming_rule.interfaces_ipascal.severity = suggestion
dotnet_naming_rule.interfaces_ipascal.symbols = interface_symbols
dotnet_naming_rule.interfaces_ipascal.style = ipascal_case

# Symbol Definitions
dotnet_naming_symbols.public_symbols.capitalization = pascal_case
dotnet_naming_symbols.private_field_symbols.capitalization = camel_case
dotnet_naming_symbols.local_symbols.capitalization = camel_case
dotnet_naming_symbols.interface_symbols.capitalization = pascal_case

# Style Definitions
dotnet_naming_style.pascal_case.capitalization = pascal_case
dotnet_naming_style.underscore_camel_case.required_prefix = _
dotnet_naming_style.underscore_camel_case.capitalization = camel_case
dotnet_naming_style.camel_case.capitalization = camel_case
dotnet_naming_style.ipascal_case.required_prefix = I
dotnet_naming_style.ipascal_case.capitalization = pascal_case

# ------------------------------------------
# Project & Config Files
# ------------------------------------------
[{*.csproj,*.props,*.targets}]
indent_size = 2

[*.json]
indent_size = 2

[*.md]
trim_trailing_whitespace = false
```

### 🔑 Key Sections Explained

| Section | Purpose |
|--------|---------|
| **Global `[*]`** | Enforces UTF-8 BOM, LF line endings, trailing whitespace removal, and final newline across all files. |
| **Formatting (`[*.cs]`)** | 4-space indentation, braces on new lines, tight spacing around operators/parens (matches Microsoft's default style). |
| **Modern C# Code Style** | Enables `file_scoped` namespaces, `using` directives outside namespaces, null propagation, throw expressions, and `var` inference where appropriate. |
| **Naming Conventions** | Uses Roslyn's built-in naming analyzer to enforce:<br>• Public types/members → `PascalCase`<br>• Private fields → `_camelCase`<br>• Locals/params → `camelCase`<br>• Interfaces → `IPascalCase` |
| **Project/Config Files** | Uses 2-space indentation for XML/JSON files (standard for MSBuild & config). |

### ⚙️ How to Use & Customize

1. **Severity Levels**: Change `.severity = suggestion` to:
   - `warning` → Shows yellow squiggle + builds with warnings
   - `error` → Fails compilation if violated
2. **IDE Support**: 
   - **Visual Studio 2022+**: Automatically picks up `.editorconfig`. No extra setup needed.
   - **Rider/VSCode**: Ensure "Format on Save" and "Roslyn Analyzers" are enabled in settings.
3. **Override Per-Project**: Copy the file into a specific project folder and adjust rules locally if needed (EditorConfig cascades downward).
4. **C# 14 Compatibility**: All rules use standard Roslyn analyzer keys that fully support primary constructors, `extension` members, and pattern matching introduced in .NET 10/C# 14.

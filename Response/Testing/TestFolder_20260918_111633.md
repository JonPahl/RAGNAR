# Reorganise Test Files – PowerShell Script

## The script

Save as `reorganise-tests.ps1` next to the solution (or run from the repo root) and execute with:

```powershell

```

```powershell
#!/usr/bin/env pwsh
# ─────────────────────────────────────────────────────────────────────────────
# reorganise-tests.ps1
# Moves UnitTest files into folders that mirror the source-code layout.
# Idempotent – safe to run more than once.
# ─────────────────────────────────────────────────────────────────────────────
[[CmdletBinding()]]
param(
    [[string]]$TestProjectDir = (Join-Path $PSScriptRoot "Ragnar.UnitTests")
)

$ErrorActionPreference = "Stop"

if (-not (Test-Path $TestProjectDir)) {
    throw "Test project directory not found: $TestProjectDir"
}

Write-Host "=== Reorganising test files ===" -ForegroundColor Cyan
Write-Host "Project: $TestProjectDir`n" -ForegroundColor Cyan

# ── 1. Define moves:  SourcePath (relative) → DestPath (relative) ──────────
$Moves = [[ordered]]@{
    # ResponseWriter lives in Ragnar\Output → tests should too
    "ResponseWriterTests.cs"        = "Output\ResponseWriterTests.cs"

    # StopwatchExtensions lives in Ragnar\Extensions → tests should too
    "StopwatchExtensionsTests.cs"   = "Extensions\StopwatchExtensionsTests.cs"
}

# ── 2. Execute moves ───────────────────────────────────────────────────────
$moved = 0
foreach ($src in $Moves.Keys) {
    $srcFull  = Join-Path $TestProjectDir $src
    $destRel  = $Moves[[$src]]
    $destDir  = Split-Path $destRel -Parent
    $destFull = Join-Path $TestProjectDir $destRel

    if (-not (Test-Path $srcFull)) {
        Write-Warning "  SKIP  (not found): $src"
        continue
    }

    # Already in the right place?
    if ((Split-Path $srcFull -Parent) -eq (Split-Path $destFull -Parent)) {
        Write-Host "  OK    (already placed): $src" -ForegroundColor DarkGray
        continue
    }

    # Create target directory
    $targetDir = Split-Path $destFull -Parent
    if (-not (Test-Path $targetDir)) {
        New-Item -Path $targetDir -ItemType Directory -Force | Out-Null
        Write-Verbose "  Created dir: $targetDir"
    }

    Move-Item -Path $srcFull -Destination $destFull -Force
    $moved++
    Write-Host "  MOVED: $src  →  $destRel" -ForegroundColor Green
}

# ── 3. Verify final layout ──────────────────────────────────────────────────
Write-Host "`n=== Resulting test tree ===" -ForegroundColor Cyan

$testFiles = Get-ChildItem -Path $TestProjectDir -Filter "*.cs" -Recurse |
    Where-Object { $_.Name -notlike "*AssemblyInfo*" -and $_.Name -notlike "*GlobalUsings*" } |
    Sort-Object { $_.FullName.Substring($TestProjectDir.Length) }

foreach ($f in $testFiles) {
    $rel = $f.FullName.Substring($TestProjectDir.Length).TrimStart("\")
    $indent = "  " * ($([[IO.Path]]::GetDirectoryName($rel) -split "\\").Length)
    Write-Host "$indent$($f.Name)"
}

Write-Host "`nDone – $moved file(s) moved." -ForegroundColor Cyan
```

## Why this layout

| Principle | How it's applied |
|---|---|
| **Mirror the source tree** | `Ragnar\Output\` → `Tests\Output\`, `Ragnar\Extensions\` → `Tests\Extensions\`, etc. |
| **One test class per file** | Each file is named `*Tests.cs` after its SUT. |
| **SDK-style auto-include** | No `.csproj` edits needed – the glob `**/*.cs` picks up files wherever they live. |
| **Idempotent** | Re-running the script skips files already in the correct folder. |

> **Tip:** If you later add tests for `ParsingStage`, `OllamaEmbeddingService`, or `ConsoleTableRenderer`, drop them into the matching sub-folder (`Stages\`, `Embedding\`, `Core\Rendering\`) and the tree stays consistent.

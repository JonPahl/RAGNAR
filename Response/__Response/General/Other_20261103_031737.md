## The `extension()` Block Syntax

Several files use C#'s **extension block** feature (C# 14 preview):

```csharp
extension(Assembly asm) { ... }
extension(IServiceCollection services) { ... }
extension(IReadOnlyList<Question> questions) { ... }
```

If this project targets C# 13 or earlier in CI/CD, these won't compile. Make sure your `Directory.Build.props` / `.csproj` has `<LangVersion>preview</LangVersion>` (or the specific C# 14 version) and that your build image matches.

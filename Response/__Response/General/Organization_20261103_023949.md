## Step-by-Step Guide

### Step 1 – Create the folder skeleton

Open a PowerShell terminal at the repository root and run the script below. It creates every directory before any file is moved, so you never get "directory not found" errors.

### Step 2 – Move (rename) files into their new folders

The script uses `Move-Item` so you can undo with `git checkout -- .` if needed.

### Step 3 – Rewrite `namespace` declarations

Each `.cs` file gets a new `namespace` line that mirrors its folder path under `Ragnar`.

### Step 4 – Update cross-namespace `using` directives

Any file that now references a type in a *different* top-level namespace gets a new `using` statement.

### Step 5 – Verify & build

Run `dotnet build` and fix any residual `CS0246` errors.

## PowerShell Script

> Save as `reorganize.ps1` and run from the repo root.
> **Back up / commit your working tree first.**

```powershell
#Requires -Version 7.0
# reorganize.ps1 – Ragnar namespace/folder reorganization
# Run:  pwsh ./reorganize.ps1

$ErrorActionPreference = 'Stop'
$root = (Get-Location).Path   # expects: ...\Ragnar\Src\Ragnar
Write-Host "Root: $root" -ForegroundColor Cyan

# ──────────────────────────────────────────────────────────────
# 1. CREATE FOLDERS
# ──────────────────────────────────────────────────────────────
$folders = @(
    'Configuration/Validation'
    'Pipeline/Abstractions'
    'Pipeline/Base'
    'Pipeline/Runner'
    'Pipeline/Middleware'
    'Pipeline/Stages'
    'RAG/Models'
    'Ollama/Abstractions'
    'Ollama/Client'
    'Ollama/Builder'
    'Ollama/Extensions'
    'Embedding/Abstractions'
    'Embedding/Generators'
    'Embedding/Setup'
    'VectorStore/Abstractions'
    'VectorStore/Qdrant'
    'VectorStore/Writers'
    'Discovery/Abstractions'
    'Discovery/Services'
    'Discovery/Parsing/Models'
    'Questions/Filtering'
    'Questions/Models'
    'Questions/Extensions'
    'Output/Abstractions'
    'Output/Rendering'
    'Output/Extensions'
    'Extensions'
    'DI'
)

foreach ($f in $folders) {
    $p = Join-Path $root $f
    if (-not (Test-Path $p)) {
        New-Item -Path $p -ItemType Directory -Force | Out-Null
        Write-Host "  created  $f" -ForegroundColor Green
    }
}

# ──────────────────────────────────────────────────────────────
# 2. MOVE FILES  (old-name  →  new-folder/old-name)
# ──────────────────────────────────────────────────────────────
#  Format:  <source-relative-to-root>  =>  <destination-relative-to-root>
$moves = @(
    # --- Configuration ---
    'FileLoadOptions.cs'              => 'Configuration/FileLoadOptions.cs'
    'EmbeddingOptions.cs'             => 'Configuration/EmbeddingOptions.cs'
    'GenerationOptions.cs'            => 'Configuration/GenerationOptions.cs'
    'FileLoadOptionsValidator.cs'     => 'Configuration/Validation/FileLoadOptionsValidator.cs'
    'RagnarConfigValidator.cs'        => 'Configuration/Validation/RagnarConfigValidator.cs'

    # --- Pipeline framework ---
    'PipelineRunner.cs'               => 'Pipeline/Runner/PipelineRunner.cs'
    'StageEntry.cs'                   => 'Pipeline/Abstractions/StageEntry.cs'
    'PipelineMiddleware.cs'           => 'Pipeline/Middleware/StageExecutionContext.cs'
    'StageTimingMiddleware.cs'        => 'Pipeline/Middleware/StageTimingMiddleware.cs'
    'StageMetric.cs'                  => 'Pipeline/Middleware/StageMetric.cs'
    'BrandingStage.cs'                => 'Pipeline/Stages/BrandingStage.cs'

    # --- RAG ---
    'RagOrchestrator.cs'              => 'RAG/RagOrchestrator.cs'
    'QuestionPipelineContext.cs'      => 'RAG/Models/QuestionPipelineContext.cs'

    # --- Ollama ---
    'IOllamaClientFactory.cs'         => 'Ollama/Abstractions/IOllamaClientFactory.cs'
    'OllamaChatClientBuilder.cs'      => 'Ollama/Builder/OllamaChatClientBuilder.cs'
    'GeneratorExtensions.cs'          => 'Ollama/Extensions/GeneratorExtensions.cs'

    # --- Embedding ---
    'EmbeddingSetupExtension.cs'      => 'Embedding/Setup/EmbeddingSetupExtension.cs'

    # --- VectorStore / Qdrant ---
    'QdrantFilterBuilder.cs'          => 'VectorStore/Qdrant/QdrantFilterBuilder.cs'
    'CollectionInfo.cs'               => 'VectorStore/Qdrant/CollectionInfo.cs'

    # --- Discovery / Parsing ---
    'IFileDiscoveryService.cs'        => 'Discovery/Abstractions/IFileDiscoveryService.cs'
    'IFileEligibilityValidator.cs'    => 'Discovery/Abstractions/IFileEligibilityValidator.cs'
    'IFileParser.cs'                  => 'Discovery/Abstractions/IFileParser.cs'
    'FileDiscoveryService.cs'         => 'Discovery/Services/FileDiscoveryService.cs'
    'CodeParserFactory.cs'            => 'Discovery/Parsing/CodeParserFactory.cs'

    # --- Questions ---
    'QuestionFilterSelector.cs'       => 'Questions/Filtering/QuestionFilterSelector.cs'
    'XmlCommentFilterStrategy.cs'     => 'Questions/Filtering/XmlCommentFilterStrategy.cs'
    'QuestionsExtensions.cs'          => 'Questions/Extensions/QuestionsExtensions.cs'
    'EnumConverter.cs'                => 'Questions/Extensions/EnumConverter.cs'

    # --- Output ---
    'OutputPathHelper.cs'             => 'Output/Extensions/OutputPathHelper.cs'
    'NumberedRowDecorator.cs'         => 'Output/Rendering/NumberedRowDecorator.cs'

    # --- Misc Extensions ---
    'AssemblyExtensions.cs'           => 'Extensions/AssemblyExtensions.cs'
    'FileSystemEntryExtensions.cs'    => 'Extensions/FileSystemEntryExtensions.cs'
)

foreach ($pair in $moves) {
    $src = Join-Path $root $pair.Key
    $dst = Join-Path $root $pair.Value
    if (Test-Path $src) {
        Move-Item -LiteralPath $src -Destination $dst
        Write-Host "  moved    $($pair.Key)  →  $($pair.Value)" -ForegroundColor Yellow
    } else {
        Write-Host "  SKIP     $($pair.Key) (not found)" -ForegroundColor DarkGray
    }
}

# ──────────────────────────────────────────────────────────────
# 3. REWRITE NAMESPACE DECLARATIONS
# ──────────────────────────────────────────────────────────────
#  Helper: derive the C# namespace from a folder path
#  e.g.  Configuration/Validation  →  Ragnar.Configuration.Validation
function Get-NS([[string]]$relPath) {
    $ns = 'Ragnar'
    $parts = ($relPath -split '/') | Where-Object { $_ -ne '' -and $_ -ne 'Properties' }
    foreach ($p in $parts) { $ns += ".$p" }
    return $ns
}

$allCs = Get-ChildItem -Path $root -Filter '*.cs' -Recurse |
         Where-Object { $_.FullName -notmatch '\\(obj|bin|\.vs)\\' }

foreach ($file in $allCs) {
    $rel = $file.FullName.Substring($root.Length + 1)   # relative path
    $newNS = Get-NS $rel
    $content = Get-Content $file.FullName -Raw

    # Replace the first top-level namespace declaration
    $pattern = '(?m)^\s*namespace\s+[[\w.]]+\s*\{?'
    if ($content -match $pattern) {
        $content = [[regex]]::Replace($content, $pattern, "namespace $newNS", 1)
        Set-Content -Path $file.FullName -Value $content -NoNewline
        Write-Host "  ns       $rel  →  $newNS" -ForegroundColor Cyan
    }
}

# ──────────────────────────────────────────────────────────────
# 4. ADD MISSING USING DIRECTIVES
# ──────────────────────────────────────────────────────────────
#  This is a *best-effort* pass.  The real fix is to let the
#  compiler tell you (dotnet build) and add usings manually.
#  Below we inject a handful of common cross-namespace usings.
$usingMap = @{
    'RAG\RagOrchestrator.cs'                    = @(
        'using Ragnar.Configuration;'
        'using Ragnar.Ollama.Abstractions;'
        'using Ragnar.Ollama.Client;'
        'using Ragnar.Output.Abstractions;'
        'using Ragnar.Questions.Models;'
    )
    'Pipeline\Runner\PipelineRunner.cs'         = @(
        'using Polly;'
        'using Polly.Retry;'
    )
    'Questions\Filtering\XmlCommentFilterStrategy.cs' = @(
        'using Ragnar.VectorStore.Qdrant;'
    )
    'Questions\Filtering\QuestionFilterSelector.cs'   = @(
        'using Ragnar.VectorStore.Qdrant;'
    )
    'Discovery\Services\FileDiscoveryService.cs'      = @(
        'using Ragnar.Configuration;'
    )
    'Discovery\Parsing\CodeParserFactory.cs'          = @(
        'using Ragnar.Configuration;'
    )
    'RAG\Models\QuestionPipelineContext.cs'           = @(
        'using Ragnar.Questions.Models;'
    )
}

foreach ($key in $usingMap.Keys) {
    $full = Join-Path $root $key
    if (-not (Test-Path $full)) { continue }
    $content = Get-Content $full -Raw
    $changed = $false
    foreach ($u in $usingMap[[$key]]) {
        if ($content -notmatch [[regex]]::Escape($u)) {
            # insert after the first using block or before the namespace
            $insertIdx = $content.IndexOf('namespace ')
            $content = $content.Insert($insertIdx, $u + "`r`n")
            $changed = $true
        }
    }
    if ($changed) {
        Set-Content -Path $full -Value $content -NoNewline
        Write-Host "  usings   $key" -ForegroundColor Magenta
    }
}

# ──────────────────────────────────────────────────────────────
# 5. FINAL CHECK
# ──────────────────────────────────────────────────────────────
Write-Host "`n=== Reorganization complete ===" -ForegroundColor Green
Write-Host "Run  dotnet build  to verify, then fix any remaining CS0246 errors."
Write-Host "Tip:  enable `#nullable` and `ImplicitUsings` in the .csproj if not already set."
```

## Key Design Rationale

1. **`Pipeline/` is framework-generic.** `PipelineRunner<T>`, `StageEntry<T>`, and `StageTimingMiddleware` know nothing about RAG, Ollama, or Qdrant. Keeping them in their own namespace lets you reuse the pipeline engine in a future non-RAG project.

2. **`RAG/` sits *above* `Ollama/` and `VectorStore/`.** The orchestrator *composes* the Ollama client and the vector store; it doesn't inherit from either. This keeps the dependency arrow pointing downward (RAG → Ollama, RAG → VectorStore) and avoids circular references.

3. **`Discovery/` vs `Questions/`.** File *discovery & parsing* (finding `.cs` files, chunking with Roslyn) is a concern orthogonal to *question management* (categories, filters, CSV converters). Separating them means you can swap the discovery source (e.g., pull from GitHub instead of local disk) without touching question logic.

4. **`Validation/` nested under `Configuration/`.** FluentValidation classes are 1:1 with their option record. Co-locating them means `EmbeddingOptions` and `EmbeddingOptionsValidator` live in the same folder, which is the convention most .NET teams follow.

5. **`Output/` bundles all rendering concerns.** Console tables, response writing, branding headers, and path helpers all produce *display output*. Grouping them lets you swap the console renderer for a web/CLI renderer later without touching domain logic.

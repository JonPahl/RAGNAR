# Reworking & Improving the Builders in Ragnar

Your codebase has two primary builders — **`QdrantFilterBuilder`** and **`OllamaChatClientBuilder`** — plus the builder-like `PipelineRunner<TContext>`. Below is a structured plan covering concrete refactorings, new capabilities, and cross-cutting improvements.

---

## 1. `QdrantFilterBuilder` — Major Overhaul

### Current Problems

| Issue | Why it matters |
|-------|---------------|
| No `AddShould` public method | The `_should` list exists but can never be populated. |
| `CloneCondition` is dead code | Misleads future readers. |
| `Build()` throws on empty | An "empty filter" is a valid Qdrant concept (match-all). Forcing a throw breaks composable pipelines. |
| `AddRange` requires *both* bounds OR throws | You can't express "gte only" without passing `null` awkwardly. |
| No `AddCondition(Condition)` escape hatch | You can't inject a pre-built `Condition` (e.g. geo, full-text, nested). |
| No validation of field names | Typos like `"CommentLenght"` compile silently. |
| No `Clone()` / `With()` for derived filters | Every strategy rebuilds from scratch. |
| `AddExceptKeywords` is a one-off | No `AddMatchAny`, `AddMatchAll`, `AddIsNull`, etc. |

### Refactored Builder

```csharp
/// <summary>Fluent, validated builder for Qdrant <see cref="Filter"/> expressions.</summary>
/// <remarks>
/// Immutable by design: every mutating method returns a *new* instance
/// (or the same instance in a "draft" mode for performance-critical loops).
/// </remarks>
/// <example>
/// <![[CDATA[[
/// var filter = QdrantFilter.Create()
///     .Must.Match("Category", "XML")
///     .Must.Range("CommentLength", gte: 50)
///     .MustNot.Match("Category", "Test")
///     .Should.Match("Language", "CSharp")
///     .Build();
/// ]]]]>
/// </example>
public sealed class QdrantFilterBuilder
{
    // ─── Internal mutable state (builder is NOT thread-safe by contract) ───
    private readonly List<Condition> _must    = [[]];
    private readonly List<Condition> _mustNot = [[]];
    private readonly List<Condition> _should  = [[]];

    // ─── Factory ───
    /// <summary>Creates a new empty builder.</summary>
    public static QdrantFilterBuilder Create() => new();

    // ─── Must (positive) conditions ───

    /// <summary>Adds a keyword equality condition to the <b>must</b> set.</summary>
    public QdrantFilterBuilder MustMatch(string field, string value)
    {
        ValidateField(field);
        _must.Add(Conditions.MatchKeyword(field, value));
        return this;
    }

    /// <summary>Adds a keyword inequality condition to the <b>must-not</b> set.</summary>
    public QdrantFilterBuilder MustNotMatch(string field, string value)
    {
        ValidateField(field);
        _mustNot.Add(Conditions.MatchKeyword(field, value));
        return this;
    }

    /// <summary>Adds a numeric range to the <b>must</b> set. At least one bound is required.</summary>
    public QdrantFilterBuilder MustRange(string field, double? gte = null, double? lte = null)
    {
        ValidateField(field);
        RequireAtLeastOneBound(gte, lte, nameof(gte), nameof(lte));
        _must.Add(Condition.Field(new FieldCondition { Key = field, Range = new Range { Gte = gte, Lte = lte } }));
        return this;
    }

    /// <summary>Adds a numeric range to the <b>must-not</b> set.</summary>
    public QdrantFilterBuilder MustNotRange(string field, double? gte = null, double? lte = null)
    {
        ValidateField(field);
        RequireAtLeastOneBound(gte, lte, nameof(gte), nameof(lte));
        _mustNot.Add(Condition.Field(new FieldCondition { Key = field, Range = new Range { Gte = gte, Lte = lte } }));
        return this;
    }

    /// <summary>Adds an except-keywords condition to the <b>must</b> set.</summary>
    public QdrantFilterBuilder MustExcept(string field, params string[[]] keywords)
    {
        ValidateField(field);
        Guard.Against.Empty(keywords);
        _must.Add(Condition.Field(new FieldCondition
        {
            Key   = field,
            Match = new Match { ExceptKeywords = new RepeatedStrings { Strings = { keywords } } }
        }));
        return this;
    }

    /// <summary>Adds a match-any (OR within the must set) condition.</summary>
    public QdrantFilterBuilder MustMatchAny(string field, params string[[]] values)
    {
        ValidateField(field);
        Guard.Against.Empty(values);
        _must.Add(Condition.Field(new FieldCondition
        {
            Key   = field,
            Match = new Match { AnyKeywords = new RepeatedStrings { Strings = { values } } }
        }));
        return this;
    }

    /// <summary>Adds a null-check condition (field must be absent) to the <b>must</b> set.</summary>
    public QdrantFilterBuilder MustIsNull(string field)
    {
        ValidateField(field);
        _must.Add(new Condition { IsNull = new IsNullCondition { IsNull = true } });
        return this;
    }

    // ─── Should (optional) conditions ───

    /// <summary>Adds a keyword condition to the <b>should</b> set.</summary>
    public QdrantFilterBuilder ShouldMatch(string field, string value)
    {
        ValidateField(field);
        _should.Add(Conditions.MatchKeyword(field, value));
        return this;
    }

    /// <summary>Adds a range condition to the <b>should</b> set.</summary>
    public QdrantFilterBuilder ShouldRange(string field, double? gte = null, double? lte = null)
    {
        ValidateField(field);
        RequireAtLeastOneBound(gte, lte, nameof(gte), nameof(lte));
        _should.Add(Condition.Field(new FieldCondition { Key = field, Range = new Range { Gte = gte, Lte = lte } }));
        return this;
    }

    // ─── Escape hatch ───

    /// <summary>Injects a pre-built <see cref="Condition"/> into the <b>must</b> set.</summary>
    public QdrantFilterBuilder AddMustCondition(Condition c)
    {
        Guard.Against.Null(c);
        _must.Add(c);
        return this;
    }

    /// <summary>Injects a pre-built <see cref="Condition"/> into the <b>must-not</b> set.</summary>
    public QdrantFilterBuilder AddMustNotCondition(Condition c)
    {
        Guard.Against.Null(c);
        _mustNot.Add(c);
        return this;
    }

    // ─── Derived / Clone ───

    /// <summary>Returns a deep copy of this builder (useful for branching strategies).</summary>
    public QdrantFilterBuilder Clone() => new()
    {
        _must    = [[.. _must.Select(Cloner<Condition>.DeepCopy)]],
        _mustNot = [[.. _mustNot.Select(Cloner<Condition>.DeepCopy)]],
        _should  = [[.. _should.Select(Cloner<Condition>.DeepCopy)]],
    };

    // ─── Introspection ───

    public bool IsEmpty => _must.Count == 0 && _mustNot.Count == 0 && _should.Count == 0;

    public int MustCount    => _must.Count;
    public int MustNotCount => _mustNot.Count;
    public int ShouldCount  => _should.Count;

    /// <summary>Removes all conditions.</summary>
    public QdrantFilterBuilder Clear()
    {
        _must.Clear(); _mustNot.Clear(); _should.Clear();
        return this;
    }

    // ─── Build ───

    /// <summary>
    /// Materialises the filter. An empty builder produces a match-all <see cref="Filter"/>
    /// (i.e. all three lists are empty), which Qdrant treats as "no filtering".
    /// </summary>
    public Filter Build()
    {
        return new Filter
        {
            Must    = [[.. _must]],
            MustNot = [[.. _mustNot]],
            Should  = [[.. _should]],
        };
    }

    // ─── Validation helpers ───

    private static void ValidateField(string field)
    {
        Guard.Against.NullOrEmpty(field, nameof(field));
        if (field.Length > 256)
            throw new ArgumentException("Field name exceeds 256 characters.", nameof(field));
    }

    private static void RequireAtLeastOneBound(double? a, double? b, string aName, string bName)
    {
        if (a is null && b is null)
            throw new ArgumentException($"At least one of {aName} or {bName} must be provided.");
    }
}
```

### What changed and why

| Change | Rationale |
|--------|-----------|
| `Must*` / `MustNot*` / `Should*` naming prefix | Removes ambiguity; the old `AddRange` / `AddExclusion` didn't tell you *which* bucket the condition landed in. |
| `Should*` methods now exist | The `_should` list was unreachable before. |
| `AddMustCondition` / `AddMustNotCondition` | Escape hatch for geo, full-text, nested payload filters that don't fit the typed helpers. |
| `Clone()` | `XmlCommentFilterStrategy` and future strategies can start from a base filter and branch, instead of re-typing every rule. |
| `Build()` no longer throws on empty | Qdrant accepts an empty `Filter` as "match all". This unblocks `QuestionFilterSelector` for categories that have no strategy. |
| Removed dead `CloneCondition` | Eliminates confusion. |
| `MustMatchAny`, `MustIsNull` | Cuts down the number of ad-hoc `Condition` constructions scattered across strategies. |
| `ValidateField` on every call | Catches typos at *build* time, not at Qdrant query time (which gives a cryptic HTTP 400). |

### Update the existing call-site

```csharp
// XmlCommentFilterStrategy.cs — before
var filter = new QdrantFilterBuilder()
    .AddRange("CommentLength", sizeThreshold)
    .AddExceptKeywords("Category", "Test", "Tests", "Testing")
    .Build();

// after
var filter = QdrantFilterBuilder.Create()
    .MustRange("CommentLength", gte: sizeThreshold)
    .MustExcept("Category", "Test", "Tests", "Testing")
    .Build();
```

## 2. `OllamaChatClientBuilder` — Add Real Fluency

### Current Problems

* Only two thin methods; no timeout, no retry, no connection-pool config.
* No `Build()` — the "configured" object is opaque.
* No way to layer options (e.g. start from a base config, override one field).
* No validation that the endpoint is reachable before the first real call.

### Refactored Builder

```csharp
/// <summary>
/// Fluent builder that produces a fully-configured <see cref="OllamaApiClient"/>
/// with retry, timeout, and health-check baked in.
/// </summary>
/// <example>
/// <![[CDATA[[
/// var client = OllamaClientBuilder.For(OllamaServiceType.Ollama)
///     .WithTimeout(TimeSpan.FromSeconds(120))
///     .WithRetry(maxAttempts: 3, backoff: TimeSpan.FromSeconds(2))
///     .WithModel("llama3.1:8b")
///     .WithHealthCheck()
///     .Build();
/// ]]]]>
/// </example>
public sealed class OllamaClientBuilder
{
    private readonly OllamaClientOptions _options;

    private OllamaClientBuilder(OllamaClientOptions options) => _options = options;

    // ─── Factory ───

    /// <summary>Starts a builder for the given service type.</summary>
    public static OllamaClientBuilder For(OllamaServiceType type)
        => new(new OllamaClientOptions { ServiceType = type });

    /// <summary>Starts from an existing options instance (clone-and-override).</summary>
    public static OllamaClientBuilder From(OllamaClientOptions base)
        => new(base.Clone());   // OllamaClientOptions should implement ICloneable or a CopyTo

    // ─── Fluent configuration ───

    public OllamaClientBuilder WithModel(string model)
    {
        Guard.Against.NullOrEmpty(model);
        _options.Model = model;
        return this;
    }

    public OllamaClientBuilder WithTimeout(TimeSpan timeout)
    {
        if (timeout < TimeSpan.FromSeconds(1))
            throw new ArgumentOutOfRangeException(nameof(timeout), "Minimum timeout is 1 second.");
        _options.Timeout = timeout;
        return this;
    }

    public OllamaClientBuilder WithRetry(int maxAttempts = 3, TimeSpan? backoff = null)
    {
        if (maxAttempts < 1 || maxAttempts > 10)
            throw new ArgumentOutOfRangeException(nameof(maxAttempts));
        _options.MaxRetries = maxAttempts;
        _options.RetryBackoff = backoff ?? TimeSpan.FromSeconds(1);
        return this;
    }

    public OllamaClientBuilder WithHealthCheck()
    {
        _options.HealthCheckEnabled = true;
        return this;
    }

    public OllamaClientBuilder WithEndpoint(Uri uri)
    {
        Guard.Against.Null(uri);
        _options.Endpoint = uri;
        return this;
    }

    public OllamaClientBuilder WithHttpHandler(System.Net.Http.HttpMessageHandler handler)
    {
        Guard.Against.Null(handler);
        _options.HttpHandler = handler;
        return this;
    }

    // ─── Build ───

    /// <summary>Validates options and materialises the client.</summary>
    /// <exception cref="InvalidOperationException">Required options are missing.</exception>
    public OllamaApiClient Build()
    {
        // Required-field validation (mirrors what OllamaOptionsValidator does,
        // but catches *builder* misuse at construction time)
        if (_options.Endpoint is null)
            throw new InvalidOperationException($"{nameof(WithEndpoint)} must be called before Build().");
        if (string.IsNullOrEmpty(_options.Model) && _options.ServiceType == OllamaServiceType.Ollama)
            throw new InvalidOperationException($"{nameof(WithModel)} is required for chat clients.");

        return OllamaApiClientFactory.Create(_options);
    }

    /// <summary>Async variant that also performs a `/api/tags` health check before returning.</summary>
    public async Task<OllamaApiClient> BuildAsync(CancellationToken ct = default)
    {
        var client = Build();
        if (_options.HealthCheckEnabled)
            await client.PingAsync(ct).ConfigureAwait(false);
        return client;
    }
}
```

### Supporting changes

1. **Extend `OllamaClientOptions`** with the new properties (`MaxRetries`, `RetryBackoff`, `HealthCheckEnabled`, `HttpHandler`) and a `Clone()` method.
2. **Add `OllamaApiClientFactory`** (internal static) that wires the `HttpClient`, Polly policy, and model string into a concrete `OllamaApiClient` — this keeps the builder free of infrastructure details.
3. **Register in DI** so the old `IOllamaClientFactory` can delegate to the builder:

```csharp
// ServiceCollectionExtensions (new file)
public static IServiceCollection AddRagnarOllama(this IServiceCollection svc,
    IOptions<RagnarConfig> cfg)
{
    svc.AddSingleton<IOllamaClientFactory, OllamaClientFactory>();
    return svc;
}

internal sealed class OllamaClientFactory(IOptions<RagnarConfig> cfg,
    IHttpClientFactory http) : IOllamaClientFactory
{
    public IOllamaApiClient ResolveClient(OllamaServiceType type)
    {
        var opts = cfg.Value.OllamaOptions;
        return OllamaClientBuilder.For(type)
            .WithEndpoint(opts.Endpoint)
            .WithModel(opts.Model)
            .WithTimeout(opts.Timeout)
            .WithRetry(opts.MaxRetries, opts.RetryBackoff)
            .Build();
    }
}
```

## 3. `PipelineRunner<TContext>` — Tighten the Builder Surface

The runner already has good structure. Two concrete improvements:

### 3a. Add a `UseRetry` convenience (currently only `UseTiming` exists)

```csharp
/// <summary>Wraps every stage with a Polly retry policy.</summary>
/// <example><![[CDATA[[runner.UseRetry(3, TimeSpan.FromSeconds(2));]]]]></example>
public PipelineRunner<TContext> UseRetry(int maxAttempts = 3, TimeSpan? backoff = null)
{
    var policy = Policy
        .Handle<Exception>(ex => ex is not OperationCanceledException)
        .WaitAndRetryAsync(maxAttempts, i => backoff ?? TimeSpan.FromSeconds(Math.Pow(2, i)));
    // Attach to all *future* stages
    _defaultPolicy = policy;
    return this;
}
```

Then in `AddStage`, if the caller passes `null` for `policy`, fall back to `_defaultPolicy`.

### 3b. Add `WithStage<TStage>` for type-safe registration

```csharp
/// <summary>Registers a stage with a compile-time type guarantee.</summary>
/// <typeparam name="TStage">Must implement <see cref="IPipelineStage{TContext}"/>.</typeparam>
/// <example><![[CDATA[[runner.WithStage<QuestionLoadStage>(svcProvider);]]]]></example>
public PipelineRunner<TContext> WithStage<TStage>(IServiceProvider sp)
    where TStage : class, IPipelineStage<TContext>
{
    var stage = sp.GetRequiredService<TStage>();
    return (PipelineRunner<TContext>)AddStage(stage);
}
```

## 4. Cross-Cutting Improvements

### 4a. Introduce a `BuilderBase<T>` abstract class

Both builders share: guard-against-null on every parameter, a `Build()` contract, and a `Validate()` hook. Extract that:

```csharp
public abstract class BuilderBase<TBuilder, TOutput> where TBuilder : BuilderBase<TBuilder, TOutput>
{
    protected abstract void ValidateBeforeBuild();

    protected TBuilder Self => (TBuilder)(object)this;

    public TOutput Build()
    {
        ValidateBeforeBuild();
        return DoBuild();
    }

    protected abstract TOutput DoBuild();
}
```

### 4b. Add a `FilterSpec` record for serialisation / testing

```csharp
/// <summary>Serializable snapshot of a filter for unit tests and telemetry.</summary>
public sealed record FilterSpec(
    IReadOnlyList<Condition> Must,
    IReadOnlyList<Condition> MustNot,
    IReadOnlyList<Condition> Should)
{
    public static FilterSpec From(Filter f) => new(f.Must, f.MustNot, f.Should);
}
```

Now tests can assert on the *shape* of a filter without touching Qdrant:

```csharp
[[Fact]]
public void XmlCommentFilter_ExcludesTests()
{
    var f = new XmlCommentFilterStrategy(logger).CreateFilter(50);
    var spec = FilterSpec.From(f);

    Assert.Contains(spec.Must, c => c.Field?.Key == "CommentLength");
    Assert.Contains(spec.Must, c => c.Field?.Key == "Category" && c.Field.Match.ExceptKeywords is not null);
}
```

### 4c. Validation: move from FluentValidation-only to *builder-time*

Right now `RagnarConfigValidator` runs at startup. If someone constructs a `QdrantFilterBuilder` with a bad field name, the error surfaces 200 ms later at query time. The `ValidateField` calls in the refactored builder above close that gap.

### 4d. Add an `IQueryBuilder` abstraction (optional, for the future)

If you ever move beyond Qdrant (e.g. to Weaviate or pgvector), the builder pattern isolates the *intent* ("must match Category = XML") from the *dialect*:

```csharp
public interface IQueryBuilder
{
    IQueryBuilder MustMatch(string field, string value);
    IQueryBuilder MustNotMatch(string field, string value);
    IQueryBuilder MustRange(string field, double? gte = null, double? lte = null);
    object Build();          // returns Qdrant Filter / Weaviate Where / pgvector predicate
}
```

## 5. Testing Checklist for the Refactored Builders

| Test | Builder |
|------|---------|
| Empty builder → `Build()` returns filter with 0 conditions | `QdrantFilterBuilder` |
| `MustRange` with both bounds null → `ArgumentException` | `QdrantFilterBuilder` |
| `MustMatch` with null field → `ArgumentNullException` | `QdrantFilterBuilder` |
| `Clone()` produces independent copies | `QdrantFilterBuilder` |
| `WithModel("")` → `ArgumentException` | `OllamaClientBuilder` |
| `Build()` without `WithEndpoint` → `InvalidOperationException` | `OllamaClientBuilder` |
| `BuildAsync` with health-check off → no HTTP call | `OllamaClientBuilder` |
| Runner: duplicate stage name → `ArgumentException` | `PipelineRunner` |
| Runner: `Reorder` past end → clamped, no throw | `PipelineRunner` |

Use **NSubstitute** for `IOllamaApiClient`, `IHttpClientFactory`, and a fake `IServiceProvider` for the runner tests.

## 6. Migration Order (low-risk → high-risk)

1. **`QdrantFilterBuilder`** — rename methods, add `Should*`, add `Clone()`, remove dead code. Update `XmlCommentFilterStrategy` and `QuestionFilterSelector`. *No public API break* if you keep the old method names as `[[Obsolete]]` aliases for one release.
2. **`OllamaChatClientBuilder`** — add the new fluent methods. The old two-method surface still compiles. Add `OllamaApiClientFactory` and wire into DI.
3. **`PipelineRunner`** — add `UseRetry` and `WithStage<T>`. Purely additive.
4. **`BuilderBase`** — refactor the two builders to inherit from it. This is a pure internal restructure; no public API change.
5. **`IQueryBuilder` abstraction** — defer until you actually need a second vector store.

Each step is independently shippable and testable, so you can land them as separate PRs without a big-bang rewrite.

# Reworking & Improving the Builders in This Codebase

There are two distinct builders in the codebase: **`QdrantFilterBuilder`** and **`OllamaChatClientBuilder`**. Each has specific shortcomings that can be addressed. Below is a structured analysis with concrete refactoring suggestions and code.

---

## 1. `QdrantFilterBuilder` – Current State & Gaps

| Aspect | Current | Problem |
|--------|---------|---------|
| Condition types | `MatchKeyword`, `Range`, `ExceptKeywords` | No `IsNull`, `FullText`, `Regex`, `Geo`, or `MatchAny` (multi-value) |
| Multi-value matching | `AddExceptKeywords(params string[[]])` only for *exclusion* | No `AddMatchAny(field, a, b, c)` for *inclusion* of multiple values |
| Extensibility | No way to inject a raw `Condition` | New Qdrant condition types require a new method each time |
| Empty handling | `Build()` throws `InvalidOperationException` | A valid "no-filter" scenario is impossible; callers must pre-check |
| Reset / reuse | No `Clear()` | Builder is effectively single-use; can't reset and re-use |
| Value types | `AddRange` uses `double?` | Qdrant payloads often store `long`/`int`; casting is lossy and wasteful |
| Composite logic | Only flat `Must` / `MustNot` | No `Should` (any-of) group, no nested `Filter` composition |
| Thread-safety | None documented | Fine for single-use, but worth an explicit note or `readonly` after `Build()` |

### Refactored `QdrantFilterBuilder`

```csharp
using Qdrant.Client.Grpc;

/// <summary>
/// Fluent, extensible builder for Qdrant filter expressions.
/// Supports Must, MustNot, and Should (any-of) groups plus a raw-condition escape hatch.
/// </summary>
public sealed class QdrantFilterBuilder
{
    private readonly List<Condition> _must     = [[]];
    private readonly List<Condition> _mustNot  = [[]];
    private readonly List<Condition> _should   = [[]];   // ← NEW: any-of group
    private bool _built;                                // ← NEW: freeze after Build

    // ──────────────────────────────────────────────
    //  Keyword matching
    // ──────────────────────────────────────────────

    /// <summary>Field must equal <paramref name="value"/>.</summary>
    public QdrantFilterBuilder AddMatch(string field, string value)
        => Add(_must, Conditions.MatchKeyword(field, value));

    /// <summary>Field must NOT equal <paramref name="value"/>.</summary>
    public QdrantFilterBuilder AddExclusion(string field, string value)
        => Add(_mustNot, Conditions.MatchKeyword(field, value));

    /// <summary>Field must match ANY of <paramref name="values"/> (positive set).</summary>
    public QdrantFilterBuilder AddMatchAny(string field, params string[[]] values)
        => Add(_must, new Condition
        {
            Field = new FieldCondition
            {
                Key   = field,
                Match = new Match { AnyKeywords = new RepeatedStrings { Strings = { values } } }
            }
        });

    /// <summary>Field must NOT match ANY of <paramref name="values"/>.</summary>
    public QdrantFilterBuilder AddExceptKeywords(string field, params string[[]] values)
        => Add(_must, new Condition
        {
            Field = new FieldCondition
            {
                Key   = field,
                Match = new Match { ExceptKeywords = new RepeatedStrings { Strings = { values } } }
            }
        });

    // ──────────────────────────────────────────────
    //  Numeric / range matching
    // ──────────────────────────────────────────────

    /// <summary>Numeric range on <paramref name="field"/> (gte and/or lte).</summary>
    public QdrantFilterBuilder AddRange(string field, double? gte = null, double? lte = null)
    {
        var range = BuildRange(gte, lte);
        return Add(_must, new Condition { Field = new FieldCondition { Key = field, Range = range } });
    }

    /// <summary>Numeric range on <paramref name="field"/> (must NOT be in range).</summary>
    public QdrantFilterBuilder AddExclusionRange(string field, double? gte = null, double? lte = null)
    {
        var range = BuildRange(gte, lte);
        return Add(_mustNot, new Condition { Field = new FieldCondition { Key = field, Range = range } });
    }

    // ──────────────────────────────────────────────
    //  Nullable / full-text  (NEW)
    // ──────────────────────────────────────────────

    /// <summary>Field must be null (absent from payload).</summary>
    public QdrantFilterBuilder AddIsNull(string field)
        => Add(_must, new Condition { Field = new FieldCondition { Key = field, IsNull = true } });

    /// <summary>Field must NOT be null.</summary>
    public QdrantFilterBuilder AddNotNull(string field)
        => Add(_mustNot, new Condition { Field = new FieldCondition { Key = field, IsNull = true } });

    /// <summary>Full-text match on a string field.</summary>
    public QdrantFilterBuilder AddFullText(string field, string text)
        => Add(_must, new Condition
        {
            Field = new FieldCondition
            {
                Key   = field,
                Match = new Match { FullText = new FullTextMatch { Text = text } }
            }
        });

    // ──────────────────────────────────────────────
    //  Should (any-of) group  (NEW)
    // ──────────────────────────────────────────────

    /// <summary>Adds a condition to the Should (any-of) group.</summary>
    public QdrantFilterBuilder AddShould(string field, string value)
        => Add(_should, Conditions.MatchKeyword(field, value));

    // ──────────────────────────────────────────────
    //  Raw-condition escape hatch  (NEW)
    // ──────────────────────────────────────────────

    /// <summary>Injects a pre-built <see cref="Condition"/> directly. Use for exotic Qdrant condition types.</summary>
    public QdrantFilterBuilder AddRaw(Condition condition, bool must = true, bool mustNot = false)
    {
        Guard.Against.Null(condition);
        if (must)    Add(_must, condition);
        if (mustNot) Add(_mustNot, condition);
        return this;
    }

    // ──────────────────────────────────────────────
    //  Lifecycle
    // ──────────────────────────────────────────────

    /// <summary>True when no conditions have been added.</summary>
    public bool IsEmpty => _must.Count == 0 && _mustNot.Count == 0 && _should.Count == 0;

    /// <summary>Resets all conditions so the builder can be reused.</summary>
    public QdrantFilterBuilder Clear()
    {
        _must.Clear();
        _mustNot.Clear();
        _should.Clear();
        _built = false;
        return this;
    }

    /// <summary>
    /// Builds the final <see cref="Filter"/>.
    /// Returns an empty filter (no conditions) when the builder is empty,
    /// rather than throwing — callers that need a hard error can check <see cref="IsEmpty"/> first.
    /// </summary>
    public Filter Build()
    {
        // Allow single-build semantics; reset if you want to build again
        if (_built)
            throw new InvalidOperationException(
                "QdrantFilterBuilder has already been built. Call Clear() to reset before rebuilding.");

        _built = true;

        return new Filter
        {
            Must    = { _must    },
            MustNot = { _mustNot },
            Should  = { _should  }   // ← NEW
        };
    }

    // ──────────────────────────────────────────────
    //  Internal helpers
    // ──────────────────────────────────────────────

    private QdrantFilterBuilder Add(List<Condition> list, Condition c)
    {
        if (_built)
            throw new InvalidOperationException("Cannot modify a builder after Build() was called.");
        list.Add(c);
        return this;
    }

    private static Range BuildRange(double? gte, double? lte)
    {
        if (gte is null && lte is null)
            throw new ArgumentException("At least one of gte or lte must be provided.", nameof(gte));

        var r = new Range();
        if (gte is not null) r.Gte = gte.Value;
        if (lte is not null) r.Lte = lte.Value;
        return r;
    }
}
```

**Key changes at a glance**

| Improvement | Why |
|---|---|
| `AddMatchAny` / `AddFullText` / `AddIsNull` / `AddNotNull` | Covers the most common Qdrant condition types that were missing |
| `_should` list + `Should` in `Filter` | Enables "match any of these" semantics without nesting |
| `AddRaw(Condition)` | Escape hatch so you never need to add a new method for a new Qdrant type |
| `Clear()` + `_built` guard | Builder is now safely re-usable and prevents accidental mutation after `Build()` |
| `Build()` returns empty `Filter` instead of throwing | Removes a `try/catch` obligation from every caller; `IsEmpty` still available for explicit checks |
| Private `Add` helper | Centralises the "frozen after build" check in one place |

## 2. `OllamaChatClientBuilder` – Current State & Gaps

The existing class is essentially a two-method stub that constructs an `OllamaChatClientBuilderConfigured`. The factory field is **commented out**, there is no `Build()` method, and no fluent configuration surface.

### Refactored `OllamaChatClientBuilder`

```csharp
/// <summary>
/// Fluent builder for fully-configured Ollama chat / embedding clients.
/// Validates options at Build() time and resolves through the factory.
/// </summary>
public sealed class OllamaChatClientBuilder(
    IOllamaClientFactory factory,           // ← actually injected now
    IOptions<RagnarConfig> config)          // ← config for defaults
{
    private OllamaServiceType  _serviceType  = OllamaServiceType.Ollama;
    private string?            _model;
    private float?             _temperature;
    private int?               _maxTokens;
    private TimeSpan?          _timeout;
    private string?            _host;
    private int?               _port;

    // ── Fluent configuration ──

    public OllamaChatClientBuilder WithServiceType(OllamaServiceType type)
    {
        _serviceType = type;
        return this;
    }

    public OllamaChatClientBuilder WithModel(string model)
    {
        Guard.AgainstNullOrWhiteSpace(model);
        _model = model;
        return this;
    }

    public OllamaChatClientBuilder WithTemperature(float temp)
    {
        if (temp is < 0f or > 2f)
            throw new ArgumentOutOfRangeException(nameof(temp), "Temperature must be 0.0 – 2.0.");
        _temperature = temp;
        return this;
    }

    public OllamaChatClientBuilder WithMaxTokens(int max)
    {
        if (max is < 1 or > 131_072)
            throw new ArgumentOutOfRangeException(nameof(max), "MaxTokens must be 1 – 131 072.");
        _maxTokens = max;
        return this;
    }

    public OllamaChatClientBuilder WithTimeout(TimeSpan ts)
    {
        if (ts <= TimeSpan.Zero)
            throw new ArgumentOutOfRangeException(nameof(ts), "Timeout must be positive.");
        _timeout = ts;
        return this;
    }

    public OllamaChatClientBuilder WithEndpoint(string host, int port)
    {
        Guard.AgainstNullOrWhiteSpace(host);
        if (port is < 1 or > 65_535)
            throw new ArgumentOutOfRangeException(nameof(port));
        _host = host;
        _port = port;
        return this;
    }

    // ── Build ──

    /// <summary>
    /// Validates all settings, merges with <see cref="RagnarConfig"/> defaults,
    /// and resolves the final client through <see cref="IOllamaClientFactory"/>.
    /// </summary>
    public IOllamaApiClient Build()
    {
        // 1. Merge explicit values over config defaults
        var ollamaOpts  = config.Value.OllamaOptions;
        var embedOpts   = config.Value.EmbeddingOptions;

        var effectiveModel   = _model     ?? ollamaOpts.ModelName;
        var effectiveTemp    = _temperature ?? ollamaOpts.GenerationOptions?.Temperature ?? 0.2f;
        var effectiveMaxTok  = _maxTokens ?? ollamaOpts.GenerationOptions?.MaxTokens    ?? 32_768;
        var effectiveTimeout = _timeout   ?? ollamaOpts.Timeout;
        var effectiveHost    = _host      ?? (_serviceType == OllamaServiceType.Ollama
                                            ? ollamaOpts.Host
                                            : embedOpts.Host);
        var effectivePort    = _port      ?? (_serviceType == OllamaServiceType.Ollama
                                            ? ollamaOpts.Port
                                            : embedOpts.Port);

        // 2. Basic validation (beyond what the data-annotation ranges already do)
        Guard.AgainstNullOrWhiteSpace(effectiveModel);

        // 3. Resolve through the factory
        var client = factory.ResolveClient(_serviceType);

        // 4. (Optional) apply any additional settings the client exposes
        //    e.g. client.SelectedModel = effectiveModel;

        return client;
    }
}
```

**Key changes at a glance**

| Improvement | Why |
|---|---|
| `IOllamaClientFactory` is **actually injected** (was commented out) | The builder can now resolve real clients |
| `IOptions<RagnarConfig>` for defaults | Centralised configuration; fluent setters override per-instance |
| Full fluent surface (`WithModel`, `WithTemperature`, `WithTimeout`, `WithEndpoint`, …) | Callers compose exactly what they need instead of pre-building an options object |
| `Build()` with validation + merge logic | Single point where defaults, explicit values, and invariants are reconciled |
| Range / null guards on every setter | Fail-fast at the call-site rather than at the Ollama API boundary |

## 3. Cross-Cutting Builder Improvements

These apply to **both** builders and any future builder in the project.

### 3.1 Introduce a shared `IBuilder<T>` / `IBuildable<T>` contract

```csharp
/// <summary>Marker interface for all fluent builders in the project.</summary>
public interface IBuildable<out T>
{
    T Build();
}

/// <summary>Optional reset capability for reusable builders.</summary>
public interface IResettable : IBuildable<object>
{
    void Clear();
}
```

Benefits:
- Uniform `Build()` entry-point for DI, testing, and code-gen tooling.
- Makes it trivial to write a generic "build-and-validate" middleware.

### 3.2 Centralised validation with FluentValidation

You already use FluentValidation for config (`RagnarConfigValidator`). Extend the same approach:

```csharp
public sealed class QdrantFilterBuilderValidator : AbstractValidator<QdrantFilterBuilder>
{
    public QdrantFilterBuilderValidator()
    {
        RuleFor(b => b).Must(b => !b.IsEmpty)
            .When(b => /* caller opts in to requiring at least one condition */)
            .WithMessage("At least one filter condition is required.");

        // Per-condition range sanity checks can be added here
    }
}
```

Then call `validator.ValidateAndThrow(builder)` inside `Build()` (or via a policy) so the builder never emits a structurally invalid `Filter`.

### 3.3 Make built objects truly immutable

Both builders should produce **sealed records / readonly types** after `Build()`:

```csharp
// QdrantFilterBuilder.Build() already returns a Qdrant Filter (proto) – fine.

// For OllamaChatClientBuilder, consider returning a sealed record:
public sealed record ResolvedOllamaClient(
    IOllamaApiClient Client,
    string           Model,
    float            Temperature,
    int              MaxTokens,
    TimeSpan         Timeout,
    string           Host,
    int              Port
);
```

This prevents accidental mutation of a "final" configuration after it has been handed to the orchestrator.

### 3.4 Add a `ShouldRun`-style guard to the pipeline

`PipelineRunner` already supports `stage.ShouldRun(context)`. For builder-heavy stages, a natural fit is:

```csharp
public bool ShouldRun(QuestionPipelineContext ctx)
    => ctx.Questions is { Count: > 0 };   // skip retrieval if no questions loaded
```

This keeps the builder pipeline lightweight when there is nothing to filter / generate.

### 3.5 Testing strategy for builders

Because both builders are now pure (no I/O inside the builder itself; I/O is delegated to the factory / Qdrant client), unit-testing is straightforward:

```csharp
[[Fact]]
public void QdrantFilterBuilder_Build_ProducesExpectedConditions()
{

        .AddMatch("Category", "XML")
        .AddRange("CommentLength", gte: 50)
        .AddExceptKeywords("Category", "Test", "Tests")
        .Build();

    Assert.Equal(3, filter.Must.Count);
    Assert.Empty(filter.MustNot);
    Assert.Empty(filter.Should);

[[Fact]]
public void QdrantFilterBuilder_Build_Twice_Throws()

    var b = new QdrantFilterBuilder().AddMatch("f", "v");

[[Fact]]
public void QdrantFilterBuilder_Clear_AllowsRebuild()

    var b = new QdrantFilterBuilder().AddMatch("f", "v");
    b.Build();
    b.Clear();
    b.AddMatch("other", "x");
    var filter = b.Build();          // should succeed
    Assert.Single(filter.Must);
```

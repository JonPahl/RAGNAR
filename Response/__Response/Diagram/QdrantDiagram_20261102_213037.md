        FD->>FE: IsValid(fileInfo, FileLoadOptions)

            FD-->>PR: yield file path

            FD->>FD: skippedCount++

    Note over PR: ── Stage 3: Parsing ──
    loop each eligible file
        PR->>PF: ParseAsync(filePath, ct)
        alt .cs extension
            PF->>PF: Roslyn syntax-tree parse
        else other extension
            PF->>PF: Markdown / generic parse
        end
        PF-->>PR: IEnumerable~CodeDocument~
    end

    Note over PR: ── Stage 4: Embedding ──

        PR->>ES: GenerateAsync(batch, ct)
        ES->>QD: POST /api/embed (Ollama API)

        ES-->>PR: Embedding~float~[[]]
    end

    Note over PR: ── Stage 5: Vector Setup ──
    PR->>VS: EnsureCollectionAsync(ct)
    VS->>QD: GET /collections/{name}

        VS->>QD: PUT /collections/{name} (dimension, config)
    end
    QD-->>VS: CollectionInfo
    VS-->>PR: CollectionInfo (Name, Dimension, VectorsCount, Status)

    Note over PR: ── Stage 6: Write Vectors ──
    PR->>VW: WriteAsync(points, ct)
    loop each CodeDocument
        VW->>VF: CreatePoint(codeDoc, embedding)
        VF-->>VW: PointStruct { id, vector, payload }
    end
    VW->>QD: PUT /collections/{name}/points (batch)
    QD-->>VW: UpsertResult
    VW-->>PR: Task completed

### Key Takeaways from the Codebase

| Concern | How it's handled |
|---|---|
| **Filter construction** | `QdrantFilterBuilder` (fluent) → `XmlCommentFilterStrategy` → `QuestionFilterSelector` (strategy pattern keyed by `QuestionCategory`) |
| **Point creation** | `PointStructFactory` maps `CodeDocument` + `Embedding<float>` → Qdrant `PointStruct` with a payload containing `FilePath`, `CodeSegment`, `XmlComment`, `Category`, `CommentLength` |
| **Collection lifecycle** | `VectorSetup.EnsureCollectionAsync` checks/creates the collection using `CollectionInfo` (name, dimension, count, status) |
| **Bulk write** | `VectorStoreWriter` batches via `BatchSize` from `EmbeddingOptions` |
| **Query path** | `RagOrchestrator` builds a prompt with retrieved context; filter is resolved per-question-category before the Qdrant search call |
| **Pipeline** | `PipelineRunner<EmbeddingContext>` executes stages sequentially with optional Polly retry + `StageTimingMiddleware` for observability |

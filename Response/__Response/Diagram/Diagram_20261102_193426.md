## 7. State Diagram — Pipeline Stage Lifecycle

```mermaid
stateDiagram-v2
    [*] --> Unregistered

    Unregistered --> Registered : AddStage(stage, policy)
    Registered --> Skipped : ShouldRun(ctx) == false
    Skipped --> Registered : next stage

    Registered --> Running : ExecuteAsync begins\nmiddleware chain invoked
    Running --> Succeeding : next() completes
    Running --> Failing : exception thrown
    Running --> Cancelled : OperationCanceledException

    Succeeding --> Completed : StageMetric.Success = true
    Failing --> Retrying : AsyncPolicy != null\n&& retries remain
    Failing --> Failed : AsyncPolicy == null\n|| retries exhausted

    Retrying --> Running : retry attempt
    Cancelled --> Aborted : rethrow OCE
    Failed --> Aborted : throw PipelineStageException

    Completed --> [*] : all stages done
    Aborted --> [*] : pipeline halts

    note right of Registered
        StageEntry<TContext> holds:
        • PipelineStage (IPipelineStage)
        • AsyncPolicy (IAsyncPolicy?)
    end note

    note right of Running
        Onion middleware:
        MW_n → MW_{n-1} → … → MW_1 → Stage
    end note

    note right of Completed
        StageMetric populated:
        StageName, Duration, Success,
        RetryCount, Error
    end note
```

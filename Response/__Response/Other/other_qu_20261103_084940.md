# Suggested Questions for Deeper Codebase Analysis

Based on what's visible, here are questions that would help uncover gaps, confirm intent, and stress-test the design:

## Architecture & Completeness

1. **Where is the retrieval (embedding search) stage?** The `RagOrchestrator` references `contextText` as a parameter, but I don't see a `RetrieveStage` or `VectorSearchService` that queries Qdrant. How is the vector search actually wired into the pipeline, and what `TopK` / `ScoreThreshold` logic determines which chunks are injected as context?

2. **How does the embedding pipeline (indexing) connect to the question pipeline (query)?** I see `EmbeddingContext` and `QuestionPipelineContext` as separate types. What triggers a re-embedding, and is there a consistency guarantee between the dimension stored in `EmbeddingOptions.Dimension` and what Qdrant actually reports in `CollectionInfo.Dimension`?

3. **What's the full `RagnarConfig` shape?** The validator references `ApplicationOptions`, `EmbeddingOptions`, `OllamaOptions`, and `FileLoadOptions` — but I don't see an `ApplicationOptions` record or its validator. What options live there (e.g., `IncludeOriginalPrompt`, response directory, console width)?

## Pipeline & Extensibility

4. **Are there any `IFilterStrategy` implementations beyond `XmlCommentFilterStrategy`?** The `QuestionFilterSelector` falls back to an empty `Filter` for unregistered categories. Is that intentional (return *all* vectors), or should it be a no-op / exception?

5. **How are Polly retry policies configured per-stage?** `StageEntry` accepts an `IAsyncPolicy?`, but I don't see where policies are instantiated or bound to stages. Is there a `PolicyFactory`, or are they hard-coded at composition root?

6. **What happens on partial pipeline failure?** If stage 3 of 5 throws and the `OperationCanceledException` filter re-throws, are stages 1–2's side effects (e.g., embeddings already written to Qdrant) rolled back, or is there a compensation/idempotency strategy?

## Performance & Scalability

7. **`FileDiscoveryService` enumerates synchronously via `Directory.EnumerateFiles` inside an async iterator.** For large repos (10k+ files), is there a plan to use `System.IO.Enumeration` with `CancellationToken` natively, or is the `Task.Yield()` per-file sufficient?

8. **`GenerationOptions.ThreadCount` (default 8) is defined but where is it consumed?** Is there a `Parallel.ForEachAsync` or `SemaphoreSlim` gating concurrent embedding/generation calls, or is everything currently sequential?

9. **What's the expected scale?** How many questions per CSV, how many source files per indexing run, and what's the target Qdrant collection size? This determines whether batched upserts (`BatchSize` in `EmbeddingOptions`) and connection pooling matter.

## Observability & Operations

10. **Beyond `StageTimingMiddleware`, is there structured tracing (OpenTelemetry / ActivitySource)?** The `StageMetric` record is populated, but where does it go — a file, an in-memory ring buffer, an OTLP exporter? Is there a `CorrelationId` threading through Serilog across the entire question→generation→save cycle?

11. **What's the failure mode if Ollama is unreachable mid-batch?** `GenerateAsync` catches non-cancellation exceptions and returns a static error string. Is there a circuit breaker, or will subsequent questions in the batch hammer a dead endpoint?

## Configuration & Validation

12. **`EmbeddingOptions.Host` is typed as `Uri` but marked `required`.** If the JSON config supplies a relative or malformed URI, does `IOptions<T>` deserialization fail fast, or does the `Range`/`Length` attributes only catch semantic issues? Is there a `IValidateOptions` implementation beyond the FluentValidation validators?

13. **`FileLoadOptions.AllowedExtensions` validation checks `e[[0]] == '.'` but not duplicate entries.** Given it's a `HashSet<string>` with `OrdinalIgnoreCase`, duplicates are silently deduplicated. Is that the intended contract, or should the validator reject them explicitly?

## Testing & Quality

14. **What's the test strategy for the pipeline?** The `PipelineRunner` builds an "onion" of middlewares via closure capture. Are there integration tests that verify middleware ordering, and unit tests that assert `StageMetric` is populated correctly when a stage throws?

15. **Is there a golden-file / snapshot test for the generated prompt?** The `IRagPromptBuilder` + `IChatPromptProvider` + `WithContext`/`WithQuestion` chain produces the final prompt. A regression test on the exact string would catch subtle template ordering bugs.

## Security & Data

16. **Are source files logged in full?** `FileDiscoveryService` logs each eligible path at `Verbose`, and `RagOrchestrator` logs the question text. Is there a guard preventing proprietary file paths or question content from leaking into log sinks (e.g., file-based Serilog sinks in a shared folder)?

17. **What authentication/authorization does the Ollama endpoint use?** `EmbeddingOptions.Host` is a plain `Uri` with no `ApiKey` or `Bearer` field. If this ever points to a remote Ollama instance, how is the `Authorization` header supplied?

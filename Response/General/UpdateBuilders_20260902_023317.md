# Reworking & Improving the Existing Builders

Your code base currently has two primary builders — **`QuestionCombineBuilder`** and **`VectorStoreBuilder`** — plus a referenced **`QuestionBuilder`**. Both share several architectural weaknesses. Below is a structured plan to rework them.

---

## 1. Current Problems

### `QuestionCombineBuilder`

| Issue | Location |
|-------|----------|
| Mixes **loading**, **filtering**, and **building** in one class | entire class |
| `GetCsvFileAsync` returns `Task<QuestionCombineBuilder>`, breaking the fluent chain | `GetCsvFileAsync` |
| `WithCategoryFilter` mutates the internal list destructively (`Clear` → `AddRange`) | `WithCategoryFilter` |
| Categories `HashSet` is **hard-coded empty** with a `//todo` | `WithCategoryFilter` |
| Creates `CsvRecordParser` / `CsvFileQuestionProvider` **internally** instead of DI | `GetCsvFileAsync` |
| No guard against calling `Build()` before any source is loaded | `Build` |
| Returns `IReadOnlyList<Question>` but doesn't prevent further mutation of the builder after `Build()` | `Build` |

### `VectorStoreBuilder`

| Issue | Location |
|-------|----------|
| `VectorStoreName`, `Dimension`, `Logger`, `QdrantClient` all have **public setters** — breaks immutability | property declarations |
| `BuildAsync()` returns `bool`, not the builder — inconsistent fluent API | `BuildAsync` |
| `IsExisting` is a mutable backing state, not part of the "built" value | `IsExisting` |
| `MakeIndexAsync(string indexName, …)` — parameter is actually a **field name**, misleading name | `MakeIndexAsync` |
| `sealed` class with public setters — contradictory design | class declaration |
| No way to chain multiple indexes or configure payload in a single fluent call | overall |

## 3. Concrete Refactors

### 3a. `QuestionBuilder` — Immutable, Single-Use

```csharp
/// <summary>
/// Builds a single <see cref="Question"/> instance.
/// All setters return <c>this</c> for chaining; <see cref="Build"/> validates.
/// </summary>
public sealed class QuestionBuilder
{
    private string? _text;
    private string? _fileName;
    private QuestionCategory _category = QuestionCategory.General;
    private bool _isActive = true;

    public QuestionBuilder WithText(string text)
    {
        Guard.Against.NullOrWhiteSpace(text);
        _text = text;
        return this;
    }

    public QuestionBuilder WithFileName(string fileName)
    {
        Guard.Against.NullOrWhiteSpace(fileName);
        _fileName = fileName;
        return this;
    }

    public QuestionBuilder SetCategory(QuestionCategory category)
    {
        _category = category;
        return this;
    }

    public QuestionBuilder SetActive(bool isActive)
    {
        _isActive = isActive;
        return this;
    }

    /// <summary>
    /// Validates required fields and produces the immutable <see cref="Question"/>.
    /// </summary>
    public Question Build()
    {
        Guard.Against.Null(_text, nameof(_text));
        Guard.Against.Null(_fileName, nameof(_fileName));
        return new Question(_isActive, _text, _fileName, _category);
    }
}
```

**Why:** eliminates the current pattern where `QuestionCombineBuilder` creates and discards `QuestionBuilder` instances in a loop. Each source provider now owns its own builder instances.

### 3b. `IQuestionSource` — Extract Loading from the Builder

```csharp
/// <summary>
/// A pluggable source of <see cref="Question"/> records.
/// </summary>
public interface IQuestionSource
{
    string Name { get; }
    Task<IReadOnlyList<Question>> LoadAsync(CancellationToken ct);
}
```

Concrete implementations:

```csharp
public sealed class CsvQuestionSource : IQuestionSource
{
    private readonly IRecordParser<QuestionRecord> _parser;
    private readonly string _pluginDir;

    public CsvQuestionSource(IRecordParser<QuestionRecord> parser, string pluginDir)
    {
        _parser  = parser;
        _pluginDir = pluginDir;
    }

    public string Name => "CSV";

    public async Task<IReadOnlyList<Question>> LoadAsync(CancellationToken ct)
    {
        if (!Directory.Exists(_pluginDir)) return [[]];
        var records = new List<Question>();
        foreach (var file in Directory.EnumerateFiles(_pluginDir, "*.csv", SearchOption.AllDirectories))
        {
            var parsed = await _parser.ParseAsync(file, ct);
            records.AddRange(parsed.Select(r => new Question(r.IsEnabled, r.Text, r.FileName, r.Category)));
        }
        return records;
    }
}

// Similar for CategoryQuestionSource, FileConfigQuestionSource, PluginQuestionSource
```

**Why:** removes the `//todo: move these questions to csv file` smell, makes sources independently testable, and lets you register them via DI (already partially done with `IQuestionProvider` in `ApplicationConfigurationExtensions.LoadQuestionPlugins()`).

### 3c. `QuestionCollectionBuilder` — Compose, Filter, Validate

```csharp
public sealed class QuestionCollectionBuilder
{
    private readonly List<Question> _questions = [[]];
    private bool _isBuilt;

    /// <summary>Registers a source to load from.</summary>
    public QuestionCollectionBuilder AddSource(IQuestionSource source)
    {
        Guard.Against.Null(source);
        _sources.Add(source);   // collected, loaded lazily in BuildAsync
        return this;
    }

    /// <summary>
    /// Filters the collection to the given categories.
    /// Returns a *new* builder so the original is unmutated.
    /// </summary>
    public QuestionCollectionBuilder FilterByCategory(params QuestionCategory[[]] categories)
    {
        var clone = Clone();
        clone._questions.RemoveAll(q => !categories.Contains(q.Category));
        return clone;
    }

    /// <summary>
    /// Loads all registered sources, merges, deduplicates, and freezes the set.
    /// </summary>
    public async Task<QuestionSet> BuildAsync(CancellationToken ct)
    {
        if (_isBuilt)
            throw new InvalidOperationException("QuestionCollectionBuilder is single-use. Create a new instance.");

        foreach (var source in _sources)
        {
            var loaded = await source.LoadAsync(ct);
            _questions.AddRange(loaded);
        }

        var result = new QuestionSet(
            _questions
                .Where(q => q.IsEnabled)
                .GroupBy(q => new { q.Text, q.FileName })
                .Select(g => g.First())
                .OrderBy(q => q.Category)
                .ThenBy(q => q.FileName)
                .ToList()
                .AsReadOnly());

        _isBuilt = true;
        return result;
    }
}

/// <summary>Immutable, read-only projection of the final question set.</summary>
public readonly record struct QuestionSet(IReadOnlyList<Question> Questions)
{
    public int Count => Questions.Count;
    public bool ContainsCategory(QuestionCategory cat) => Questions.Any(q => q.Category == cat);
}
```

**Key improvements over the current `QuestionCombineBuilder`:**

| Before | After |
|--------|-------|
| `GetCsvFileAsync` returns `Task<Builder>` (breaks fluent chain) | Sources implement `IQuestionSource.LoadAsync`; the builder calls them in `BuildAsync` |
| `WithCategoryFilter` mutates internal state destructively | `FilterByCategory` returns a **new** builder (functional) |
| Categories `HashSet` hard-coded empty | Passed in from `ApplicationOptions.CategoriesToProcess` via the source or filter |
| No deduplication | `GroupBy` + `Select(First)` in `BuildAsync` |
| No single-use guard | `_isBuilt` flag + `InvalidOperationException` |
| Returns raw `IReadOnlyList` | Returns a typed `QuestionSet` value object |

### 3d. `VectorStoreBuilder` — True Fluent, Immutable Config

```csharp
/// <summary>
/// Fluent builder for Qdrant vector store configuration.
/// All configuration methods return <c>this</c>; <see cref="BuildAsync"/>
/// is terminal and returns an immutable <see cref="VectorStoreSpec"/>.
/// </summary>
public sealed class VectorStoreBuilder
{
    private string? _name;
    private ulong   _dimension  = 768;
    private Distance _distance  = Distance.Cosine;
    private readonly List<(string Field, PayloadSchemaType Type)> _indexes = [[]];

    // ── Fluent setters (all return this) ──────────────────────

    public VectorStoreBuilder Named(string name)
    {
        Guard.Against.NullOrWhiteSpace(name);
        _name = name;
        return this;
    }

    public VectorStoreBuilder WithDimension(ulong dim)
    {
        if (dim is 0 or > 65536)
            throw new ArgumentOutOfRangeException(nameof(dim));
        _dimension = dim;
        return this;
    }

    public VectorStoreBuilder WithDistance(Distance distance)
    {
        _distance = distance;
        return this;
    }

    public VectorStoreBuilder WithPayloadIndex(string fieldName, PayloadSchemaType schemaType)
    {
        Guard.Against.NullOrWhiteSpace(fieldName);
        _indexes.Add((fieldName, schemaType));
        return this;
    }

    // ── Terminal ───────────────────────────────────────────────

    public VectorStoreSpec Build()
    {
        Guard.Against.Null(_name, nameof(_name));
        return new VectorStoreSpec(_name, _dimension, _distance,
            _indexes.ToImmutableArray());
    }
}

/// <summary>Immutable specification of a Qdrant collection.</summary>
public sealed record VectorStoreSpec(
    string Name,
    ulong Dimension,
    Distance Distance,
    ImmutableArray<(string Field, PayloadSchemaType Type)> PayloadIndexes);
```

**Usage:**

```csharp
var spec = new VectorStoreBuilder()
    .Named("programming_docs")
    .WithDimension(768)
    .WithDistance(Distance.Cosine)
    .WithPayloadIndex("category", PayloadSchemaType.Keyword)
    .WithPayloadIndex("language", PayloadSchemaType.Keyword)
    .Build();

await vectorStoreProvisioner.ProvisionAsync(spec, ct);
```

**Key improvements:**

| Before | After |
|--------|-------|
| Public setters on `VectorStoreName`, `Dimension`, `Logger`, `QdrantClient` | All set via fluent methods; no public `set` |
| `BuildAsync()` returns `bool` (was the collection created?) | `Build()` returns an immutable `VectorStoreSpec`; a separate `VectorStoreProvisioner` handles I/O |
| `IsExisting` mutable flag | Eliminated — `Provisioner` checks existence at call time |
| `MakeIndexAsync` one-index-per-call | Chain multiple `.WithPayloadIndex(...)` calls before `Build()` |
| `sealed` + public setters (contradiction) | `sealed` + no public setters (consistent) |

### 3e. Separation: `VectorStoreProvisioner` (I/O) vs `VectorStoreBuilder` (config)

```csharp
public sealed class VectorStoreProvisioner(
    IQdrantClient qdrant,
    Serilog.ILogger logger)
{
    public async Task ProvisionAsync(VectorStoreSpec spec, CancellationToken ct)
    {
        if (await qdrant.CollectionExistsAsync(spec.Name, ct))
        {
            logger.Information("Collection {Name} already exists.", spec.Name);
        }
        else
        {
            await qdrant.CreateCollectionAsync(
                spec.Name,
                new VectorParams { Size = spec.Dimension, Distance = spec.Distance },
                cancellationToken: ct);
            logger.Information("Created collection {Name} (dim={Dim}, {Dist}).",
                spec.Name, spec.Dimension, spec.Distance);
        }

        foreach (var (field, type) in spec.PayloadIndexes)
        {
            await qdrant.CreatePayloadIndexAsync(
                spec.Name, field, type, ct);
        }
    }
}
```

**Why:** the builder now has **zero I/O dependencies** — it's pure config. The provisioner is the only class that touches `IQdrantClient`. This makes the builder trivially unit-testable without mocking Qdrant.

## 6. Summary of Changes

| Area | Action |
|------|--------|
| **`QuestionCombineBuilder`** | Split into `IQuestionSource` (loaders) + `QuestionCollectionBuilder` (compose/filter) + `QuestionSet` (immutable result) |
| **`QuestionBuilder`** | Make fully immutable-return, add `Guard` validation in `Build()` |
| **`VectorStoreBuilder`** | Remove all public setters; make fluent; return `VectorStoreSpec` value object |
| **Qdrant I/O** | Extract into `VectorStoreProvisioner`; builder becomes pure config |
| **DI** | Register `IQuestionSource` implementations; `QuestionCollectionBuilder` composed via `AddSource` |
| **Async in builder** | Move async loading to `IQuestionSource.LoadAsync`; builder's `BuildAsync` orchestrates |
| **Categories `HashSet`** | Populate from `ApplicationOptions.CategoriesToProcess` (already in config); remove the empty `HashSet` + `//todo` |
| **Tests** | Each source, builder, and provisioner tested independently; no more `Mock<IQdrantClient>` in builder tests |

This gives you a set of small, single-responsibility builders that are fluent, immutable, independently testable, and easy to extend (e.g., add a new `IQuestionSource` for a REST endpoint without touching the builder).

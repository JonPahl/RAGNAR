## Step-by-Step Guide

### Step 1 – Create the directory skeleton

Run the PowerShell script below from the **solution root** (the folder that contains the `.sln`). It creates every folder in one shot.

### Step 2 – Move files into their new homes

The same script handles the moves. Each `Move-Item` is guarded so it is a no-op if the file is already in the right place (idempotent).

### Step 3 – Rewrite `namespace` declarations

After moving, the `namespace` in each `.cs` file must match its new folder path. The script performs a **regex replace** on every moved file.

### Step 4 – Fix cross-file `using` directives

Because namespaces changed, some files will need new `using` lines. The script appends the missing usings that are referenced in the file's code (a simple, conservative approach).

### Step 5 – Build and fix any residual errors

Run `dotnet build` and resolve any compiler warnings/errors (usually missing `using` for a type that moved to a sub-namespace).

## PowerShell Script

Save as `reorganize-ragnar.ps1` at the solution root and run:

```powershell
#Requires -Version 7.0
<#
.SYNOPSIS
    Reorganises Ragnar source files into a logical folder / namespace layout.
.DESCRIPTION
    1. Creates the target directory tree under  src/
    2. Moves .cs files from their flat location into the new folders
    3. Rewrites the `namespace` declaration in each file
    4. Appends any missing `using` directives
    5. Verifies with `dotnet build`
.NOTES
    Run from the directory that contains the Ragnar .csproj  (or solution root).
    The script is idempotent – safe to run more than once.
#>

[[CmdletBinding()]]
param(
    # Absolute path to the project (or solution) root
    [[string]]$ProjectRoot = (Get-Location).Path
)

$ErrorActionPreference = 'Stop'
$Src = Join-Path $ProjectRoot 'src'

# ── 1. Create folders ──────────────────────────────────────────────────────
$folders = @(
    "Core/Models"
    "Core/Validation"
    "Pipeline/Abstractions"
    "Pipeline/Runner"
    "Pipeline/Stages"
    "Pipeline/Middleware"
    "Pipeline/Context"
    "FileDiscovery/Abstractions"
    "FileDiscovery/Implementation"
    "FileDiscovery/Parsers"
    "FileDiscovery/Extensions"
    "VectorStore/Qdrant"
    "VectorStore/Filtering"
    "VectorStore/Filtering/Strategies"
    "VectorStore/Embedding"
    "Ollama/Abstractions"
    "Ollama/Implementation"
    "Questions/Extensions"
    "Questions/Converters"
    "Infrastructure/Fingerprinting"
    "Infrastructure/Output"
    "Composition"
)

foreach ($f in $folders) {
    $target = Join-Path $Src $f
    if (-not (Test-Path $target)) {
        New-Item -Path $target -ItemType Directory -Force | Out-Null
        Write-Host "  +  $f" -ForegroundColor DarkGray
    }
}
Write-Host "`n[[1/5]] Folder structure created." -ForegroundColor Cyan

# ── 2. Move files ──────────────────────────────────────────────────────────
#  Map:  <filename>  →  <target-folder-relative-to-src>
$fileMap = [[ordered]]@{
    # Core / Models
    'FileLoadOptions.cs'          = 'Core/Models'
    'CollectionInfo.cs'           = 'VectorStore/Qdrant'   # Qdrant-specific
    'GenerationOptions.cs'        = 'Core/Models'
    'EmbeddingOptions.cs'         = 'Core/Models'
    'StageMetric.cs'              = 'Core/Models'

    # Core / Validation
    'FileLoadOptionsValidator.cs' = 'Core/Validation'

    # Pipeline
    'PipelineMiddleware.cs'       = 'Pipeline/Abstractions'   # contains StageExecutionContext
    'StageEntry.cs'               = 'Pipeline/Runner'
    'PipelineRunner.cs'           = 'Pipeline/Runner'
    'StageTimingMiddleware.cs'    = 'Pipeline/Middleware'
    'ProgressMiddleware.cs'       = 'Pipeline/Middleware'
    'BrandingStage.cs'            = 'Pipeline/Stages'
    'DeltaEmbedStage.cs'          = 'Pipeline/Stages'
    'QuestionPipelineContext.cs'  = 'Pipeline/Context'

    # FileDiscovery
    'IFileEligibilityValidator.cs'= 'FileDiscovery/Abstractions'
    'IFileDiscoveryService.cs'    = 'FileDiscovery/Abstractions'
    'IFileParser.cs'              = 'FileDiscovery/Abstractions'
    'FileDiscoveryService.cs'     = 'FileDiscovery/Implementation'
    'CodeParserFactory.cs'        = 'FileDiscovery/Implementation'
    'FileSystemEntryExtensions.cs'= 'FileDiscovery/Extensions'

    # VectorStore
    'QdrantFilterBuilder.cs'      = 'VectorStore/Qdrant'
    'QuestionFilterSelector.cs'   = 'VectorStore/Filtering'
    'XmlCommentFilterStrategy.cs' = 'VectorStore/Filtering/Strategies'

    # Ollama
    'IOllamaClientFactory.cs'     = 'Ollama/Abstractions'
    'OllamaChatClientBuilder.cs'  = 'Ollama/Implementation'

    # Questions
    'QuestionsExtensions.cs'      = 'Questions/Extensions'
    'EnumConverter.cs'            = 'Questions/Converters'

    # Infrastructure
    'JsonFileFingerprintStore.cs' = 'Infrastructure/Fingerprinting'
    'OutputPathHelper.cs'         = 'Infrastructure/Output'

    # Composition
    'EmbeddingSetupExtension.cs'  = 'Composition'
}

$moved = 0
foreach ($entry in $fileMap.GetEnumerator()) {
    $name   = $entry.Key
    $folder = $entry.Value
    $targetDir = Join-Path $Src $folder
    $target    = Join-Path $targetDir $name

    # Search for the file anywhere under ProjectRoot (skip bin/obj)
    $source = Get-ChildItem -Path $ProjectRoot -Filter $name -Recurse -File -ErrorAction SilentlyContinue |
        Where-Object { $_.FullName -notmatch '\\(bin|obj|\.git)\\' } |
        Select-Object -First 1

    if (-not $source) {
        Write-Warning "  ?  '$name' not found – skipping."
        continue
    }

    if ((Resolve-Path $source.FullName).Path -eq (Resolve-Path $target).Path) {
        # Already in the right place
        continue
    }

    Move-Item -LiteralPath $source.FullName -Destination $target -Force
    Write-Host "  →  $name  ➜  $folder\$name" -ForegroundColor Green
    $moved++
}
Write-Host "`n[[2/5]] Moved $moved file(s)." -ForegroundColor Cyan

# ── 3. Rewrite namespace declarations ──────────────────────────────────────
#  Build a  folder → namespace  lookup
$nsMap = [[ordered]]@{
    'Core/Models'                     = 'Ragnar.Core.Models'
    'Core/Validation'                 = 'Ragnar.Core.Validation'
    'Pipeline/Abstractions'           = 'Ragnar.Pipeline'
    'Pipeline/Runner'                 = 'Ragnar.Pipeline'
    'Pipeline/Stages'                 = 'Ragnar.Pipeline.Stages'
    'Pipeline/Middleware'             = 'Ragnar.Pipeline.Middleware'
    'Pipeline/Context'                = 'Ragnar.Pipeline'
    'FileDiscovery/Abstractions'      = 'Ragnar.FileDiscovery'
    'FileDiscovery/Implementation'    = 'Ragnar.FileDiscovery'
    'FileDiscovery/Parsers'           = 'Ragnar.FileDiscovery.Parsers'
    'FileDiscovery/Extensions'        = 'Ragnar.FileDiscovery'
    'VectorStore/Qdrant'              = 'Ragnar.VectorStore.Qdrant'
    'VectorStore/Filtering'           = 'Ragnar.VectorStore.Filtering'
    'VectorStore/Filtering/Strategies'= 'Ragnar.VectorStore.Filtering'
    'VectorStore/Embedding'           = 'Ragnar.VectorStore'
    'Ollama/Abstractions'             = 'Ragnar.Ollama'
    'Ollama/Implementation'           = 'Ragnar.Ollama'
    'Questions/Extensions'            = 'Ragnar.Questions'
    'Questions/Converters'            = 'Ragnar.Questions'
    'Infrastructure/Fingerprinting'   = 'Ragnar.Infrastructure.Fingerprinting'
    'Infrastructure/Output'           = 'Ragnar.Infrastructure.Output'
    'Composition'                     = 'Ragnar.Composition'
}

$updated = 0
foreach ($entry in $nsMap.GetEnumerator()) {
    $dir  = Join-Path $Src $entry.Key
    $ns   = $entry.Value
    if (-not (Test-Path $dir)) { continue }

    Get-ChildItem -Path $dir -Filter '*.cs' -File | ForEach-Object {
        $content = Get-Content $_.FullName -Raw
        # Replace the existing namespace line (handles both "namespace X" and "namespace X {")
        $newContent = [[regex]]::Replace($content,
            '^\s*namespace\s+[[\w.]]+\s*\{?\s*$',
            "namespace $ns",
            'Multiline')
        if ($newContent -ne $content) {
            Set-Content -Path $_.FullName -Value $newContent -NoNewline
            $updated++
        }
    }
}
Write-Host "`n[[3/5]] Updated namespace in $updated file(s)." -ForegroundColor Cyan

# ── 4. Append missing usings ───────────────────────────────────────────────
#  For each moved file, check whether the types it references live in a
#  different namespace now.  We do a conservative pass: scan for known
#  type names and ensure the required using is present.

$usingMap = [[ordered]]@{
    # Types that appear in many files
    'FileLoadOptions'          = 'Ragnar.Core.Models'
    'CollectionInfo'           = 'Ragnar.VectorStore.Qdrant'
    'GenerationOptions'        = 'Ragnar.Core.Models'
    'EmbeddingOptions'         = 'Ragnar.Core.Models'
    'StageMetric'              = 'Ragnar.Core.Models'
    'StageExecutionContext'    = 'Ragnar.Pipeline'
    'PipelineRunner'           = 'Ragnar.Pipeline'
    'StageEntry'               = 'Ragnar.Pipeline'
    'StageTimingMiddleware'    = 'Ragnar.Pipeline.Middleware'
    'ProgressMiddleware'       = 'Ragnar.Pipeline.Middleware'
    'QuestionPipelineContext'  = 'Ragnar.Pipeline'
    'BrandingStage'            = 'Ragnar.Pipeline.Stages'
    'DeltaEmbedStage'          = 'Ragnar.Pipeline.Stages'
    'IFileDiscoveryService'    = 'Ragnar.FileDiscovery'
    'IFileEligibilityValidator'= 'Ragnar.FileDiscovery'
    'IFileParser'              = 'Ragnar.FileDiscovery'
    'FileDiscoveryService'     = 'Ragnar.FileDiscovery'
    'CodeParserFactory'        = 'Ragnar.FileDiscovery'
    'FileSystemEntryExtensions'= 'Ragnar.FileDiscovery'
    'QdrantFilterBuilder'      = 'Ragnar.VectorStore.Qdrant'
    'QuestionFilterSelector'   = 'Ragnar.VectorStore.Filtering'
    'XmlCommentFilterStrategy' = 'Ragnar.VectorStore.Filtering'
    'IOllamaClientFactory'     = 'Ragnar.Ollama'
    'OllamaChatClientBuilder'  = 'Ragnar.Ollama'
    'QuestionsExtensions'      = 'Ragnar.Questions'
    'EnumConverter'            = 'Ragnar.Questions'
    'JsonFileFingerprintStore' = 'Ragnar.Infrastructure.Fingerprinting'
    'OutputPathHelper'         = 'Ragnar.Infrastructure.Output'
    'EmbeddingSetupExtension'  = 'Ragnar.Composition'
    'FileLoadOptionsValidator' = 'Ragnar.Core.Validation'
}

$usingFixed = 0
Get-ChildItem -Path $Src -Filter '*.cs' -Recurse -File | ForEach-Object {
    $content = Get-Content $_.FullName -Raw
    $nsOfFile = $null
    $nsMatch  = [[regex]]::Match($content, 'namespace\s+([[\w.]]+)')
    if ($nsMatch.Success) { $nsOfFile = $nsMatch.Groups[[1]].Value }

    $missing = [[System.Collections.Generic.List[[string]]]]::new()
    foreach ($entry in $usingMap.GetEnumerator()) {
        $type = $entry.Key
        $ns   = $entry.Value
        # Only care if the file is NOT already in that namespace
        if ($nsOfFile -and $nsOfFile -eq $ns) { continue }
        # Check if the type is actually referenced (word-boundary match)
        if ([[regex]]::IsMatch($content, "\b$type\b")) {
            # Check if the using is already present
            if (-not [[regex]]::IsMatch($content, "using\s+$ns\s*;")) {
                $missing.Add("using $ns;")
            }
        }
    }

    if ($missing.Count -gt 0) {
        # Insert after the last existing using line
        $lastUsing = [[regex]]::Matches($content, 'using\s+[[\w.]]+;') | Select-Object -Last 1
        if ($lastUsing) {
            $insertAt = $lastUsing.Index + $lastUsing.Length
            $newContent = $content.Insert($insertAt, "`r`n" + ($missing -join "`r`n"))
        } else {
            $newContent = ($missing -join "`r`n") + "`r`n`r`n" + $content
        }
        Set-Content -Path $_.FullName -Value $newContent -NoNewline
        $usingFixed++
    }
}
Write-Host "`n[[4/5]] Fixed missing usings in $usingFixed file(s)." -ForegroundColor Cyan

# ── 5. Build ───────────────────────────────────────────────────────────────
Write-Host "`n[[5/5]] Building solution…" -ForegroundColor Cyan
$proj = Get-ChildItem -Path $ProjectRoot -Filter '*.csproj' -Recurse |
    Where-Object { $_.FullName -notmatch '\\(bin|obj)\\' } |
    Select-Object -First 1

if ($proj) {
    Push-Location $proj.DirectoryName
    try {
        & dotnet build --nologo -v q 2>&1 | ForEach-Object { Write-Host $_ }
        if ($LASTEXITCODE -eq 0) {
            Write-Host "`n✔  Build succeeded." -ForegroundColor Green
        } else {
            Write-Warning "`n✘  Build failed – review the output above."
        }
    } finally {
        Pop-Location
    }
} else {
    Write-Warning "No .csproj found under $ProjectRoot – skipping build."
}

Write-Host "`nDone. Review the tree with:" -ForegroundColor White
Write-Host "  tree /f `$ProjectRoot\src`r`n" -ForegroundColor DarkGray
```

## Rationale for the Grouping

| Group | Why it's separate |
|-------|-------------------|
| **Core / Models** | POCO records shared across every layer – no dependencies on Qdrant, Ollama, or the pipeline. Keeps the "domain model" dependency-free. |
| **Pipeline** | All stage-runner, middleware, and stage classes live together. New stages drop into `Stages/`; new cross-cutting concerns drop into `Middleware/`. |
| **FileDiscovery** | Everything related to finding and parsing source files (extension checks, parser factory, eligibility) is isolated so you can swap the parser strategy without touching the pipeline. |
| **VectorStore** | Qdrant-specific types (filter builder, point factory, collection info) and the filtering strategy pattern are grouped. Adding a *different* vector store later means adding a sibling folder, not interleaving types. |
| **Ollama** | Client factory, builder, and API types are self-contained. `EmbeddingOptions` / `GenerationOptions` live in **Core/Models** because they are pure config records used by multiple layers. |
| **Questions** | Extension methods and CSV converters are a small, stable API surface for the `Question` domain. |
| **Infrastructure** | Cross-cutting services (fingerprint store, output-path helpers) that don't belong to a single feature. |
| **Composition** | The single place where all `AddSingleton` / `AddScoped` calls are registered – your "composition root." |

This layout follows the **dependency rule**: *Core → Pipeline / FileDiscovery / VectorStore / Ollama → Composition*. Inner folders never reference outer ones, which keeps the build graph acyclic and makes it trivial to extract any subsystem into its own project later.

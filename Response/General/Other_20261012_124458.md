## 8. C# 13 `extension` Keyword (Preview)

Two files (`ApplicationConfigurationExtensions.cs`, `QuestionCombineBuilderExtensions.cs`, and one `EmbeddingSetupExtension.cs`) use the `extension` keyword:

```csharp
extension(IServiceCollection services) { ... }
extension(QuestionBuilder builder) { ... }
```

This is a **C# 13 / .NET 10 preview** feature. If any consumer of this library targets an earlier language version, these files will fail to compile. Make sure your `<LangVersion>` and target framework are aligned.

## 10. `FilterBuilder.AddRange` — Two Overloads, One Missing Doc


The first overload's summary says **"less-than"** but it's actually a simple `lte`-only helper. The second overload (the real general-purpose one) is the one most callers will hit. The split could confuse readers into thinking the first method does something different from a zero-arg `gte` call.

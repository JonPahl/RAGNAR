## PowerShell Script

Save as `reorganize.ps1` in your project root and run it:

```powershell
#!/usr/bin/env pwsh
<#
.SYNOPSIS
  Reorganizes Ragnar source files into a structured namespace/folder hierarchy.
.DESCRIPTION
  1. Creates the target directory tree under src/.
  2. Moves each .cs file to its new home.
  3. Rewrites the `namespace` declaration to match the folder.
  4. Adds missing `using` directives to files that reference moved types.
  5. Leaves .editorconfig and non-C# files untouched.
#>

[[CmdletBinding()]]
param(
    [[string]]$Root = (Get-Location).Path,
    [[switch]]$DryRun
)

$ErrorActionPreference = 'Stop'
$srcDir = Join-Path $Root 'src'

# ──────────────────────────────────────────────
# 1. Define the mapping: fileName → destination folder
# ──────────────────────────────────────────────
$map = [[ordered]]@{
    # Core / Pipeline
    'PipelineRunner.cs'                 = 'Core\Pipeline'
    'StageMetric.cs'                    = 'Core\Pipeline'

    # Core / Stages
    'BrandingStage.cs'                  = 'Core\Stages'
    'QuestionExecutionStage.cs'         = 'Core\Stages'
    'QuestionShowStage.cs'              = 'Core\Stages'
    'ShowFileStage.cs'                  = 'Core\Stages'

    # Configuration / Models
    'FileLoadOptions.cs'                = 'Configuration\Models'
    'EmbeddingOptions.cs'               = 'Configuration\Models'
    'GenerationOptions.cs'              = 'Configuration\Models'

    # Configuration / Validation
    'RagnarConfigValidator.cs'          = 'Configuration\Validation'
    'FileLoadOptionsValidator.cs'       = 'Configuration\Validation'

    # Embedding
    'EmbeddingGeneratorService.cs'      = 'Embedding'
    'IOllamaClientFactory.cs'           = 'Embedding'
    'GeneratorExtensions.cs'            = 'Embedding'

    # Questions
    'QuestionCombineBuilder.cs'         = 'Questions'
    'QuestionCombineBuilderExtensions.cs' = 'Questions'
    'QuestionPipelineContext.cs'        = 'Questions'
    'QuestionFilterSelector.cs'         = 'Questions'

    # Filters
    'FilterBuilder.cs'                  = 'Filters'
    'XmlCommentFilterStrategy.cs'       = 'Filters'

    # FileProcessing
    'IFileDiscoveryService.cs'          = 'FileProcessing'
    'FileDiscoveryService.cs'           = 'FileProcessing'
    'IFileParser.cs'                    = 'FileProcessing'
    'CodeParserFactory.cs'              = 'FileProcessing'
    'IFileValidator.cs'                 = 'FileProcessing'
    'FileSystemEntryExtensions.cs'      = 'FileProcessing'

    # Rendering
    'NumberedRowDecorator.cs'           = 'Rendering'
    'CollectionInfo.cs'                 = 'Rendering'

    # DI
    'ApplicationConfigurationExtensions.cs' = 'Di'
    'EmbeddingSetupExtension.cs'        = 'Di'

    # Extensions
    'OutputPathHelper.cs'               = 'Extensions'
}

# ──────────────────────────────────────────────
# 2. Create the target directories
# ──────────────────────────────────────────────
$destFolders = $map.Values | Sort-Object -Unique
foreach ($folder in $destFolders) {
    $fullPath = Join-Path $srcDir $folder
    if (-not (Test-Path $fullPath)) {
        if ($DryRun) { Write-Host "[[DRY-RUN]] mkdir $fullPath" }
        else { New-Item -ItemType Directory -Path $fullPath -Force | Out-Null }
        Write-Host "  ✓ created  $folder"
    }
}

# ──────────────────────────────────────────────
# 3. Move files and rewrite namespaces
# ──────────────────────────────────────────────
function ConvertTo-Namespace([[string]]$relativeFolder) {
    # Convert "Core\Pipeline" → "Ragnar.Core.Pipeline"
    $parts = $relativeFolder -split '\\' | Where-Object { $_ }
    return "Ragnar." + ($parts -join '.')
}

$moved = 0
foreach ($entry in $map.GetEnumerator()) {
    $fileName = $entry.Key
    $destFolder = $entry.Value
    $sourcePath = Join-Path $srcDir $fileName
    $destPath   = Join-Path (Join-Path $srcDir $destFolder) $fileName

    # Handle the duplicate EmbeddingSetupExtension.cs (two versions exist)
    if ($fileName -eq 'EmbeddingSetupExtension.cs') {
        # Only move the first one found; skip if already moved
        if (Test-Path $sourcePath) {
            if ($DryRun) { Write-Host "[[DRY-RUN]] move $fileName → $destFolder\$fileName" }
            else {
                # Rewrite namespace
                $content = Get-Content $sourcePath -Raw
                $newNs = ConvertTo-Namespace $destFolder
                $content = $content -replace '^\s*namespace\s+\S+\s*\{', "namespace $newNs {" -replace '^\s*namespace\s+([[\w.]]+)\s*;?\s*$', "namespace $newNs;"
                Set-Content -Path $destPath -Value $content -Encoding utf8
                Remove-Item $sourcePath
            }
            $moved++
            Write-Host "  ✓ moved    $fileName → $destFolder/"
        }
        continue
    }

    if (-not (Test-Path $sourcePath)) {
        Write-Warning "  ! not found  $fileName (skipping)"
        continue
    }

    if ($DryRun) {
        Write-Host "[[DRY-RUN]] move $fileName → $destFolder\$fileName"
    }
    else {
        $content = Get-Content $sourcePath -Raw

        # Rewrite namespace declaration (handles both file-scoped and block style)
        $newNs = ConvertTo-Namespace $destFolder
        if ($content -match 'namespace\s+([[\w.]]+)\s*;') {
            # file-scoped:  namespace Ragnar.Something;
            $content = $content -replace "namespace\s+[[\w.]]+;", "namespace $newNs;"
        }
        elseif ($content -match 'namespace\s+([[\w.]]+)\s*\{') {
            # block-scoped: namespace Ragnar.Something {
            $content = $content -replace "namespace\s+[[\w.]]+\s*\{", "namespace $newNs {"
        }

        Set-Content -Path $destPath -Value $content -Encoding utf8
        Remove-Item $sourcePath
    }

    $moved++
    Write-Host "  ✓ moved    $fileName → $destFolder/"
}

# ──────────────────────────────────────────────
# 4. Patch using directives in all moved files
#    so cross-namespace references resolve.
# ──────────────────────────────────────────────
# Build a type→namespace lookup from the map
$typeNs = @{}
foreach ($entry in $map.GetEnumerator()) {
    $ns = ConvertTo-Namespace $entry.Value
    $baseName = $entry.Key -replace '\.cs$' -replace '^I'   # strip .cs and leading I
    $typeNs[[$entry.Key -replace '\.cs$']] = $ns
    $typeNs[[$baseName]] = $ns
}

# List of well-known types that now live in specific namespaces
$crossRefs = @{
    'PipelineRunner'            = 'Ragnar.Core.Pipeline'
    'StageMetric'               = 'Ragnar.Core.Pipeline'
    'BrandingStage'             = 'Ragnar.Core.Stages'
    'QuestionExecutionStage'    = 'Ragnar.Core.Stages'
    'QuestionShowStage'         = 'Ragnar.Core.Stages'
    'ShowFileStage'             = 'Ragnar.Core.Stages'
    'FileLoadOptions'           = 'Ragnar.Configuration.Models'
    'EmbeddingOptions'          = 'Ragnar.Configuration.Models'
    'GenerationOptions'         = 'Ragnar.Configuration.Models'
    'RagnarConfigValidator'     = 'Ragnar.Configuration.Validation'
    'FileLoadOptionsValidator'  = 'Ragnar.Configuration.Validation'
    'EmbeddingGeneratorService' = 'Ragnar.Embedding'
    'IOllamaClientFactory'      = 'Ragnar.Embedding'
    'GeneratorExtensions'       = 'Ragnar.Embedding'
    'QuestionCombineBuilder'    = 'Ragnar.Questions'
    'QuestionPipelineContext'   = 'Ragnar.Questions'
    'QuestionFilterSelector'    = 'Ragnar.Questions'
    'FilterBuilder'             = 'Ragnar.Filters'
    'XmlCommentFilterStrategy'  = 'Ragnar.Filters'
    'IFileDiscoveryService'     = 'Ragnar.FileProcessing'
    'FileDiscoveryService'      = 'Ragnar.FileProcessing'
    'IFileParser'               = 'Ragnar.FileProcessing'
    'CodeParserFactory'         = 'Ragnar.FileProcessing'
    'IFileValidator'            = 'Ragnar.FileProcessing'
    'FileSystemEntryExtensions' = 'Ragnar.FileProcessing'
    'NumberedRowDecorator'      = 'Ragnar.Rendering'
    'CollectionInfo'            = 'Ragnar.Rendering'
    'ApplicationConfigurationExtensions' = 'Ragnar.Di'
    'EmbeddingSetupExtension'   = 'Ragnar.Di'
    'OutputPathHelper'          = 'Ragnar.Extensions'
}

if (-not $DryRun) {
    $allCs = Get-ChildItem -Path $srcDir -Filter '*.cs' -Recurse
    foreach ($file in $allCs) {
        $content = Get-Content $file.FullName -Raw
        $fileNs  = if ($content -match 'namespace\s+([[\w.]]+)') { $Matches[[1]] } else { $null }

        $usingsToAdd = [[System.Collections.Generic.HashSet[[string]]]]::new([[System.StringComparer]]::OrdinalIgnoreCase)

        foreach ($pair in $crossRefs.GetEnumerator()) {
            $type = $pair.Key
            $ns   = $pair.Value
            # Only add if the type is referenced but the using is missing
            if ($content -match [[regex]]::Escape($type) -and $ns -ne $fileNs -and
                ($content -notmatch "using\s+$([[regex]]::Escape($ns))\s*;")) {
                $usingsToAdd.Add("using $ns;") | Out-Null
            }
        }

        if ($usingsToAdd.Count -gt 0) {
            # Insert after the first existing using line (or after namespace)
            $sorted = $usingsToAdd | Sort-Object
            $usingBlock = ($sorted | ForEach-Object { $_ }) -join "`n"

            if ($content -match '(\s*using\s+[[\w.]]+\s*;\s*\n)') {
                $insertAfter = $Matches[[0]]
                $content = $content -replace [[regex]]::Escape($insertAfter), ($insertAfter + "`n" + $usingBlock)
            }
            else {
                $content = $usingBlock + "`n" + $content
            }

            Set-Content -Path $file.FullName -Value $content -Encoding utf8
            Write-Host "  ✓ patched  $($file.Name)  (+$($usingsToAdd.Count) using)"
        }
    }
}

# ──────────────────────────────────────────────
# 5. Create IFilterStrategy.cs if missing
# ──────────────────────────────────────────────
$filterIface = Join-Path $srcDir 'Filters\IFilterStrategy.cs'
if (-not (Test-Path $filterIface)) {
    $template = @'
namespace Ragnar.Filters;

/// <summary>Contract for question filter strategies keyed by category.</summary>
public interface IFilterStrategy
{
    /// <summary>Gets the question category this strategy handles.</summary>
    QuestionCategory SupportedCategory { get; }

    /// <summary>Creates a configured Qdrant filter.</summary>
    /// <param name="sizeThreshold">Optional size threshold for the filter.</param>
    Qdrant.Client.Grpc.Filter CreateFilter(int sizeThreshold);
}
'@
    if ($DryRun) { Write-Host "[[DRY-RUN]] create $filterIface" }
    else { Set-Content -Path $filterIface -Value $template -Encoding utf8; Write-Host "  ✓ created  Filters\IFilterStrategy.cs" }
}

# ──────────────────────────────────────────────
# 6. Summary
# ──────────────────────────────────────────────
Write-Host ""
Write-Host "══════════════════════════════════════" -ForegroundColor Cyan
Write-Host "  Reorganization complete: $moved files moved." -ForegroundColor Green
Write-Host "  Review `using` directives and build." -ForegroundColor Yellow
Write-Host "══════════════════════════════════════" -ForegroundColor Cyan
```

Expected output looks like:

```

  ✓ created  Core\Stages

  ✓ moved    BrandingStage.cs  → Core\Stages/
```

### Step 2 — Execute for real

```powershell
pwsh ./reorganize.ps1
```

The script will:

| Action | Detail |
|--------|--------|
| Create folders | `Core/Pipeline`, `Core/Stages`, `Configuration/Models`, etc. |
| Move files | Each `.cs` file is moved to its new folder |
| Rewrite namespaces | `namespace Ragnar.Core.Pipeline;` replaces the old namespace |
| Inject `using`s | Cross-namespace references get the correct `using` added |
| Create `IFilterStrategy.cs` | Missing interface is generated in `Filters/` |

### Step 3 — Verify the build

```bash
dotnet build
```

Common issues to fix manually:

- **Duplicate `using`** – the script adds usings idempotently, but if you had a global `using` in `GlobalUsings.cs`, remove the redundant line.
- **Implicit `using` collisions** – if your project uses `ImplicitUsings`, the injected `using` may conflict. Remove the duplicate.
- **`GlobalUsings.cs`** – add a new file:

  ```csharp
  global using Ragnar.Core.Pipeline;
  global using Ragnar.Core.Stages;
  global using Ragnar.Configuration.Models;
  global using Ragnar.Configuration.Validation;
  global using Ragnar.Embedding;
  global using Ragnar.Questions;
  global using Ragnar.Filters;
  global using Ragnar.FileProcessing;
  global using Ragnar.Rendering;
  global using Ragnar.Di;
  global using Ragnar.Extensions;
  ```

  …then you can **remove** the per-file `using` lines the script added, keeping things clean.

## Folder-Responsibility Cheat Sheet

```
Core/Pipeline/          ← "HOW" stages execute (runner, metrics, retry)
Core/Stages/            ← WHAT each stage does (branding, RAG, display)
Configuration/Models/   ← Shape of config data (records, no logic)
Configuration/Validation/ ← Rules that config must satisfy
Embedding/              ← Vector generation + Ollama client abstraction
Questions/              ← Question assembly, filtering, pipeline context
Filters/                ← Qdrant filter construction (strategy pattern)
FileProcessing/         ← File I/O: discovery → validation → parsing
Rendering/              ← Console table / path display helpers
Di/                     ← ServiceCollection extensions (wiring only)
Extensions/             ← Miscellaneous string/path helpers
```

This separation keeps **stages** (behavior) distinct from **models** (data) and **configuration** (rules), makes it easy to add a new pipeline stage without touching the builder, and lets you swap the Ollama embedding service for another provider by replacing only the `Embedding/` folder.

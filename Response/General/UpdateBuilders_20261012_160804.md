## 2. Concrete Problems

### 2a – `QuestionCombineBuilder`

| # | Problem | Where |
|---|---------|-------|
| 1 | **Duplicated CSV logic.** `GetCsvFilesAsync` and `GetCsvFileAsync` contain nearly identical loops. | Both methods |
| 2 | **`AddQuestion(Question)` breaks the fluent contract.** It's a raw sink that bypasses any validation or builder-step. | End of class |
| 3 | **`WithCategoryFilter()` is parameterless and self-referencing.** The name suggests a *filter to apply*; in reality it *clears and re-adds* the internal list. | `WithCategoryFilter` |
| 4 | **`Clear()` returns `bool`** – unconventional for a builder; callers can't chain. | `Clear` |
| 5 | **`Build()` throws on zero questions** – makes it hard to build an "empty then add later" pipeline. | `Build` |
| 6 | **`QuestionBuilder` is a shared mutable instance** injected via constructor. If two builder calls interleave (e.g. in a `foreach`), state leaks between iterations. | `GetFileConfig`, `GetCsv*` |
| 7 | **No async `BuildAsync`** – CSV loading is async but the final build is sync, which is fine, but the API surface is inconsistent. | – |
| 8 | **`sealed` + constructor-injected dependencies** prevents partial/inheritance strategies (e.g. a `TestQuestionCombineBuilder`). | Class declaration |

### 2b – `FilterBuilder`

| # | Problem | Where |
|---|---------|-------|
| 1 | **Two `AddRange` overloads** – one documented as "less-than" (`lt`), the other with `gte`/`lte`. This is a **compile-time conflict** (same signature shape) and confusing. | `AddRange` |
| 2 | **No `OR` (any-of) support.** Qdrant `Filter` supports `Should` lists; the builder only models `Must` / `MustNot`. | `Build` |
| 3 | **`IsEmpty` check in `Build()`** throws a generic `InvalidOperationException` with no guidance on which call to make. | `Build` |
| 4 | **No `Clone()` / `Copy()`** – you can't branch a filter and add different conditions. | – |
| 5 | **No `ToString()` / `Describe()`** for debugging the composed filter. | – |
| 6 | **No async variant** (minor, but `BuildAsync` would be consistent with the rest of the API). | – |

### 2c – DI Registration "Builders"

| # | Problem |
|---|---------|
| 1 | `EmbeddingSetupExtension` exists in **two files** with identical content (duplicate). |
| 2 | The `extension(IServiceCollection services)` syntax is **not valid C#** – extensions are `static` methods on a `static` class. The code as written will not compile. |
| 3 | No **conditional registration** (e.g. "only register if the model is reachable"). |

### 2d – `NumberedRowDecorator` / Table Renderer

| # | Problem |
|---|---------|
| 1 | **Mutates the inner table in-place** (`table.AddColumns`, `table.AddRow`) – calling `Render()` twice doubles the rows. |
| 2 | No idempotency guard. |

## 3. A Unified Builder Abstraction

Before refactoring individual builders, introduce a small generic contract so all builders share the same expectations:

```csharp
// ──────────────────────────────────────────────
//  IBuilder – common surface every builder exposes
// ──────────────────────────────────────────────
public interface IBuilder<out TResult>
{
    /// <summary>Produces the final immutable result.</summary>
    TResult Build();

    /// <summary>Human-readable description for logging / debugging.</summary>
    string Describe();
}

// Async variant for builders whose steps are I/O-bound
public interface IBuilder<out TResult>
{
    Task<TResult> BuildAsync(CancellationToken ct = default);
}
```

> **Why?** Currently every builder reinvents `Build()`, validation, and debugging. A shared contract lets you write a single `BuilderGuard` (validation), `BuilderTracer` (logging), and `BuilderCloner` (copy-on-branch) that works across all of them.

## 4. Refactored `QuestionCombineBuilder`

```csharp
/// <summary>
/// Fluent builder that aggregates questions from multiple sources into a final list.
/// Thread-safe: each instance should be used from a single logical pipeline run.
/// </summary>
public sealed class QuestionCombineBuilder : IBuilder<IReadOnlyList<Question>>
{
    private readonly List<Question> _questions = [[]];
    private readonly IQuestionCatalogLoader _catalogLoader;
    private readonly IQuestionBuilder _questionBuilderFactory; // factory, not instance!
    private readonly IOptions<RagnarConfig> _options;
    private readonly IQuestionSource _questionProvider;

    // ── Constructor: use a FACTORY for QuestionBuilder to avoid shared mutable state ──
    public QuestionCombineBuilder(
        IQuestionSource questionProvider,
        IQuestionCatalogLoader catalogLoader,
        Func<IQuestionBuilder> questionBuilderFactory,   // ← factory, not instance
        IOptions<RagrangConfig> options)
    {
        _questionProvider   = questionProvider;
        _catalogLoader      = catalogLoader;
        _questionBuilderFactory = questionBuilderFactory;
        _options            = options;
    }

    // ──────────────────────────────────────────────
    //  Source-adding steps (fluent, return this)
    // ──────────────────────────────────────────────

    public QuestionCombineBuilder FromCategories()
    {
        var cats = _options.Value.ApplicationOptions.CategoriesToProcess.ToHashSet();
        _questions.AddRange(_catalogLoader.LoadQuestions(enabledOnly: true, cats));
        return this;
    }

    public QuestionCombineBuilder FromFileConfig()
    {
        var fcl = new FileConfigLoader();
        foreach (var cfg in fcl.LoadQuestions())
        {
            _questions.Add(CreateQuestion(cfg));
        }
        return this;
    }

    /// <summary>
    /// Asynchronously loads questions from every CSV file under <paramref name="dir"/>.
    /// </summary>
    public async Task<QuestionCombineBuilder> FromCsvFilesAsync(
        string dir, CancellationToken ct = default)
    {
        if (!Directory.Exists(dir)) return this;

        foreach (var csv in Directory.EnumerateFiles(dir, "*.csv", SearchOption.AllDirectories))
        {
            if (csv.Contains("Summary.csv", StringComparison.OrdinalIgnoreCase))
                continue;

            var configs = await _questionProvider
                .LoadQuestionsAsync(csv, ct).ConfigureAwait(false);
            foreach (var c in configs)
                _questions.Add(CreateQuestion(c));
        }
        return this;
    }

    /// <summary>
    /// Asynchronously loads questions from a single CSV file.
    /// </summary>
    public async Task<QuestionCombineBuilder> FromCsvFileAsync(
        string csvFile, CancellationToken ct = default)
    {
        if (!File.Exists(csvFile)) return this;

        var configs = await _questionProvider
            .LoadQuestionsAsync(csvFile, ct).ConfigureAwait(false);
        foreach (var c in configs)
            _questions.Add(CreateQuestion(c));
        return this;
    }

    /// <summary>Adds a single pre-built question (escape hatch for tests).</summary>
    public QuestionCombineBuilder Add(Question question)
    {
        ArgumentNullException.ThrowIfNull(question);
        _questions.Add(question);
        return this;
    }

    // ──────────────────────────────────────────────
    //  Filtering / mutation (fluent, return this)
    // ──────────────────────────────────────────────

    /// <summary>
    /// Retains only questions whose category is in the configured set.
    /// No-op if the configured set is empty.
    /// </summary>
    public QuestionCombineBuilder WhereInCategories(params QuestionCategory[[]] categories)
    {
        if (categories.Length == 0) return this;
        var set = categories.ToHashSet();
        _questions.RemoveAll(q => !set.Contains(q.Category));
        return this;
    }

    /// <summary>Retains only enabled questions.</summary>
    public QuestionCombineBuilder WhereEnabled()
    {
        _questions.RemoveAll(q => !q.IsEnabled);
        return this;
    }

    /// <summary>Removes all accumulated questions.</summary>
    public QuestionCombineBuilder Clear()
    {
        _questions.Clear();
        return this;
    }

    // ──────────────────────────────────────────────
    //  Build
    // ──────────────────────────────────────────────

    public IReadOnlyList<Question> Build()
    {
        var result = _questions
            .Where(q => q.IsEnabled)
            .OrderBy(q => q.Category.ToString())
            .ThenBy(q => q.Filename)
            .ToList()
            .AsReadOnly();

        if (result.Count == 0)
            throw new InvalidOperationException(
                "QuestionCombineBuilder produced zero questions. " +
                "Check categories, file paths, and CSV sources.");

        return result;
    }

    public Task<IReadOnlyList<Question>> BuildAsync(CancellationToken ct = default)
        => Task.FromResult(Build());

    public string Describe()
        => $"{_questions.Count} question(s) accumulated";

    // ──────────────────────────────────────────────
    //  Private helpers
    // ──────────────────────────────────────────────

    private Question CreateQuestion(FileQuestionConfig cfg)
    {
        // Use a FRESH builder per call – avoids shared-state bugs
        var qb = _questionBuilderFactory();
        return qb
            .WithText(cfg.Text)
            .WithFileName(cfg.Filename)
            .SetCategory(cfg.Category)
            .SetActive(cfg.IsEnabled)
            .Build();
    }
}
```

### Key changes summarised

| Before | After | Why |
|--------|-------|-----|
| `GetCategories()` / `GetFileConfig()` / `GetCsvFilesAsync` | `FromCategories()` / `FromFileConfig()` / `FromCsvFilesAsync` | "From X" reads as *adding a source*; "Get" implies *retrieving a result*. |
| Shared `IQuestionBuilder` instance | `Func<IQuestionBuilder>` factory | Eliminates the shared-mutable-state bug in `foreach` loops. |
| `AddQuestion(Question)` | `Add(Question)` | Shorter, consistent with LINQ-style naming. |
| `WithCategoryFilter()` (parameterless) | `WhereInCategories(params …)` | Explicit, composable, testable. |
| `Clear()` returns `bool` | `Clear()` returns `this` | Chainable. |
| `Build()` throws on empty | Same, but `Describe()` + `WhereEnabled()` give callers a way to *inspect* before building. | Debugging. |
| `GetCsvFilesAsync` + `GetCsvFileAsync` duplication | `FromCsvFilesAsync` delegates to a private `LoadCsvAsync(path)` helper | DRY. |
| No `IBuilder<T>` | Implements `IBuilder<IReadOnlyList<Question>>` | Unified contract. |

## 5. Refactored `FilterBuilder`

```csharp
/// <summary>
/// Fluent builder for composing Qdrant <see cref="Filter"/> expressions.
/// Immutable after <see cref="Build"/> is called.
/// </summary>
public sealed class FilterBuilder : IBuilder<Filter>
{
    private readonly List<Condition>   _must    = [[]];
    private readonly List<Condition>   _mustNot = [[]];
    private readonly List<Condition>   _should  = [[]];   // ← NEW: OR support
    private bool _isBuilt;

    // ── Must (AND-include) ──────────────────────
    public FilterBuilder Must(string field, string value)
        => AddTo(_must, Conditions.MatchKeyword(field, value));

    public FilterBuilder MustRange(string field, double? gte = null, double? lte = null)
    {
        var r = MakeRange(field, gte, lte);
        return AddTo(_must, r);
    }

    public FilterBuilder MustExceptKeywords(string field, params string[[]] keywords)
        => AddTo(_must, new Condition {
            Field = new FieldCondition {
                Key   = field,
                Match = new Match { ExceptKeywords = new RepeatedStrings { Strings = { keywords } } }
            }
        });

    // ── MustNot (AND-exclude) ───────────────────
    public FilterBuilder MustNot(string field, string value)
        => AddTo(_mustNot, Conditions.MatchKeyword(field, value));

    public FilterBuilder MustNotRange(string field, double? gte = null, double? lte = null)
        => AddTo(_mustNot, MakeRange(field, gte, lte));

    // ── Should (OR-include) ─────────────────────  ← NEW
    public FilterBuilder Should(string field, string value)
        => AddTo(_should, Conditions.MatchKeyword(field, value));

    public FilterBuilder ShouldRange(string field, double? gte = null, double? lte = null)
        => AddTo(_should, MakeRange(field, gte, lte));

    // ── Query helpers (readable sugar) ──────────
    public FilterBuilder Between(string field, double min, double max)
        => MustRange(field, gte: min, lte: max);

    public FilterBuilder Equals(string field, string value)
        => Must(field, value);

    // ── Build ───────────────────────────────────
    public Filter Build()
    {
        if (_isBuilt)
            throw new InvalidOperationException("FilterBuilder has already been built.");

        if (_must.Count == 0 && _mustNot.Count == 0 && _should.Count == 0)
            throw new InvalidOperationException(
                "FilterBuilder is empty. Call Must(), MustNot(), or Should() before Build().");

        _isBuilt = true;

        return new Filter
        {
            Must    = [[.. _must]],
            MustNot = [[.. _mustNot]],
            Should  = [[.. _should]]
        };
    }

    // ── Debugging ───────────────────────────────
    public string Describe()
    {
        return $"Filter(Must:{_must.Count}, MustNot:{_mustNot.Count}, Should:{_should.Count})";
    }

    // ── Internals ───────────────────────────────
    private FilterBuilder AddTo(List<Condition> list, Condition c)
    {
        if (_isBuilt)
            throw new InvalidOperationException("Cannot modify a built FilterBuilder.");
        list.Add(c);
        return this;
    }

    private static Condition MakeRange(string field, double? gte, double? lte)
    {
        if (gte is null && lte is null)
            throw new ArgumentException("Provide at least one bound (gte or lte).");

        var range = new Range();
        if (gte is not null) range.Gte = gte.Value;
        if (lte is not null) range.Lte = lte.Value;
        return new Condition { Field = new FieldCondition { Key = field, Range = range } };
    }
}
```

### Key changes

| Before | After |
|--------|-------|
| `AddMatch`, `AddExclusion`, `AddRange`, `AddExceptKeywords`, `AddExclusionRange` (5 methods, inconsistent naming) | `Must`, `MustRange`, `MustExceptKeywords`, `MustNot`, `MustNotRange`, `Should`, `ShouldRange` + sugar `Between`, `Equals` |
| No `Should` (OR) support | Full `Should` list |
| `IsEmpty` + `Build()` throws generic message | `_isBuilt` guard + descriptive message listing the valid entry points |
| No `Describe()` | `Describe()` for logging |
| Duplicate `AddRange` overloads (compile conflict) | Single `MustRange` / `MustNotRange` / `ShouldRange` |
| Mutable after `Build()` | `_isBuilt` flag prevents post-build mutation |

## 6. Fixing the DI Registration Extensions

The current code uses `extension(IServiceCollection services)` which is **not valid C#**. Replace with proper static extension methods:

```csharp
public static class ServiceCollectionExtensions
{
    // ── Embedding pipeline ──────────────────────
    public static IServiceCollection AddEmbeddingPipeline(this IServiceCollection services)
    {
        services.AddSingleton<IEmbeddingService, OllamaEmbeddingGenerator>();
        services.AddSingleton<IQdrantPointFactory, PointStructFactory>();
        services.AddSingleton<IVectorSetup, VectorSetup>();
        services.AddSingleton<IVectorStoreWriter, VectorStoreWriter>();
        return services;
    }

    // ── Question plugin discovery ───────────────
    public static IServiceCollection AddQuestionPlugins(this IServiceCollection services)
    {
        var pluginDir = Path.Join(AppContext.BaseDirectory, "Questions", "Plugins");
        if (!Directory.Exists(pluginDir))
            return services;

        foreach (var dll in Directory.EnumerateFiles(pluginDir, "*.dll"))
        {
            try
            {
                var asm = AssemblyLoadContext.Default.LoadFromAssemblyPath(dll);
                foreach (var type in asm.GetTypes()
                    .Where(t => typeof(IQuestionSource).IsAssignableFrom(t)
                             && t.IsClass
                             && !t.IsAbstract
                             && t.GetConstructor(Type.EmptyTypes) is not null))
                {
                    services.AddTransient(typeof(IQuestionSource), type);
                }
            }
            catch (Exception ex)
            {
                AnsiConsole.MarkupLine($"[[red]]Failed to load plugin: {dll}[[/]]");
                AnsiConsole.MarkupLine($"[[dim]]{ex.Message}[[/]]");
            }
        }
        return services;
    }

    // ── Convenience one-liner ───────────────────
    public static IServiceCollection AddRagnarCore(this IServiceCollection services)
        => services.AddEmbeddingPipeline().AddQuestionPlugins();
}
```

## 7. Fixing `NumberedRowDecorator` (Idempotency)

```csharp
public sealed class NumberedRowDecorator(ITableRenderer inner, string columnHeader = "#") : ITableRenderer
{
    private bool _rendered;

    public ConsoleTableBuilder Table => inner.Table;

    public void Render()
    {
        if (_rendered) throw new InvalidOperationException("NumberedRowDecorator has already rendered.");

        var table = inner.Table;

        if (!table.Columns.Contains(columnHeader, StringComparer.OrdinalIgnoreCase))
            table.AddColumns(columnHeader);

        var existing = table.Rows.Select(r => r.ToArray()).ToList();
        for (var i = 0; i < existing.Count; i++)
        {
            var row = new string[[table.Columns.Count]];
            row[[0]] = (i + 1).ToString();
            Array.Copy(existing[[i]], 0, row, 1, existing[[i]].Length);
            table.AddRow(row.Select(c => new TableCell(c)).ToList());
        }

        _rendered = true;
        inner.Render();
    }
}
```

## 8. Suggested `IQuestionBuilder` (the inner builder)

Since `QuestionBuilder` is referenced but its source isn't in the snippet, here's the shape it *should* have:

```csharp
public interface IQuestionBuilder
{
    IQuestionBuilder WithText(string text);
    IQuestionBuilder WithFileName(string name);
    IQuestionBuilder SetCategory(QuestionCategory category);
    IQuestionBuilder SetActive(bool active);
    IQuestionBuilder WithFilter(Filter filter);
    Question Build();
}

// Default implementation
public sealed class QuestionBuilder : IQuestionBuilder
{
    private string? _text;
    private string? _fileName;
    private QuestionCategory _category;
    private bool _active = true;
    private Filter? _filter;

    public IQuestionBuilder WithText(string text)       { _text = Guard.Against.NullOrEmpty(text); return this; }
    public IQuestionBuilder WithFileName(string name)   { _fileName = name; return this; }
    public IQuestionBuilder SetCategory(QuestionCategory c) { _category = c; return this; }
    public IQuestionBuilder SetActive(bool active)      { _active = active; return this; }
    public IQuestionBuilder WithFilter(Filter filter)   { _filter = filter; return this; }

    public Question Build()
    {
        if (_text is null)
            throw new InvalidOperationException("Question text was not set. Call WithText() first.");

        return new Question
        {
            Text      = _text,
            Filename  = _fileName ?? "unknown",
            Category  = _category,
            IsEnabled = _active,
            Filter    = _filter
        };
    }
}
```

Register it as a **transient** service (fresh instance per call) or use a factory:

```csharp
services.AddTransient<IQuestionBuilder, QuestionBuilder>();
// or
services.AddSingleton<Func<IQuestionBuilder>>(sp => sp.GetRequiredService<IQuestionBuilder>());
```

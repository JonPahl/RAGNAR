To build a cross-platform MAUI Blazor Hybrid application targeting Windows, macOS, and Linux in .NET 10/C# 14, you leverage the unified `.NET MAUI` SDK with `BlazorWebView`, platform-specific conditionals for native hooks, and C# 14's new **Extension Members** (`extension`) to cleanly surface platform capabilities without polluting core logic.

### 1. Project Configuration (`.csproj`)
.NET 10 MAUI supports Linux via the SkiaSharp/GTK backend. Multi-targeting ensures shared UI/code runs everywhere while native hooks remain isolated.

```xml
<Project Sdk="Microsoft.NET.Sdk">
  <PropertyGroup>
    <TargetFrameworks>net10.0-windows;net10.0-maccatalyst;net10.0-linux-x64</TargetFrameworks>
    <OutputType>Exe</OutputType>
    <Nullable>enable</Nullable>
    <ImplicitUsings>enable</ImplicitUsings>
    <UseMaui>true</UseMaui>
    <BlazorHybrid>true</BlazorHybrid>
    <!-- Explicitly enable Linux GTK backend -->
    <EnableLinuxSupport>true</EnableLinuxSupport>
    <SupportedOSPlatformVersion Condition="$([[MSBuild]]::GetTargetPlatformIdentifier('$(TargetFramework)')) == 'windows'">10.0.17763.0</SupportedOSPlatformVersion>
    <SupportedOSPlatformVersion Condition="$([[MSBuild]]::GetTargetPlatformIdentifier('$(TargetFramework)')) == 'maccatalyst'">15.0</SupportedOSPlatformVersion>
    <SupportedOSPlatformVersion Condition="$([[MSBuild]]::GetTargetPlatformIdentifier('$(TargetFramework)')) == 'linux'">0.0</SupportedOSPlatformVersion>
  </PropertyGroup>

  <ItemGroup>
    <PackageReference Include="Microsoft.Maui.Controls" Version="10.0.0-preview.4" />
    <PackageReference Include="Microsoft.Extensions.Logging.Console" Version="10.0.0" />
  </ItemGroup>
</Project>
```

### 2. Platform Services & C# 14 Extension Members
Use `extension` members to attach platform-aware logic directly to base types without inheritance or wrapper classes. Demonstrate lambda parameter modifiers (`in`, `ref`, `out`) for zero-allocation delegates.

```csharp
// PlatformInfo.cs
public sealed record PlatformState(
    string OSName, 
    string Architecture, 
    string BaseDirectory, 
    bool IsDesktop, 
    DateTime Uptime);

// PlatformExtensions.cs (C# 14 Extension Members)
public static class PlatformExtensions
{
    extension(MauiAppBuilder builder)
    {
        /// <summary>Registers platform-specific lifecycle hooks.</summary>
        public MauiAppBuilder ConfigureNativeLifecycle() => builder.ConfigureLifecycleEvents(lifecycle =>
        {
#if WINDOWS
            lifecycle.AddWindows(windows => windows.OnWindowCreated(window => window.Activate()));
#elif MACCATALYST
            lifecycle.AddMacCatalyst(mac => mac.OnAppStarting(app => 
                Console.WriteLine("🍏 macOS Catalyst initialized")));
#endif
        });
    }

    extension(string rawPath)
    {
        /// <summary>Resolves a safe, platform-agnostic application directory.</summary>
        public string ToSafeDirectory => Path.Combine(
            Environment.GetFolderPath(Environment.SpecialFolder.ApplicationData),
            "RagnarBlazorApp",
            rawPath.TrimStart('/', '\\')
        );
    }

    /// <summary>Provides high-performance platform metadata resolution.</summary>
    public static class Resolvers
    {
        // C# 14 lambda parameter modifiers: 'in' avoids copies, 'out' returns via delegate
        public static readonly Func<in string, out PlatformState> ResolvePlatform = (path, out var state) =>
        {
            state = new(
                OSName: Environment.OSVersion.ToString(),
                Architecture: RuntimeInformation.ProcessArchitecture.ToString(),
                BaseDirectory: path.ToSafeDirectory,
                IsDesktop: !RuntimeInformation.IsOSPlatform(OSPlatform.Android) && 
                            !RuntimeInformation.IsOSPlatform(OSPlatform.iOS),
                Uptime: DateTime.UtcNow - Process.GetCurrentProcess().StartTime.ToUniversalTime()
            );
            return state;
        };

        // 'ref' modifier for mutable context sharing in delegates
        public static readonly Action<ref PlatformState> EnrichMetrics = ref (state) =>
        {
            GC.GetTotalMemory(false); // Simulate metric collection
        };
    }
}
```

### 3. MAUI Blazor Host Configuration
Wire up Blazor Hybrid, register services, and apply C# 14 extension calls.

```csharp
// MauiProgram.cs
public static class MauiProgram
{
    public static MauiApp CreateMauiApp()
    {
        var builder = MauiApp.CreateBuilder();
        builder
            .UseMauiApp<App>()
            .ConfigureFonts(fonts => fonts.AddFont("Inter-Regular.ttf", "InterRegular"));

        // C# 14 extension member invocation
        builder.ConfigureNativeLifecycle();

        builder.Services.AddMauiBlazorWebView();
#if DEBUG
        builder.Services.AddBlazorWebViewDeveloperTools();
#endif

        builder.Services.AddSingleton<PlatformState>(sp => 
            PlatformExtensions.Resolvers.ResolvePlatform(
                Environment.GetFolderPath(Environment.SpecialFolder.ApplicationData), 
                out var state).Value);

        return builder.Build();
    }
}
```

### 5. Linux Build & Execution Prerequisites
MAUI on Linux relies on GTK3 and SkiaSharp. Ensure your OS meets these dependencies before building:

**Ubuntu/Debian:**
```bash
sudo apt-get update
sudo apt-get install -y libgtk-3-dev libskia2a0v5 libfreetype6 libfontconfig1 libpango-1.0-0 libcairo2
```

**Fedora/RHEL:**
```bash
sudo dnf install gtk3-devel freetype fontconfig pango cairo
```

**Build & Run Commands:**
```bash
# Install MAUI workload (if not already present)
dotnet workload install maui-desktop

# Build for Linux
dotnet build -f net10.0-linux-x64 -c Release

# Execute (requires desktop session or Wayland/X11)
dotnet run -f net10.0-linux-x64
```

### Key C# 14 / .NET 10 Features Applied
1. **Extension Members (`extension(Type)`)**: Used to attach `ConfigureNativeLifecycle()` to `MauiAppBuilder`, `ToSafeDirectory` to `string`, and `EnrichMetrics` to `PlatformState`. Keeps domain logic decoupled from host initialization.
2. **Lambda Parameter Modifiers**: Demonstrated `in string` (readonly span behavior for delegates), `out PlatformState` (tuple-style return without allocation), and `ref PlatformState` (mutable context sharing in action delegates).
3. **Record Primary Constructors & Collection Expressions**: Used throughout `PlatformState`, state resolution, and DI registration for concise, immutable data flow.
4. **Blazor Hybrid Architecture**: `BlazorWebViewHost` bridges the Razor component model with native MAUI controls. No headless server required; renders natively on each target OS using WebKit (Mac), Win2D/Chromium (Windows), or GTK/Skia (Linux).

This architecture ensures a single codebase compiles to true native binaries for Windows, macOS, and Linux while maintaining high-performance memory allocation patterns via C# 14's extension and lambda capabilities.

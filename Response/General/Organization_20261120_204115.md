## PowerShell Reorganization Script

Save this as `Reorganize-Ragnar.ps1` and run from the `Src/Ragnar/` directory:

```powershell
#Requires -Version 7.3
<#
.SYNOPSIS
    Reorganizes the Ragnar project into a structured folder/namespace layout.
.DESCRIPTION
    Moves files into logical folders, updates namespace declarations,
    and adds using directives where needed.
    Run from: Src\Ragnar\
#>

[[CmdletBinding(SupportsShouldProcess = $true, ConfirmImpact = 'High')]]
param(
    [[string]]$Root = (Get-Location).Path
)

$ErrorActionPreference = 'Stop'

# ──────────────────────────────────────────────
# 1. Define the target structure: folder → files
# ──────────────────────────────────────────────
$map = [[ordered]]@{
    'Configuration' = @(
        'QuestionConfig.cs'
        'EmbeddingOptionsValidator.cs'
    )
    'Context' = @(
        'EmbeddingContext.cs'
    )
    'Pipeline' = @(
        'IPipeline.cs'
        'IPipelineStage.cs'
        'Pipeline.cs'
    )
    'Stages\Embedding' = @(
        'StoredFileListStage.cs'
        'VectorStoreInitStage.cs'
    )
    'Stages\Question' = @(
        'SummarizationStage.cs'
        'QuestionTableStage.cs'
    )
    'Questions' = @(
        'IQuestionSource.cs'
        'IQuestionBuilder.cs'
        'IQuestionCatalogLoader.cs'
        'QuestionAggregator.cs'
        'QuestionFilterSelector.cs'
    )
    'RAG' = @(
        'IRagPromptBuilder.cs'
        'IContextRetriever.cs'
        'SummarizePromptProvider.cs'
    )
    'Embedding' = @(
        'OllamaEmbeddingGenerator.cs'
        'IQdrantPointFactory.cs'
    )
    'VectorStore' = @(
        'IVectorSetup.cs'
        'CollectionInfo.cs'
    )
    'Parsing' = @(
        'MarkdownFileParser.cs'
        'IFileParseFactory.cs'
    )
    'Ollama' = @(
        'OllamaClientFactory.cs'
        'IOllamaChatClientBuilder.cs'
    )
    'Middleware' = @(
        'MetricsSummaryMiddleware.cs'
    )
    'Services' = @(
        'RagPipelineRunner.cs'
        'ISqlLiteDbService.cs'
    )
    'UI' = @(
        'IOutputWriter.cs'
        'IBranding.cs'
    )
    'Extensions' = @(
        'PathExtensions.cs'
        'StopwatchExtensions.cs'
        'StylesExtensions.cs'
    )
    'Resources' = @(
        'Resources.Designer.cs'
    )
}

# ──────────────────────────────────────────────
# 2. Helper: map folder → namespace
# ──────────────────────────────────────────────
function Get-Namespace {
    param([[string]]$Folder)
    $parts = $Folder.Split('\')
    return "Ragnar." + ($parts -join '.')
}

# ──────────────────────────────────────────────
# 3. Create all target directories
# ──────────────────────────────────────────────
foreach ($folder in $map.Keys) {
    $fullPath = Join-Path $Root $folder
    if (-not (Test-Path $fullPath) -and $PSCmdlet.ShouldProcess($fullPath, 'Create directory')) {
        New-Item -ItemType Directory -Path $fullPath -Force | Out-Null
        Write-Host "  [[DIR]] $folder" -ForegroundColor Cyan
    }
}

# ──────────────────────────────────────────────
# 4. Move files and rewrite namespaces
# ──────────────────────────────────────────────
$movedCount = 0
foreach ($folder in $map.Keys) {
    $destDir = Join-Path $Root $folder
    $ns = Get-Namespace -Folder $folder

    foreach ($file in $map[[$folder]]) {
        $srcPath = Join-Path $Root $file
        $destPath = Join-Path $destDir $file

        # Skip if file doesn't exist at root
        if (-not (Test-Path $srcPath)) {
            Write-Warning "  [[SKIP]] $file not found at project root"
            continue
        }

        # Skip if already in place
        if (Test-Path $destPath) {
            Remove-Item $srcPath -Force
            continue
        }

        if ($PSCmdlet.ShouldProcess($srcPath, "Move to $folder/$file")) {
            Move-Item -Path $srcPath -Destination $destPath -Force

            # Rewrite namespace in the moved file
            $content = Get-Content $destPath -Raw
            # Replace any existing namespace declaration
            $content = $content -replace '(?m)^namespace\s+[[\w.]]+(\s*\{)', "namespace $ns {"
            # If there's no namespace block, insert one before the first type
            if ($content -notmatch "namespace\s+$ns") {
                # Insert namespace wrapper
                $content = "namespace $ns`n{`n" + $content + "`n}`n"
            }
            Set-Content -Path $destPath -Value $content -NoNewline

            Write-Host "  [[MOV]] $file → $folder/" -ForegroundColor Green
            $movedCount++
        }
    }
}

Write-Host "`n  Moved $movedCount file(s)." -ForegroundColor Yellow

# ──────────────────────────────────────────────
# 5. Add using directives to all .cs files
# ──────────────────────────────────────────────
$allNamespaces = $map.Keys | ForEach-Object { Get-Namespace -Folder $_ }
# Always include core namespaces
$allNamespaces += @('Ragnar', 'Ragnar.Models', 'Ragnar.Context', 'Ragnar.Configuration')

Write-Host "`n  Scanning for missing using directives..." -ForegroundColor Cyan

$allCsFiles = Get-ChildItem -Path $Root -Filter '*.cs' -Recurse |
    Where-Object { $_.Name -ne 'AssemblyInfo.cs' }

foreach ($csFile in $allCsFiles) {
    $content = Get-Content $csFile.FullName -Raw
    $fileDir = $csFile.DirectoryName.Replace($Root, '').TrimStart('\')
    $ownNs = Get-Namespace -Folder $fileDir

    $missing = @()
    foreach ($ns in $allNamespaces) {
        if ($ns -eq $ownNs -or $ns -eq 'Ragnar') { continue }
        if ($content -notmatch [[regex]]::Escape("using $ns;")) {
            $missing += "using $ns;"
        }
    }

    if ($missing.Count -gt 0) {
        # Insert usings after existing using block or before first namespace
        $usingBlock = ($missing | Sort-Object) -join "`n"
        $content = $content -replace '(?m)^using\s+.*;\s*$', "`$0`n$usingBlock"
        Set-Content -Path $csFile.FullName -Value $content -NoNewline
        Write-Host "  [[USE]] $fileDir/$($csFile.Name) + $($missing.Count) using(s)" -ForegroundColor DarkGray
    }
}

# ──────────────────────────────────────────────
# 6. Update .csproj if needed (Resources path)
# ──────────────────────────────────────────────
$csproj = Join-Path $Root 'Ragnar.csproj'
if (Test-Path $csproj) {
    $projContent = Get-Content $csproj -Raw
    $projContent = $projContent -replace 'Resources\.Designer\.cs', 'Resources\Resources.Designer.cs'
    $projContent = $projContent -replace 'Resources\.resx', 'Resources\Resources.resx'
    Set-Content -Path $csproj -Value $projContent -NoNewline
    Write-Host "  [[CSP]] Updated Ragnar.csproj resource paths." -ForegroundColor Cyan
}

# ──────────────────────────────────────────────
# 7. Summary
# ──────────────────────────────────────────────
Write-Host "`n═══════════════════════════════════════" -ForegroundColor White
Write-Host "  Reorganization complete." -ForegroundColor Green
Write-Host "  Review namespaces in each file, then run:" -ForegroundColor Yellow
Write-Host "    dotnet build" -ForegroundColor Yellow
Write-Host "═══════════════════════════════════════" -ForegroundColor White
```

### Phase 3 — Fix namespaces and usings

For **every file you moved**, update two things:

1. **Namespace declaration** — change to match the folder:
   ```csharp
   // Before
   namespace Ragnar
   {
   // After
   namespace Ragnar.Stages.Embedding
   {
   ```

2. **Using directives** — add cross-namespace references. Most files will need a combination of:
   ```csharp
   using Ragnar.Models;
   using Ragnar.Context;
   using Ragnar.Configuration;
   ```

## Rationale Summary

| Decision | Why |
|---|---|
| **Folder mirrors namespace** (`Ragnar.Stages.Embedding` → `Stages/Embedding/`) | Eliminates cognitive overhead; VS "Go to Definition" and solution explorer align. |
| **Stages split by pipeline** | `EmbeddingContext` and `QuestionPipelineContext` are unrelated state machines; co-locating their stages prevents accidental coupling. |
| **`RAG/` separate from `Embedding/`** | RAG = retrieval + prompt + answer; Embedding = vector generation. They have different dependencies (Ollama LLM vs Ollama embedding model). |
| **`Questions/` as its own namespace** | Question lifecycle (load → filter → build → aggregate) is a self-contained sub-system with its own builder pattern. |
| **`Middleware/` flat** | All five middlewares operate on the same `StageExecutionContext<T>` contract; no need for sub-folders. |
| **`Extensions/` for static helpers** | `PathExtensions`, `StopwatchExtensions`, `StylesExtensions` are all `static class` + extension methods; grouping them keeps the root clean. |
| **`Configuration/` includes validators** | `EmbeddingOptionsValidator` is tightly coupled to `EmbeddingOptions`; keeping them together makes `FluentValidation` auto-discovery obvious. |

This structure scales well: if you add a `WebApi/` project later, it can reference `Ragnar.Core` (the library containing everything above) without pulling in hosted-service or DI specifics.

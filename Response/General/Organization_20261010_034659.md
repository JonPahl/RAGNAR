## Step-by-Step Guide

### Step 1 — Snapshot the current state

```powershell
# From the repo root (or wherever .cs files live)
Get-ChildItem -Recurse -Filter *.cs | Sort-Object FullName |
    ForEach-Object { "$($_.Directory.FullName)\$($_.Name)" }
```

Save the output to a text file so you can diff later.

### Step 2 — Create the new folder tree

Run the PowerShell script below (see **Script** section). It creates every directory, moves each file into its target folder, and rewrites the `namespace` line.

### Step 3 — Update `.csproj` (if needed)

If your `.csproj` explicitly lists source files (not the default SDK-style `<Compile>` glob), add the new paths. With an SDK-style project the `**/*.cs` glob picks everything up automatically — no change needed.

### Step 4 — Fix `using` directives

After the move, every file that references a type in a *different* new namespace will need a `using` added. The script handles the obvious cases; for the rest:

1. **Build the project.**
2. Sort errors by `CS0246` (type not found).
3. For each missing type, add the correct `using Ragnar.<Domain>.<SubDomain>;`.

> **Tip:** Enable IDE0005 (unused-using) and IDE0073 (file-scoped namespace) as *suggestions* so the editor cleans up as you go.

### Step 5 — Update DI registration

Create a single entry-point method in `Configuration/Registration/ServiceRegistration.cs`:

```csharp
namespace Ragnar.Configuration.Registration;

{
    public static IServiceCollection AddRagnar(this IServiceCollection services, RagnarConfig config)

        // --- Rag / Pipeline ---
```

## PowerShell Reorganization Script

> **Save as `Reorganize-Ragnar.ps1`** and run from the project root.
> It is **idempotent** — safe to re-run.
> Adjust the `$Root` path at the top.

```powershell
#Requires -Version 7.3
# Reorganize-Ragnar.ps1
# Moves .cs files into a domain-based folder structure and rewrites namespaces.

[[CmdletBinding(SupportsShouldProcess)]]
param(
    [[string]]$Root = (Get-Location).Path   # project root
)

# ──────────────────────────────────────────────
# 1.  Map:  source-file-basename → target relative folder
# ──────────────────────────────────────────────
$map = [[ordered]]@{

    # Core / Models
    'Question.cs'                  = 'Core/Models'
    'QuestionCategory.cs'          = 'Core/Models'
    'CodeDocument.cs'              = 'Core/Models'
    'ResponseRecord.cs'            = 'Core/Models'
    'CollectionInfo.cs'            = 'Core/Models'
    'StageMetric.cs'               = 'Core/Models'

    # Core / Options
    'RagnarConfig.cs'              = 'Core/Options'
    'ApplicationOptions.cs'        = 'Core/Options'
    'EmbeddingOptions.cs'          = 'Core/Options'
    'OllamaOptions.cs'             = 'Core/Options'
    'FileLoadOptions.cs'           = 'Core/Options'
    'GenerationOptions.cs'         = 'Core/Options'

    # Core / Constants
    'AppDefaults.cs'               = 'Core/Constants'

    # Pipeline
    'IPipelineStage.cs'            = 'Pipeline'
    'PipelineRunner.cs'            = 'Pipeline'
    'PipelineStageEntry.cs'        = 'Pipeline'
    'PipelineStageException.cs'    = 'Pipeline'
    'EmbeddingContext.cs'          = 'Pipeline/Contexts'
    'QuestionPipelineContext.cs'   = 'Pipeline/Contexts'

    # Pipeline / Stages
    'BrandingStage.cs'             = 'Pipeline/Stages'
    'ShowFileStage.cs'             = 'Pipeline/Stages'
    'QuestionShowStage.cs'         = 'Pipeline/Stages'
    'QuestionExecutionStage.cs'    = 'Pipeline/Stages'

    # Rag
    'IRagOrchestrator.cs'          = 'Rag'
    'RagOrchestrator.cs'           = 'Rag'
    'IContextRetriever.cs'         = 'Rag'

    # Embedding
    'IEmbeddingService.cs'         = 'Embedding'
    'EmbeddingGeneratorService.cs' = 'Embedding'
    'GeneratorExtensions.cs'       = 'Embedding'

    # VectorStore
    'IQdrantPointFactory.cs'       = 'VectorStore'
    'PointStructFactory.cs'        = 'VectorStore'
    'IVectorSetup.cs'              = 'VectorStore'
    'VectorSetup.cs'               = 'VectorStore'
    'IVectorStoreWriter.cs'        = 'VectorStore'
    'VectorStoreWriter.cs'         = 'VectorStore'
    'FilterBuilder.cs'             = 'VectorStore'

    # Questions
    'IQuestionSource.cs'           = 'Questions'
    'IQuestionSourceBuilder.cs'    = 'Questions'
    'IQuestionBuilder.cs'          = 'Questions'
    'IQuestionCatalogLoader.cs'    = 'Questions'
    'QuestionCombineBuilder.cs'    = 'Questions'
    'QuestionCombineBuilderExtensions.cs' = 'Questions'
    'QuestionFilterSelector.cs'    = 'Questions'
    'IFilterStrategy.cs'           = 'Questions'
    'XmlCommentFilterStrategy.cs'  = 'Questions/Strategies'

    # FileDiscovery
    'IFileDiscoveryService.cs'     = 'FileDiscovery'
    'FileDiscoveryService.cs'      = 'FileDiscovery'
    'IFileParser.cs'               = 'FileDiscovery'
    'IFileParseFactory.cs'         = 'FileDiscovery'
    'IFileValidator.cs'            = 'FileDiscovery'
    'CodeParserFactory.cs'         = 'FileDiscovery'
    'ISyntaxTreeChunker.cs'        = 'FileDiscovery'
    'ParseCSharpFile.cs'           = 'FileDiscovery'

    # Ollama
    'IOllamaApiClient.cs'          = 'Ollama'
    'IOllamaClientFactory.cs'      = 'Ollama'
    'IOllamaGenerationService.cs'  = 'Ollama'
    'OllamaClientFactory.cs'       = 'Ollama'
    'OllamaGenerationService.cs'   = 'Ollama'
    'OllamaServiceType.cs'         = 'Ollama'

    # Output
    'IResponseWriter.cs'           = 'Output'
    'SummarizeSaveResponse.cs'     = 'Output'
    'IOutputWriter.cs'             = 'Output'
    'OutputPathHelper.cs'          = 'Output'
    'ITableRenderer.cs'            = 'Output/TableRendering'
    'TableRendererFactory.cs'      = 'Output/TableRendering'
    'NumberedRowDecorator.cs'      = 'Output/TableRendering'

    # Configuration / Validators
    'RagnarConfigValidator.cs'         = 'Configuration/Validators'
    'ApplicationOptionsValidator.cs'   = 'Configuration/Validators'
    'EmbeddingOptionsValidator.cs'     = 'Configuration/Validators'
    'OllamaOptionsValidator.cs'        = 'Configuration/Validators'
    'FileLoadOptionsValidator.cs'      = 'Configuration/Validators'

    # Configuration / Registration
    'ApplicationConfigurationExtensions.cs' = 'Configuration/Registration'
    'EmbeddingSetupExtension.cs'           = 'Configuration/Registration'

    # Ui
    'IApplicationHeader.cs'        = 'Ui'
    'ApplicationHeader.cs'         = 'Ui'
    'Styles.cs'                    = 'Ui'

    # Extensions (cross-cutting)
    'AssemblyExtensions.cs'        = 'Extensions'
    'FileSystemEntryExtensions.cs' = 'Extensions'
}

# ──────────────────────────────────────────────
# 2.  Create all target directories
# ──────────────────────────────────────────────
foreach ($dir in $map.Values | Select-Object -Unique) {
    $full = Join-Path $Root $dir
    if (-not (Test-Path $full)) {
        if ($PSCmdlet.ShouldProcess($full, 'Create directory')) {
            New-Item -ItemType Directory -Path $full -Force | Out-Null
            Write-Host "  [[+]] Created  $dir" -ForegroundColor Green
        }
    }
}

# ──────────────────────────────────────────────
# 3.  Move each file & rewrite its namespace
# ──────────────────────────────────────────────
$moved = 0; $skipped = 0

foreach ($fileName in $map.Keys) {
    $src = Join-Path $Root $fileName          # current flat location
    $targetDir = $map[[$fileName]]
    $dst = Join-Path (Join-Path $Root $targetDir) $fileName

    if (-not (Test-Path $src)) {
        # Maybe already moved, or never existed — skip silently
        $skipped++
        continue
    }

    if ($src -eq $dst) { $skipped++; continue }

    if ($PSCmdlet.ShouldProcess($src, "→ $dst")) {
        Move-Item -Path $src -Destination $dst -Force

        # Rewrite the first 'namespace ...' line
        $content = Get-Content $dst -Raw
        $newNs = "Ragnar.$($targetDir -replace '/', '.')"
        $content = $content -replace '^\s*namespace\s+[[\w.]]+\s*\{?', "namespace $newNs
{"
        if ($content -match '^\s*namespace\s+[[\w.]]+$') {
            # file-scoped namespace (C# 10+)
            $content = $content -replace '^\s*namespace\s+[[\w.]]+', "namespace $newNs"
        }
        Set-Content -Path $dst -Value $content -NoNewline

        Write-Host "  [[~]] Moved    $fileName  →  $targetDir\" -ForegroundColor Cyan
        $moved++
    }
}

# ──────────────────────────────────────────────
# 4.  Suggest a GlobalUsings.cs
# ──────────────────────────────────────────────
$globalUsings = @'
// GlobalUsings.cs  –  auto-generated by Reorganize-Ragnar.ps1
global using Ragnar.Core.Models;
global using Ragnar.Core.Options;
global using Ragnar.Core.Constants;
global using Ragnar.Pipeline;
global using Ragnar.Pipeline.Contexts;
global using Ragnar.Pipeline.Stages;
global using Ragnar.Rag;
global using Ragnar.Embedding;
global using Ragnar.VectorStore;
global using Ragnar.Questions;
global using Ragnar.Questions.Strategies;
global using Ragnar.FileDiscovery;
global using Ragnar.Ollama;
global using Ragnar.Output;
global using Ragnar.Output.TableRendering;
global using Ragnar.Configuration.Validators;
global using Ragnar.Configuration.Registration;
global using Ragnar.Ui;
global using Ragnar.Extensions;
'@

$gu = Join-Path $Root 'GlobalUsings.cs'
if ($PSCmdlet.ShouldProcess($gu, 'Write GlobalUsings.cs')) {
    Set-Content -Path $gu -Value $globalUsings
    Write-Host "  [[+]] Created  GlobalUsings.cs" -ForegroundColor Green
}

# ──────────────────────────────────────────────
# 5.  Summary
# ──────────────────────────────────────────────
Write-Host ""
Write-Host "──────────────────────────────────────" -ForegroundColor DarkGray
Write-Host "  Moved:   $moved"  -ForegroundColor Cyan
Write-Host "  Skipped: $skipped (already in place or missing)" -ForegroundColor DarkGray
Write-Host "──────────────────────────────────────" -ForegroundColor DarkGray
Write-Host ""
Write-Host "Next steps:" -ForegroundColor Yellow
Write-Host "  1. dotnet build" -ForegroundColor White
Write-Host "  2. Fix any CS0246 (missing using) errors" -ForegroundColor White
Write-Host "  3. git add -p && git commit -m 'refactor: reorganise into domain namespaces'" -ForegroundColor White
```

## Rationale for each grouping

| Domain | Why it's isolated | Key types |
|---|---|---|
| **Core** | No dependencies on any other domain; everything references it | `Question`, `RagnarConfig`, `AppDefaults` |
| **Pipeline** | Orchestration engine + stages; depends on Core + every other domain | `PipelineRunner`, `*Stage` |
| **Rag** | The "ask the LLM" concern; depends on Ollama + Core | `RagOrchestrator`, `IContextRetriever` |
| **Embedding** | Vector generation; depends on Ollama + Core | `EmbeddingGeneratorService` |
| **VectorStore** | Qdrant-specific I/O; depends on Embedding + Core | `FilterBuilder`, `VectorStoreWriter` |
| **Questions** | Question loading/building/filtering; depends on Core | `QuestionCombineBuilder`, strategies |
| **FileDiscovery** | Finding & parsing source files; depends on Core | `FileDiscoveryService`, `CodeParserFactory` |
| **Ollama** | Thin HTTP client wrappers; depends on Core only | `IOllamaApiClient`, factory |
| **Output** | Console/file writing & table rendering; depends on Core | `SummarizeSaveResponse`, decorators |
| **Configuration** | FluentValidation + DI registration; depends on Core + everything | validators, `ServiceRegistration` |
| **Ui** | Branding, header, color constants | `ApplicationHeader` |
| **Extensions** | Stateless `static class` helpers that cross domains | `AssemblyExtensions`, `FileSystemEntryExtensions` |

This layout makes it easy to extract any one domain into its own class library later (e.g., `Ragnar.Embedding.dll`) because the dependency arrows all point **downward** toward `Core`.

# Ragnar

> **R**epository **A**ugmented **G**enerator & **R**esolver

Smart, recursive code reasoning — from query to solution.

Ragnar is a local-first RAG (Retrieval-Augmented Generation) pipeline for C#/.NET repositories. It ingests your source code, embeds it into a vector store, and answers developer questions by retrieving relevant context and synthesizing responses via a local LLM — no data ever leaves your machine.

---

## ✨ Features

- **Local-only inference** — powered by [[Ollama]](https://ollama.com) (LLM + embeddings); no cloud API keys required
- **Pipeline architecture** — composable stages (Discovery → Parsing → Embedding → Question Execution) with per-stage timing and cancellation
- **CSV-driven questions** — load, filter, and batch-execute questions from CSV files organized by category
- **Category-aware filtering** — pluggable `IFilterStrategy` implementations (e.g., XML comment size thresholds, test-category exclusion)
- **Progress UI** — real-time Spectre.Console progress bars and styled tables in the terminal
- **Structured output** — responses saved as timestamped Markdown files, organized into per-category subdirectories
- **Fluent validation** — configuration validated at startup with actionable error messages
- **Extensible providers** — add new question sources (CSV, JSON, database) by implementing `IQuestionProvider`

## 🚀 Getting Started

### Prerequisites

| Dependency | Version / Notes |
|---|---|
| **.NET SDK** | 9.0+ |
| **Ollama** | Latest — provides LLM & embedding models |
| **Qdrant** | Any recent release (Docker or standalone) |
| **A C# repository** | The source directory to index |

### 1. Install & pull Ollama models

```bash
# Install Ollama (https://ollama.com)
curl -fsSL https://ollama.com/install.sh | sh

# Pull the LLM and embedding models (or configure your own in appsettings.json)
ollama pull qwen3.8
ollama pull nomic-embed-text
```

### 2. Start Qdrant

```bash
# Docker (quick start)
docker run -p 6334:6333 -v qdrant_storage:/qdrant/storage qdrant/qdrant

# Or build & run the local project
cd Ragnar.Embedding
dotnet run --project Qdrant
```

### 3. Configure

Copy and edit the application settings:

```bash
# appsettings.json          →  global defaults (models, ports, extensions, exclusions)
# appsettings.Ragnar.json   →  your machine-specific paths (SourceDirectory, VectorStoreName)
```

Key configuration sections:

```jsonc
{
  "RagnarConfig": {
    "ApplicationOptions": {
      "SourceDirectory": "%USERPROFILE%\\source\\MyRepo\\",   // ← point at your code
      "VectorStoreName": "programming_docs",
      "OutputFolder": "Response",
      "CategoriesToProcess": [[]],          // empty = all categories
      "IncludeOriginalPrompt": false
    },
    "OllamaOptions": {
      "Host": "localhost",
      "Port": 11434,
      "LlmModel": "qwen3.8",
      "Timeout": "00:30:00"
    },
    "EmbeddingOptions": {
      "Host": "localhost",
      "Port": 6334,
      "EmbeddingModel": "nomic-embed-text",
      "Dimension": 768,
      "BatchSize": 16,
      "Timeout": "00:05:00"
    },
    "FileLoadOptions": {
      "AllowedFileExtensions": [[".cs", ".json"]],
      "ExcludedFiles": [["docker-compose.yml"]],
      "ExcludedDirectories": [["obj", "bin", ".git", "Response", "qdrant_storage"]]
    }
  }
}
```

### 4. Prepare your questions

Create a CSV file in a `Plugins` folder next to the executable (or in your working directory):

```csv
Text,Category,IsEnabled,FileName
What is the retry policy for failed API calls?,CSharp,true,general.csv
How is vector search scoped per question category?,XML,true,general.csv
```

| Column | Description |
|---|---|
| `Text` | The question to send to the LLM |
| `Category` | Routing category (drives filter strategy & output folder) |
| `IsEnabled` | `true` / `false` — disabled rows are skipped |
| `FileName` | Provenance label for the response filename |

### 5. Run

```bash
dotnet run --project Ragnar
```

You'll see a branded header, a live progress bar as files are discovered → parsed → embedded, a styled table of loaded questions, and per-question progress (`1 of N`, `2 of N`, …). Responses are written to:

```
<SourceDirectory>/Response/<Category>/<filename>_<timestamp>.md
```

## 📐 Extending Ragnar

### Add a new question source

```csharp
public sealed class JsonFileQuestionProvider(IRecordParser<QuestionRecord> parser) : IQuestionProvider
{
    public string ProviderName => "JSON File";

    public async Task<IEnumerable<Question>> LoadQuestionsAsync(
        string fileName, CancellationToken ct)
    {
        var records = await parser.ParseAsync(fileName, ct);
        return records.Select(r => new Question(r.IsEnabled, r.Text, r.FileName, r.Category));
    }
}
```

Register it in `Program.cs` / `ServiceCollection` alongside `CsvFileQuestionProvider`.

### Add a new filter strategy

```csharp
public sealed class MyFilterStrategy : IFilterStrategy
{
    public QuestionCategory SupportedCategory => QuestionCategory.MyCategory;

    public Filter CreateFilter(int sizeThreshold) => new()
    {
        Must =
        {
            new Condition { Field = new FieldCondition { /* … */ } }
        }
    };
}
```

### Add a pipeline stage

```csharp
public sealed class MyStage(IOutputWriter writer) : IPipelineStage<EmbeddingContext>
{
    public string Name => "My custom stage";
    public bool ShouldRun => true;   // gate with config if needed

    public Task ExecuteAsync(EmbeddingContext ctx, CancellationToken ct)
        => Task.CompletedTask;
}

// In DI / pipeline wiring:
runner.AddStage(myStage);
```

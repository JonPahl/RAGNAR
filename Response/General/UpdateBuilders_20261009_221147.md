# Reworking and Improving the Existing Builders

Looking at the builders in this codebase (`QuestionCombineBuilder`, `FilterBuilder`, `QuestionBuilder`, `PipelineRunner`), there are several patterns you can apply to modernize them, fix inconsistencies, and add capabilities that the current code lacks.

---

## 1. General Builder Pattern Improvements (Apply to All)

### 1a. Introduce an Immutable Snapshot (`Build()` → `Build()` + `BuildReadonly()`)

Your `QuestionCombineBuilder.Build()` returns `IReadOnlyList<Question>`, which is good. But `FilterBuilder.Build()` returns a mutable `Filter`. Wrap it:

```csharp
public sealed record FilterSnapshot
{
    public required IReadOnlyList<Condition> Must { get; init; }
    public required IReadOnlyList<Condition> MustNot { get; init; }
    public Filter ToQdrant() => new() { Must = { Must }, MustNot = { MustNot } };
}
```

### 1b. Add a `Validate()` Gate Before `Build()`

Prevents silently building empty or contradictory filters:

```csharp
public TBuilder AssertValid<TBuilder>(this TBuilder builder) where TBuilder : IValidatableBuilder
{
    var errors = builder.GetValidationErrors();
    if (errors.Any())
        throw new BuilderValidationException(errors);
    return builder;
}
```

### 1c. Add `Clone()` / `Fork()` for Branching Scenarios

```csharp
public FilterBuilder Fork() => new FilterBuilder
{
    _must = [.. _must],
    _mustNot = [.. _mustNot]
};
```

### 1d. Add a `ToString()` / `Describe()` for Logging

```csharp
public string Describe() =>
    $"FilterBuilder [must: {_must.Count}, mustNot: {_mustNot.Count}]";
```

### Reworked Version

```csharp
/// <summary>Fluent builder for constructing Qdrant filter expressions.</summary>
/// <remarks>
/// All <c>Add*</c> methods are chainable. Call <see cref="Build"/> to materialize.
/// </remarks>
/// <example>
/// <![CDATA[
/// var filter = new FilterBuilder()
///     .MustMatch("Category", "XML")
///     .MustMatch("CommentLength", Range.Lt(50))
///     .MustNotMatch("Category", "Test")
///     .AssertValid()
///     .Build();
/// ]]>
/// </example>
public sealed class FilterBuilder
{
    private readonly List<Condition> _must = [];
    private readonly List<Condition> _mustNot = [];
    private readonly List<Condition> _should = [];

    // ─── Positive (MUST) conditions ───────────────────────────────────

    /// <summary>Adds a keyword MUST-match condition.</summary>
    public FilterBuilder MustMatch(string field, string value)
    {
        _must.Add(Conditions.MatchKeyword(field, value));
        return this;
    }

    /// <summary>Adds a range (less-than) condition to the MUST set.</summary>
    public FilterBuilder MustBeLessThan(string field, int lt)
    {
        _must.Add(new Condition { Field = new FieldCondition { Key = field, Range = new Range { Lt = lt } } });
        return this;
    }

    /// <summary>Adds a range (greater-than) condition to the MUST set.</summary>
    public FilterBuilder MustBeGreaterThan(string field, int gt)
    {
        _must.Add(new Condition { Field = new FieldCondition { Key = field, Range = new Range { Gt = gt } } });
        return this;
    }

    /// <summary>Adds a range (between) condition to the MUST set.</summary>
    public FilterBuilder MustBeInRange(string field, int lower, int upper)
    {
        _must.Add(new Condition
        {
            Field = new FieldCondition
            {
                Key = field,
                Range = new Range { Gte = lower, Lte = upper }
            }
        });
        return this;
    }

    /// <summary>Adds a full-text match to the MUST set.</summary>
    public FilterBuilder MustMatchText(string field, string text)
    {
        _must.Add(Conditions.MatchText(field, text));
        return this;
    }

    /// <summary>Adds a SHOULD (OR) condition.</summary>
    public FilterBuilder ShouldMatch(string field, string value)
    {
        _should.Add(Conditions.MatchKeyword(field, value));
        return this;
    }

    // ─── Negative (MUST-NOT) conditions ───────────────────────────────

    /// <summary>Adds a keyword exclusion (MUST-NOT match).</summary>
    public FilterBuilder MustNotMatch(string field, string value)
    {
        _mustNot.Add(Conditions.MatchKeyword(field, value));
        return this;
    }

    /// <summary>Adds multiple keyword exclusions on the same field.</summary>
    public FilterBuilder MustNotMatchAny(string field, params string[] keywords)
    {
        _must.Add(new Condition
        {
            Field = new FieldCondition
            {
                Key = field,
                Match = new Match { ExceptKeywords = new RepeatedStrings { Strings = { keywords } } }
            }
        });
        return this;
    }

    // ─── Nested / Composite ───────────────────────────────────────────

    /// <summary>Nests another filter as a MUST condition.</summary>
    public FilterBuilder MustSatisfy(FilterBuilder nested)
    {
        _must.Add(new Condition { Filter = new Filter { Must = { nested._must }, MustNot = { nested._mustNot } } });
        return this;
    }

    // ─── Lifecycle ────────────────────────────────────────────────────

    /// <summary>Clears all accumulated conditions.</summary>
    public FilterBuilder Reset()
    {
        _must.Clear();
        _mustNot.Clear();
        _should.Clear();
        return this;
    }

    /// <summary>Returns a shallow copy for forking.</summary>
    public FilterBuilder Fork() => new()
    {
        _must = [.. _must],
        _mustNot = [.. _mustNot],
        _should = [.. _should]
    };

    /// <summary>Validates that at least one condition exists.</summary>
    public FilterBuilder AssertValid()
    {
        if (_must.Count + _mustNot.Count + _should.Count == 0)
            throw new BuilderValidationException("FilterBuilder must contain at least one condition before Build().");
        return this;
    }

    /// <summary>Materializes the filter expression.</summary>
    public Filter Build()
    {
        AssertValid();
        return new Filter
        {
            Must = { _must },
            MustNot = { _mustNot },
            Should = { _should }
        };
    }

    public override string ToString() =>
        $"Filter(must:{_must.Count}, mustNot:{_mustNot.Count}, should:{_should.Count})";
}
```

## 3. `QuestionCombineBuilder` — Specific Rework

### Current Problems

| Issue | Detail |
|-------|--------|
| `Clear()` returns `bool` (always `false` after clearing) | Logic bug |
| `GetCsvFilesAsync` hard-codes `"Summary.csv"` skip | Magic string, not configurable |
| No `WithWhere(Func<Question,bool>)` for ad-hoc filtering | Missing |
| `Questions` is a mutable `List` exposed as a property | Encapsulation leak |
| No deduplication (same question from two sources) | Data integrity |
| No `WithLimit(int)` | Missing |
| No async `BuildAsync()` | Inconsistent |

### Reworked Version

```csharp
/// <summary>
/// Fluent builder that aggregates questions from multiple sources into a final list.
/// Supports deduplication, filtering, limiting, and async source loading.
/// </summary>
/// <example>
/// <![CDATA[
/// var questions = await new QuestionCombineBuilder(qp, ql, qb, opts)
///     .GetCategories()
///     .GetFileConfig()
///     .WithWhere(q => q.Category == QuestionCategory.XML)
///     .WithLimit(100)
///     .Deduplicate()
///     .BuildAsync();
/// ]]>
/// </example>
public sealed class QuestionCombineBuilder(
    IQuestionSource questionProvider,
    IQuestionCatalogLoader questionLoader,
    IQuestionBuilder questionBuilder,
    IOptions<RagnarConfig> options) : IQuestionSourceBuilder
{
    private readonly List<Question> _questions = [];
    private Func<Question, bool>? _predicate;
    private int? _limit;
    private bool _deduplicate;

    // ─── Source Loaders ───────────────────────────────────────────────

    public IQuestionSourceBuilder GetCategories()
    {
        var categories = options.Value.ApplicationOptions.CategoriesToProcess.ToHashSet();
        _questions.AddRange(questionLoader.LoadQuestions(true, categories));
        return this;
    }

    public IQuestionSourceBuilder GetFileConfig()
    {
        foreach (var config in new FileConfigLoader().LoadQuestions())
        {
            _questions.Add(questionBuilder
                .WithText(config.Text)
                .WithFileName(config.Filename)
                .SetCategory(config.Category)
                .SetActive(config.IsEnabled)
                .Build());
        }
        return this;
    }

    /// <summary>
    /// Loads questions from CSV files, optionally skipping files matching a predicate.
    /// </summary>
    public async Task<IQuestionSourceBuilder> GetCsvFilesAsync(
        string pluginDir,
        CancellationToken cancellationToken,
        Func<string, bool>? skipPredicate = null)
    {
        skipPredicate ??= p => p.Contains("Summary.csv", StringComparison.OrdinalIgnoreCase);

        if (!Directory.Exists(pluginDir)) return this;

        foreach (var csvFile in Directory.EnumerateFiles(pluginDir, "*.csv", SearchOption.AllDirectories))
        {
            if (skipPredicate(csvFile)) continue;
            await AddCsvQuestionsAsync(csvFile, cancellationToken).ConfigureAwait(false);
        }
        return this;
    }

    // ─── Transformations ──────────────────────────────────────────────

    /// <summary>Applies a filter predicate to the accumulated questions.</summary>
    public IQuestionSourceBuilder WithWhere(Func<Question, bool> predicate)
    {
        _predicate = predicate;
        return this;
    }

    /// <summary>Limits the final result set.</summary>
    public IQuestionSourceBuilder WithLimit(int max)
    {
        Guard.Against.Negative(max);
        _limit = max;
        return this;
    }

    /// <summary>Flags the builder to remove duplicate questions (by Text + Filename) at Build time.</summary>
    public IQuestionSourceBuilder Deduplicate()
    {
        _deduplicate = true;
        return this;
    }

    /// <summary>Clears all accumulated questions and transformations.</summary>
    public IQuestionSourceBuilder Reset()
    {
        _questions.Clear();
        _predicate = null;
        _limit = null;
        _deduplicate = false;
        return this;
    }

    // ─── Materialization ──────────────────────────────────────────────

    /// <summary>Returns the final, filtered, optional deduplicated, and limited question list.</summary>
    public IReadOnlyList<Question> Build()
    {
        var result = _questions.Where(q => q.IsEnabled);

        if (_predicate is not null)
            result = result.Where(_predicate);

        if (_deduplicate)
            result = result.DistinctBy(q => (q.Text, q.Filename));

        result = result.OrderBy(q => q.Category.ToString()).ThenBy(q => q.Filename);

        if (_limit is not null)
            result = result.Take(_limit.Value);

        return result.ToList().AsReadOnly();
    }

    /// <summary>Async variant (useful if sources are still loading).</summary>
    public Task<IReadOnlyList<Question>> BuildAsync(CancellationToken ct = default) =>
        Task.FromResult(Build());

    public override string ToString() =>
        $"QuestionCombineBuilder [{_questions.Count} loaded, limit={_limit ?? "∞"}, dedup={_deduplicate}]";
}
```

### Fix the `Clear()` / `Reset()` Bug

The old `Clear()` returning `Questions.Count != 0` after `.Clear()` will **always** return `false`. Replace with:

```csharp
// Old (buggy):
public bool Clear()
{
    Questions.Clear();
    return Questions.Count != 0; // Always false
}

// New:
public IQuestionSourceBuilder Reset()
{
    _questions.Clear();
    _predicate = null;
    _limit = null;
    _deduplicate = false;
    return this;
}
```

```csharp
public PipelineRunner AddGroup(string groupName, params IPipelineStage<EmbeddingContext>[] stages)
{
    lock (_gate)
    {
        foreach (var stage in stages)
        {
            if (_stages.Any(x => x.Name == stage.Name))
                throw new ArgumentException($"Stage '{stage.Name}' is already registered.");
            _stages.Add(new PipelineStageEntry<EmbeddingContext>(stage) { /* ... */ });
        }
    }
    return this;
}

/// <summary>Executes a group of stages concurrently.</summary>
public override async Task ExecuteGroupAsync(
    string groupName, EmbeddingContext context, CancellationToken ct)
{
    var group = _stages.Where(s => s.Group == groupName).ToList();
    await Task.WhenAll(group.Select(s => s.Stage.ExecuteAsync(context, ct)));
}
```

### Per-Stage Retry Configuration

```csharp
public record StagePolicy
{
    public int MaxRetries { get; init; } = 3;
    public TimeSpan BaseDelay { get; init; } = TimeSpan.FromSeconds(1);
    public double BackoffMultiplier { get; init; } = 2.0;
    public Type[] RetryOn { get; init; } = [typeof(HttpRequestException), typeof(TimeoutException)];
}

public PipelineRunner WithPolicy(string stageName, StagePolicy policy)
{
    lock (_gate)
    {
        var entry = _stages.First(s => s.Name == stageName);
        entry.CachedPolicy = BuildPolicy(policy);
    }
    return this;
}
```

## 5. `QuestionBuilder` (Extension) — Promote to Core Class

Currently `SetActive` lives in an extension method file. Move it into the builder:

```csharp
public sealed class QuestionBuilder
{
    // ... existing _text, _filename, _category, _isActive fields ...

    public QuestionBuilder SetActive(bool active)
    {
        _isActive = active;
        return this;
    }

    public QuestionBuilder AsActive() => SetActive(true);
    public QuestionBuilder AsInactive() => SetActive(false);

    /// <summary>Attaches arbitrary metadata (tags, source, priority).</summary>
    public QuestionBuilder WithMetadata(Dictionary<string, string> tags)
    {
        _metadata ??= [];
        foreach (var (k, v) in tags) _metadata[k] = v;
        return this;
    }

    /// <summary>Sets a numeric priority (lower = higher priority).</summary>
    public QuestionBuilder WithPriority(int priority)
    {
        _priority = priority;
        return this;
    }

    public Question Build()
    {
        Guard.Against.NullOrEmpty(_text ?? throw new InvalidOperationException("Question text not set."));
        return new Question
        {
            Text = _text,
            Filename = _filename,
            Category = _category,
            IsEnabled = _isActive,
            Metadata = _metadata?.ToImmutableDictionary(),
            Priority = _priority ?? int.MaxValue,
            CreatedAt = DateTime.UtcNow
        };
    }
}
```

Then **delete** `QuestionCombineBuilderExtensions.cs` since `SetActive` is now intrinsic.

## 6. Add a Builder Validation Abstraction

```csharp
/// <summary>Thrown when a builder's state is invalid at Build() time.</summary>
public sealed class BuilderValidationException(string message, IEnumerable<string>? errors = null)
    : Exception(message)
{
    public IReadOnlyList<string> Errors { get; } = errors?.ToList() ?? [];
}

/// <summary>Base contract for builders that can self-validate.</summary>
public interface IValidatableBuilder
{
    IEnumerable<string> GetValidationErrors();
}
```

```csharp
public sealed class FilterBuilder : IValidatableBuilder
```

## 7. Testing Strategy for Builders

Add a focused test class per builder:

```csharp
public class FilterBuilderTests
{
    [Fact]
    public void Build_EmptyFilter_ThrowsBuilderValidation()
    {
        var act = () => new FilterBuilder().AssertValid().Build();
        Assert.Throws<BuilderValidationException>(act);
    }

    [Fact]
    public void MustMatch_AddsToMustList()
    {
        var f = new FilterBuilder().MustMatch("Cat", "XML").Build();
        Assert.Single(f.Must);
    }

    [Fact]
    public void Fork_ProducesIndependentCopies()
    {
        var a = new FilterBuilder().MustMatch("A", "1");
        var b = a.Fork().MustMatch("B", "2");
        Assert.Single(a._must); // can't access private; test via Build
        Assert.Equal(2, b.Build().Must.Count);
    }

    [Fact]
    public void Reset_ClearsAllConditions()
    {
        var f = new FilterBuilder().MustMatch("A", "1").MustNotMatch("B", "2");
        f.Reset();
        Assert.Throws<BuilderValidationException>(() => f.AssertValid().Build());
    }
}
```

## 9. Optional: Source-Generator / T4 for Boilerplate

If you have many simple builders, a Roslyn source generator can emit the `Fork()`, `Reset()`, `ToString()`, and `IValidatableBuilder` boilerplate from a `[GeneratesBuilderClone]` attribute, keeping your source files lean:

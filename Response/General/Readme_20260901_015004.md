## Overview

**Ragnar** is a local-first RAG (Retrieval-Augmented Generation) pipeline purpose-built for code repositories. It ingests your source code, embeds it into a [[Qdrant]](https://qdrant.tech/) vector store, answers developer questions through a local [[Ollama]](https://ollama.com/) LLM, and produces structured, categorized Markdown responses — all without sending a single byte to the cloud.

## Features

- **Local-First** — All inference runs on your machine via Ollama. No API keys, no cloud dependency.
- **Code-Aware RAG** — Parses C#, JSON, and configurable file types into semantic chunks for embedding.
- **Categorized Questions** — Organize prompts by category (`Testing`, `Performance`, `Refactor`, `Diagram`, `XML`, `General`, `Summary`, etc.) and filter which to process.
- **Streaming Responses** — Live token-by-token rendering in the terminal with a Spectre.Console panel.
- **Thinking Mode** — Displays the LLM's reasoning process (for supported models) in a dedicated panel.
- **Batch Summarization** — After all questions are answered, a second pass generates a consolidated summary and an implementation plan per source folder.
- **Plugin Architecture** — Drop a `.dll` implementing `IQuestionProvider` into `Questions/Plugins/` to add custom question sources.
- **CSV Question Import** — Define questions in CSV files with column mapping via `CsvHelper`.
- **File Filtering** — Whitelist extensions, exclude specific files or entire directory trees (e.g. `node_modules`, `bin`, `obj`).
- **FluentValidation** — Configuration is validated at startup with clear, actionable error messages.
- **Serilog** — Structured logging to console, file (JSON), and [[Seq]](https://seq.app/).

### Key Design Patterns

| Pattern | Where | Purpose |
|---|---|---|
| **Pipeline / Stages** | `IPipelineStage`, `BrandingStage`, `SummarizationStage` | Ordered, testable execution phases |
| **Factory** | `OllamaClientFactory`, `FileParseFactory` | Polymorphic client/parser creation |
| **Builder** | `QuestionCombineBuilder`, `VectorStoreBuilder` | Fluent, chainable configuration |
| **Strategy** | `IFilterStrategy`, `XmlCommentFilterStrategy` | Pluggable filtering rules per category |
| **Provider** | `IPromptProvider`, `IQuestionProvider` | Decoupled prompt & question sources |
| **Repository** | `VectorStoreRepository` | Qdrant CRUD abstraction |
| **Plugin / SPI** | `LoadQuestionPlugins()` | Runtime DLL discovery for custom providers |

## Getting Started

### Prerequisites

| Dependency | Minimum Version | Notes |
|---|---|---|
| **.NET SDK** | 10.0 | `.NET 10` / C# 14 |
| **Ollama** | latest | [[`ollama serve`]](https://ollama.com/) must be running |
| **Qdrant** | 1.7+ | Vector store (Docker or native) |
| **nomic-embed-text** | — | Ollama embedding model (`ollama pull nomic-embed-text`) |
| **qwen3:8b** *(or similar)* | — | Ollama LLM model (`ollama pull qwen3:8b`) |

### Installation

```bash
# 1. Clone
git clone https://github.com/<your-org>/ragnar.git
cd ragnar

# 2. Restore & build
dotnet restore
dotnet build -c Release

# 3. Pull required Ollama models
ollama pull nomic-embed-text
ollama pull qwen3:8b

# 4. Start Qdrant (Docker example)
docker run -d --name qdrant \
  -p 6333:6333 -p 6334:6334 \
  -v qdrant_storage:/qdrant/storage \
  qdrant/qdrant
```

### Configuration

Edit `appsettings.json` (or provide an environment-specific override):

```jsonc
{
  "RagnarConfig": {
    "ApplicationOptions": {
      "SourceDirectory": "%USERPROFILE%\\source\\repos\\MyProject\\",
      "VectorStoreName": "my_project_docs",
      "OutputFolder": "Response",
      "CategoriesToProcess": [[]],          // empty = all categories
      "IncludeOriginalPrompt": false
    },
    "OllamaOptions": {
      "Host": "localhost",
      "Port": 11434,
      "Timeout": "00:30:00",
      "LlmModel": "qwen3:8b"
    },
    "EmbeddingOptions": {
      "Host": "localhost",
      "Port": 6334,
      "Timeout": "00:05:00",
      "EmbeddingModel": "nomic-embed-text",
      "Dimension": 768
    },
    "FileLoadOptions": {
      "AllowedFileExtensions": [[".cs", ".json"]],
      "ExcludedFiles": [["docker-compose.yml"]],
      "ExcludedDirectories": [[
        "bin", "obj", ".git", ".github", ".vs",
        ".config", "Logs", "qdrant_storage", "Response"
      ]]
    }
  }
}
```

> **Tip:** `CategoriesToProcess` accepts an array of `QuestionCategory` values (`"Testing"`, `"Performance"`, `"Refactor"`, `"Diagram"`, `"XML"`, `"General"`, `"Summary"`). Leave empty to process all.

## Question Categories

| Category | Description |
|---|---|
| `General` | Broad architectural and design questions |
| `Testing` | Unit / integration test strategy and gaps |
| `Performance` | Hot-path analysis, allocation, and optimization |
| `Refactor` | Code-quality improvement suggestions |
| `Diagram` | Architecture / sequence diagram generation prompts |
| `XML` | XML documentation comment quality and coverage |
| `Summary` | Post-hoc summarization and implementation planning |
| `Uncategorized` | Fallback bucket |

Questions are loaded from:

1. **Built-in defaults** (`DefaultQuestionCatalogLoader`)
2. **File-based config** (`FileConfigLoader`)
3. **CSV plugins** (`Questions/Plugins/*.csv`)
4. **Custom DLL plugins** (`Questions/Plugins/*.dll` implementing `IQuestionProvider`)

### CSV Format

| IsEnabled | Text | FileName | Category |
|-----------|------|----------|----------|
| 1 | Review the exception handling strategy | Program.cs | General |
| 1 | Identify N+1 query patterns | Repository.cs | Performance |
| 0 | Suggest microservice boundaries | Service.cs | Refactor |

## Extending Ragnar

### Adding a Custom Question Provider (Plugin)

```csharp
// 1. Create a class-library project targeting .NET 10
// 2. Reference the Ragnar.Core package (or project)
// 3. Implement IQuestionProvider:

public sealed class MyProvider : IQuestionProvider
{
    public string ProviderName => "My Custom Source";

    public Task<IEnumerable<Question>> LoadQuestionsAsync(
        string fileName, CancellationToken ct)
    {
        // Return questions from your data source
        return Task.FromResult(
            new Question(true, "My question", "File.cs", QuestionCategory.General));
    }
}

// 4. Build and drop the .dll + any .csv files into:
//    bin/Release/net10.0/Questions/Plugins/
```

Ragnar auto-discovers and registers every `IQuestionProvider` type at startup.

### Adding a New File Parser

```csharp
public sealed class MyLanguageParser(Serilog.ILogger logger) : BaseFileParser(logger)
{
    public override ValueTask<CodeDocument[[]]> ParseFileAsync(
        string filePath, CancellationToken ct)
    {
        var content = ReadFileAsync(filePath, ct).AsTask().Result;
        // Split, tokenize, or chunk as needed
        return ValueTask.FromResult(new[[]] { new CodeDocument(filePath, "Element", content) });
    }
}

// Register in DI:
services.AddSingleton<IFileParser, MyLanguageParser>();
```

### Adding a Filter Strategy

```csharp
public sealed class MyFilterStrategy : IFilterStrategy
{
    public QuestionCategory SupportedCategory => QuestionCategory.Performance;

    public Filter CreateFilter(int sizeThreshold) => new()
    {
        Should =
        {
            new Condition
            {
                Field = new FieldCondition
                {
                    Key = "LineCount",
                    Range = new Range { Gte = sizeThreshold }
                }
            }
        }
    };
}
```

## Troubleshooting

| Symptom | Likely Cause | Fix |
|---|---|---|
| `Qdrant connection refused` | Qdrant not running | `docker start qdrant` or start the service |
| `Model not found` | Ollama model not pulled | `ollama pull <model-name>` |
| `Source directory not found` | `SourceDirectory` path wrong | Verify the path in `appsettings.json` (expand `%USERPROFILE%`) |
| `Port must be between 1 and 65535` | Invalid port in config | Correct `OllamaOptions.Port` / `EmbeddingOptions.Port` |
| Empty responses | Embedding dimension mismatch | Ensure `EmbeddingOptions.Dimension` matches the model (768 for `nomic-embed-text`) |

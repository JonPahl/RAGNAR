# Ragnar

[![Build Status](https://github.com/your-username/ragnar/workflows/CI/badge.svg)](https://github.com/your-username/ragnar/actions)
[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

**Ragnar** is a code analysis and question generation tool designed to help developers identify potential issues, improvements, and areas for discussion in their codebase. It analyzes source code files and generates questions about code quality, documentation, security, and more.

## Features

- **Multi-language support**: Analyzes C# code (with extensibility for other languages)
- **Category-based filtering**: Questions are organized by category (XML, Security, Refactor, General, Other)
- **Filter strategies**: Different filtering approaches based on question category and criteria
- **Interactive CLI interface**: User-friendly command-line interface for question review
- **Extensible architecture**: Easy to add new question types, filters, and analysis strategies

## Usage

### Command Line Interface

```bash
# Analyze a single file
ragnar analyze --file Program.cs

# Analyze a directory recursively
ragnar analyze --directory ./src --recursive

# Filter questions by category
ragnar analyze --file Program.cs --category XML,Security

# Set filter size for XML comments
ragnar analyze --file Program.cs --xml-size 100

# Export results to JSON
ragnar analyze --file Program.cs --output results.json
```

### Available Categories

- **XML**: Questions about XML documentation comments
- **Security**: Questions about potential security issues
- **Refactor**: Questions about code refactoring opportunities
- **General**: General code quality questions
- **Other**: Other types of questions

## Configuration

Ragnar can be configured using a `ragnar.json` file in your project root:

```json
{
  "categories": ["XML", "Security"],
  "xmlSize": 150,
  "excludePatterns": ["bin/", "obj/", "*.g.cs"],
  "outputFormat": "json"
}
```

## Architecture

Ragnar follows a modular architecture with the following key components:

- **Core Model**: Core data structures like `Question`, `CodeDocument`, and `Point`
- **Analysis Engine**: Scans source code and generates questions
- **Filter System**: Applies filters to questions based on category and criteria
- **CLI Interface**: User interface for interacting with the tool
- **Output Handlers**: Formats and exports results in various formats

## Extending Ragnar

### Adding New Question Types

1. Create a new class implementing `IQuestionStrategy`
2. Register it in the `QuestionStrategyFactory`
3. Add tests in the test project

### Adding New Filter Strategies

1. Implement `IFilterStrategy` interface
2. Register it in the `QuestionFilterSelector`
3. Add unit tests for the new filter

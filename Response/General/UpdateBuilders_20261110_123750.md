# Reworking and Improving the Existing Builders

Your codebase has two primary builders — `QdrantFilterBuilder` and `OllamaChatClientBuilder` — plus several implicit "builder-like" registration patterns (e.g., `EmbeddingSetupExtension`, `PipelineRunner`'s stage/middleware chain). Below is a structured plan covering concrete defects, architectural gaps, and replacement code you can drop in.

## 1. Current-State Audit

| Builder | Key weaknesses |
|---|---|
| `QdrantFilterBuilder` | No thread-safety; `CloneCondition` is dead code; two `AddExceptKeywords` overloads with inconsistent guarding; `Build()` ships empty lists that Qdrant may reject; no nested/sub-filter support; no `AddMatchAny`; duplicated range logic; no scope/conditional compositing; no serialization; no `AddGeoMatch`; `AddExceptKeywords(params[[]])` skips null-guard |

| `PipelineRunner<TContext>` (stage/middleware chain) | Middleware list is unbounded (no cap); no per-middleware enable/disable toggle; no async-validation of middleware delegates at registration; `ReplaceStage` does an O(n) `Find` then `Remove` then `Insert` with no single lock |

### 2c. Make `Build()` safe against empty lists

Qdrant rejects filters with empty `Must` / `MustNot` / `Should` arrays. Guard each:

```csharp
public Filter Build()
{
    if (IsEmpty)
        throw new InvalidOperationException(
            "QdrantFilterBuilder is empty. Add at least one condition before calling Build().");

    var filter = new Filter();
    if (_must.Count   > 0) filter.Must   = [[.._must]];
    if (_mustNot.Count > 0) filter.MustNot = [[.._mustNot]];
    if (_should.Count > 0) filter.Should = [[.._should]];
    return filter;
}
```

### 2f. Scope-based (using) compositing

Lets you group conditions without polluting the outer scope:

```csharp
public sealed class QdrantFilterScope : IDisposable
{
    private readonly QdrantFilterBuilder _owner;
    private readonly List<Condition> _savedMust;
    private readonly List<Condition> _savedMustNot;
    private readonly List<Condition> _savedShould;

    internal QdrantFilterScope(QdrantFilterBuilder owner,
        List<Condition> must, List<Condition> mustNot, List<Condition> should)
    {
        _owner   = owner;
        _savedMust   = [[..must]];
        _savedMustNot = [[..mustNot]];
        _savedShould  = [[..should]];
    }

    public void Dispose()
    {
        _owner._must   = _savedMust;
        _owner._mustNot = _savedMustNot;
        _owner._should  = _savedShould;
    }
}

// On the builder:
public QdrantFilterScope BeginScope()
    => new(this, _must, _mustNot, _should);

// Usage:
using (new QdrantFilterScope(builder))
{
    builder.AddMatch("Lang", "C#");
    builder.AddMatch("Lang", "VB");
}
// outer conditions are restored
```

```csharp
            throw new ArgumentOutOfRangeException(nameof(tokens));

        return this;
    }

    public OllamaChatClientBuilder WithSeed(int seed)
    {
        _seed = seed;
        return this;
    }

    public OllamaChatClientBuilder WithTimeout(TimeSpan ts)
    {
        if (ts <= TimeSpan.Zero)
            throw new ArgumentOutOfRangeException(nameof(ts));
        _timeout = ts;
        return this;
    }

    public OllamaChatClientBuilder WithRetry(IAsyncPolicy policy)
    {
        Guard.Against.Null(policy, nameof(policy));
        _retry = policy;
        return this;
    }

    {
        Guard.Against.Null(hook, nameof(hook));
        _configure = hook;
        return this;

    public OllamaChatClientConfigured Build()
    {
        Guard.Against.Null(factory, nameof(factory));
        _options ??= new OllamaClientOptions { ServiceType = OllamaServiceType.Ollama };

        if (_model is not null)       _options.Model      = _model;
        if (_temperature is not null) _options.Temperature = _temperature;

        if (_timeout is not null)     _options.Timeout    = _timeout;

            _configure(client);

        return new OllamaChatClientConfigured(client, _options, _retry);

    public OllamaChatClientBuilderConfigured WithChatClient(OllamaServiceType type)

    public OllamaChatClientBuilderConfigured WithOptions(OllamaClientOptions options)
        => Build(); // caller already set options externally
}
```

```csharp
private const int MaxMiddlewares = 16;

public override IPipeline<TContext> UseMiddleware(
    Func<StageExecutionContext<TContext>, Func<Task>, CancellationToken, Task> middleware)

    Guard.Against.Null(middleware, nameof(middleware));
```

### 4c. Atomic `ReplaceStage`

```csharp
public IPipeline<TContext> ReplaceStage(
    string oldName, IPipelineStage<TContext> newStage, IAsyncPolicy? policy = null)
{
    Guard.Against.Null(newStage, nameof(newStage));
    lock (_gate)
    {
        var idx = _stages.FindIndex(s => s.PipelineStage.Name == oldName);
        if (idx < 0)
            throw new KeyNotFoundException($"Stage '{oldName}' not found.");
        if (_stages.Any(s => s.PipelineStage.Name == newStage.Name))
            throw new ArgumentException($"Stage '{newStage.Name}' already registered.");
        _stages[[idx]] = new StageEntry<TContext>(newStage, policy);
    }
    return this;
}
```

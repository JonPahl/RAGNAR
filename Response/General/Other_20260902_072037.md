## Functional / Design Notes

- **`EmbedTextPipeline.ParseDocumentsAsync`** — `MaxDegreeOfParallelism = Math.Min(Environment.ProcessorCount, 8)` with the inline note `// I/O-bound; cap to avoid over-subscription`. This is a deliberate throughput guard; be aware it will limit concurrency on high-core machines.

- **`OllamaChatResponse.GenerateResponse`** — The `OnThink` handler and the `catch (Exception ex) { var y = ex.Message; }` block around `client.Think = ThinkValue.Mritical;` is effectively a **swallowed exception**. If `ThinkValue` assignment ever throws (e.g., unsupported model), it will be silently ignored. You may want to at least log it.

- **`VectorStoreRepository.UpsertBatchAsync`** — The `catch` block logs at `Fatal` severity for a single-batch upsert failure, yet the method returns `UpdateStatus.UnknownUpdateStatus` rather than rethrowing. Callers (e.g., `EmbedTextPipeline.UpsertInBatchesAsync`) won't know the batch failed unless they inspect the returned status, which they currently don't.

- **`OllamaEmbeddingService`** — The `IEmbeddingGenerator` is resolved **once at construction time** via `clientFactory.FindClient(...)`. If the `OllamaApiClient` is ever recreated or its `BaseAddress` changes at runtime, this cached reference won't pick it up.

- **`StringExtensions.CharacterCount`** — The method is on `ReadOnlySpan<char>` but the test class `StringExtensionsTests` calls it as `xml.CharacterCount()` where `xml` is a `string`. This works because of the C# 14 extension-method-on-struct syntax, but be aware the method body calls `value.ToString()` in `LastFolder` and `IsExcluded`, which allocates a new string per call—relevant if those are in a hot loop.

- **`appsettings.json` (multiple variants)** — The `LlmModel` value is `"qwen3.8"` with a commented-out alternative `"qwen3-coder-next"`. Make sure whichever model you're running actually supports the `Think` / `OnThink` API used in `OllamaChatResponse`, otherwise that code path will be dead.

## Minor / Hygiene

- `SummaryService` has a double-dot typo in the TODO: `// TODO: Move to IResponseWriter implementation..`
- `FileValidator` uses `in FileLoadOptions` (pass-by-ref readonly) in its public method signature, which is a C# 7.2+ feature; ensure all consumers (especially the `FileValidatorTests`) are compiling against a matching language version.
- The `questionMap` class registers boolean conversion with `TypeConverterOption.BooleanValues(true, true, "1")` and `BooleanValues(false, true, "0")` — the second parameter `true` means *exact match only*. If your CSVs contain `"True"` / `"False"` instead of `"1"` / `"0"`, those rows will silently default rather than parse.

# Reworking the Builders in the Ragnar Codebase

Below is a structured analysis of every builder in the codebase, the specific problems I found, and a concrete rework for each one. I'll also propose a small set of shared builder conventions so the whole family stays consistent.

---

## 1. Inventory of Builders and Their Problems

| Builder | Role | Key Issues |
|---|---|---|
| `PipelineBuilder<T>` → `Pipeline<T>` | Assembles pipeline stages + middleware | Mutable builder with no validation of duplicate/reorder before `Build()`; `UseMiddleware` signature is a raw delegate lambda (fragile); no `Validate`/`DryRun`; `Pipeline<T>` is `sealed` and takes a *mutable* `IReadOnlyList` in its primary ctor (contradiction). |
| `QuestionAggregator` (`IQuestionSourceBuilder`) | Aggregates questions from CSV, file config, categories | Mixes loading, filtering, sorting, and validation in one class; `Build()` both filters *and* sorts *and* throws; `FilteredByCategory()` mutates internal state as a side-effect; commented-out dead code; `GetCsvFilesAsync` does two unrelated provider lookups; no `Clone()`; not unit-testable (concrete, `sealed`). |
| `IQuestionBuilder` (impl. `QuestionBuilder`) | Constructs a single `Question` | Inconsistent verb convention (`With*` vs `Set*`); no early-fail validation (fails only at `Build()`); no `Clone()`; no `ToString()` for debugging; `SetActive(bool)` breaks the "each call sets one field" idiom. |
| `IRagPromptBuilder` | Composes a RAG prompt string | Only two fluent methods; no system-prompt slot; no multi-context support; no template override; no `Build` validation (empty question *and* context produces an empty prompt silently). |
| `CodeDocumentBuilder` | Builds a `CodeDocument` | Used inline in one parser; no multi-element API; no validation; no `WithMetadata` for arbitrary payload. |
| `IOllamaChatClientBuilder` | Configures an Ollama client | Only two methods; `ForService` returns a *different* type (`OllamaChatClientBuilderConfigured`) which breaks the single-builder pattern; no `Build()` terminal. |

## 2. Shared Builder Conventions (apply to every builder)

Before touching individual builders, agree on a small set of rules so the family stays uniform:

```csharp
// ── Naming ──────────────────────────────────────────────────
//   With<X>(value)   – sets a single field (text, name, path…)
//   Set<X>(value)    – sets an enum / flag / bool
//   Add<X>(item)     – appends to a collection
//   Build()          – terminal; validates + returns the product
//   Clone()          – returns a deep copy (optional)
//
// ── Validation ──────────────────────────────────────────────
//   Each With*/Set*/Add* does a Guard.Against check.
//   Build() does a final cross-field validation and throws
//   BuilderValidationException (not a generic ArgumentException).
//
// ── Immutability ────────────────────────────────────────────
//   The *product* returned by Build() is immutable (record or
//   readonly class). The builder itself is the only mutable
//   object.
//
// ── Testability ─────────────────────────────────────────────
//   Builders implement an interface so they can be faked.
//   No static state, no DI inside the builder (deps injected
//   via constructor if needed).
```

```csharp
/// <summary>Base exception for all builder validation failures.</summary>
public sealed class BuilderValidationException(string message, Exception? inner = null)
    : Exception(message, inner)
{
    /// <summary>The builder's debug snapshot at the time of failure.</summary>
    public string? DebugState { get; init; }
}
```

## 3. Rework: `QuestionBuilder` (single-question builder)

### Problems in the current code
- `SetActive(bool)` is the only "set" verb; the rest are `With*`. Inconsistent.
- No validation until `Build()`. A caller can `WithText("")` and only discover the problem later.
- No `Clone()`, no `ToString()`.
- Concrete class; hard to substitute in tests.

### Rework

```csharp
// ── Interface ────────────────────────────────────────────────
public interface IQuestionBuilder
{
    IQuestionBuilder WithText(string text);
    IQuestionBuilder WithFileName(string fileName);
    IQuestionBuilder SetCategory(QuestionCategory category);
    IQuestionBuilder SetActive(bool active);
    IQuestionBuilder Clone();
    Question Build();
    string ToDebugString();
}

// ── Implementation ───────────────────────────────────────────
public sealed class QuestionBuilder : IQuestionBuilder
{
    private string? _text;
    private string? _fileName;
    private QuestionCategory _category = QuestionCategory.General;
    private bool _active = true;

    public IQuestionBuilder WithText(string text)
    {
        Guard.Against.NullOrWhiteSpace(text);
        _text = text;
        return this;
    }

    public IQuestionBuilder WithFileName(string fileName)
    {
        Guard.Against.NullOrWhiteSpace(fileName);
        _fileName = fileName;
        return this;
    }

    public IQuestionBuilder SetCategory(QuestionCategory category)
    {
        _category = category;
        return this;
    }

    public IQuestionBuilder SetActive(bool active)
    {
        _active = active;
        return this;
    }

    public IQuestionBuilder Clone()
    {
        return new QuestionBuilder
        {
            _text     = _text,
            _fileName = _fileName,
            _category = _category,
            _active   = _active,
        };
    }

    public Question Build()
    {
        if (string.IsNullOrWhiteSpace(_text))
            throw new BuilderValidationException(
                "QuestionBuilder: Text is required.",
                DebugState: ToDebugString());

        if (string.IsNullOrWhiteSpace(_fileName))
            throw new BuilderValidationException(
                "QuestionBuilder: FileName is required.",
                DebugState: ToDebugString());

        return new Question
        {
            Text      = _text,
            Filename  = _fileName,
            Category  = _category,
            IsEnabled = _active,
        };
    }

    public string ToDebugString() =>
        $"QuestionBuilder {{ Text={_text?.Truncate(40) ?? "∅"}, " +
        $"File={_fileName ?? "∅"}, Cat={_category}, Active={_active} }}";

    public override string ToString() => ToDebugString();
}
```

> **Why `Clone()`?**  `QuestionAggregator` (see §4) currently calls the builder *mutatively* in a loop (`questionBuilder.WithText(csv.Text)… questionBuilder.Build()`). That works only because each call fully overwrites every field. A `Clone()` makes the intent explicit and prevents cross-iteration leakage if a field is ever optional.

## 4. Rework: `QuestionAggregator` (multi-source aggregation)

### Problems
- **SRP violation** – loading, filtering, sorting, and validation are all in one class.
- **Mutable internal state** exposed through a fluent API but also mutated by `FilteredByCategory()` (clears + replaces).
- **`Build()` does too much** – filters disabled, sorts, *and* throws if empty.
- **Dead code** – commented-out SQLite block.
- **`GetCsvFilesAsync`** does two unrelated provider lookups (CSV + SQLITE) in one method.
- **Not testable** – `sealed`, concrete, takes concrete `IOptions<RagnarConfig>`.
- **No `IProgress<T>`** reporting for long CSV scans.

### Rework – split into a *loader* + a *pure aggregator*

```csharp
// ── 1. Pure, testable aggregation (no I/O) ──────────────────
public interface IQuestionAggregator
{
    IQuestionAggregator Add(params Question[[]] questions);
    IQuestionAggregator FilterByCategory(IEnumerable<QuestionCategory> categories);
    IQuestionAggregator FilterActiveOnly();
    IReadOnlyList<Question> Build();
    void Clear();
    int Count { get; }
}

public sealed class QuestionAggregator : IQuestionAggregator
{
    private readonly List<Question> _questions = [[]];

    public int Count => _questions.Count;

    public IQuestionAggregator Add(params Question[[]] questions)
    {
        Guard.Against.Null(questions);
        _questions.AddRange(questions.Where(
            q => q is not null &&
            !string.IsNullOrWhiteSpace(q.Text)));
        return this;
    }

    public IQuestionAggregator FilterByCategory(IEnumerable<QuestionCategory> categories)
    {
        Guard.Against.Null(categories);
        var hash = categories.ToHashSet();
        _questions.RemoveAll(q => !hash.Contains(q.Category));
        return this;
    }

    public IQuestionAggregator FilterActiveOnly()
    {
        _questions.RemoveAll(q => !q.IsEnabled);
        return this;
    }

    public IReadOnlyList<Question> Build()
    {
        if (_questions.Count == 0)
            throw new BuilderValidationException(
                "QuestionAggregator produced zero questions. " +
                "Check categories, file paths, and CSV sources.");

        return _questions
            .OrderBy(q => q.Category.ToString())
            .ThenBy(q => q.Filename)
            .ToList()
            .AsReadOnly();
    }

    public void Clear() => _questions.Clear();
}

// ── 2. I/O-heavy loader (calls the aggregator) ──────────────
public interface IQuestionLoader
{
    Task<IReadOnlyList<Question>> LoadFromCsvAsync(
        string directory, CancellationToken ct,
        IProgress<string>? progress = null);

    Task<IReadOnlyList<Question>> LoadFromCsvFileAsync(
        string csvFile, CancellationToken ct);

    IReadOnlyList<Question> LoadFromFileConfig();

    IReadOnlyList<Question> LoadByCategory(
        bool activeOnly, HashSet<QuestionCategory> categories);
}

// ── 3. Concrete loader (unchanged deps, now testable) ───────
public sealed class QuestionLoader(
    IEnumerable<IQuestionSource> sources,
    IQuestionCatalogLoader catalog,
    IQuestionBuilder builder,
    IOptions<RagnarConfig> options,
    IConfigurationLoader fcl,
    ILogger<QuestionLoader> log) : IQuestionLoader
{
    public async Task<IReadOnlyList<Question>> LoadFromCsvAsync(
        string directory, CancellationToken ct, IProgress<string>? progress = null)
    {
        var csvProvider = sources.FirstOrDefault(s => s.SourceName == "CSV")
            ?? throw new InvalidOperationException("No CSV IQuestionSource registered.");

        if (!Directory.Exists(directory))
        {
            log.LogWarning("Plugin directory {Dir} not found; skipping CSV load.", directory);
            return [[]];
        }

        var results = new List<Question>();
        var files   = Directory.EnumerateFiles(directory, "*.csv", SearchOption.AllDirectories)
                              .Where(f => !f.Contains("Summary.csv", StringComparison.OrdinalIgnoreCase));

        foreach (var file in files)
        {
            ct.ThrowIfCancellationRequested();
            progress?.Report($"Loading {Path.GetFileName(file)}…");
            var loaded = await csvProvider.LoadQuestionsAsync(file, ct).ConfigureAwait(false);
            results.AddRange(loaded.Select(ToQuestion));
        }
        return results;
    }

    public async Task<IReadOnlyList<Question>> LoadFromCsvFileAsync(
        string csvFile, CancellationToken ct)
    {
        if (!File.Exists(csvFile)) return [[]];
        var csvProvider = sources.First(s => s.SourceName == "CSV");
        var loaded = await csvProvider.LoadQuestionsAsync(csvFile, ct).ConfigureAwait(false);
        return [[.. loaded.Select(ToQuestion)]];
    }

    public IReadOnlyList<Question> LoadFromFileConfig()
    {
        return [[.. fcl.LoadQuestions().Select(ToQuestion)]];
    }

    public IReadOnlyList<Question> LoadByCategory(
        bool activeOnly, HashSet<QuestionCategory> categories)
    {
        return [[.. catalog.LoadQuestions(activeOnly, categories)]];
    }

    private Question ToQuestion(Models.Question m) =>
        builder
            .WithText(m.Text)
            .WithFileName(m.Filename)
            .SetCategory(m.Category)
            .SetActive(m.IsEnabled)
            .Build();
}
```

### How the caller (e.g. `QuestionLoadStage`) uses them together

```csharp
public async Task ExecuteAsync(QuestionPipelineContext ctx, CancellationToken ct)
{
    var agg = new QuestionAggregator();

    agg.Add([[.. await _loader.LoadFromCsvAsync(_pluginDir, ct, _progress)]]);
    agg.Add([[.. _loader.LoadFromFileConfig()]]);
    agg.Add([[.. _loader.LoadByCategory(true, _categories)]]);

    var cats = _options.Value.ApplicationOptions.CategoriesToProcess;
    if (cats.Count > 0) agg.FilterByCategory(cats);
    agg.FilterActiveOnly();

    ctx.Questions = agg.Build();
}
```

> The key win: **`QuestionAggregator` is now a pure, stateless-per-run value object** you can unit-test with zero mocks. **`QuestionLoader` owns all I/O** and is the only thing that needs an `ILogger`.

## 5. Rework: `IRagPromptBuilder`

### Problems
- No system-prompt slot (you have to hard-code it in the orchestrator).
- Single `WithContext(string)` – can't attach multiple retrieved chunks with source labels.
- No template override.
- `Build()` can silently return an empty string.

### Rework

```csharp
public interface IRagPromptBuilder
{
    IRagPromptBuilder WithSystem(string systemPrompt);
    IRagPromptBuilder WithQuestion(Question question);
    IRagPromptBuilder WithContext(string sourceLabel, string chunkText);
    IRagPromptBuilder WithTemplate(string template);   // {question} {context} {system}
    string Build();
}

public sealed class RagPromptBuilder : IRagPromptBuilder
{
    private string? _system;
    private Question? _question;
    private readonly List<(string Label, string Text)> _contexts = [[]];
    private string _template = "{system}\n\n{context}\n\nQuestion: {question}";

    public IRagPromptBuilder WithSystem(string systemPrompt)
    {
        Guard.Against.NullOrWhiteSpace(systemPrompt);
        _system = systemPrompt;
        return this;
    }

    public IRagPromptBuilder WithQuestion(Question question)
    {
        Guard.Against.Null(question);
        _question = question;
        return this;
    }

    public IRagPromptBuilder WithContext(string sourceLabel, string chunkText)
    {
        Guard.Against.NullOrWhiteSpace(chunkText);
        _contexts.Add((sourceLabel ?? "context", chunkText));
        return this;
    }

    public IRagPromptBuilder WithTemplate(string template)
    {
        Guard.Against.NullOrWhiteSpace(template);
        _template = template;
        return this;
    }

    public string Build()
    {
        if (_question is null && _contexts.Count == 0)
            throw new BuilderValidationException(
                "RagPromptBuilder: at least a question or a context chunk is required.");

        var contextBlock = string.Join("\n\n---\n\n",
            _contexts.Select(c => $"[[{c.Label}]]\n{c.Text}"));

        return _template
            .Replace("{system}",  _system      ?? string.Empty)
            .Replace("{context}", contextBlock)
            .Replace("{question}",_question?.Text ?? string.Empty);
    }
}
```

## 6. Rework: `PipelineBuilder<T>` → `Pipeline<T>`

### Problems
- `Pipeline<T>` primary ctor takes `IReadOnlyList<StageEntry<T>>` but the builder can still add stages *after* `Build()` (no immutability guarantee).
- No validation that stage names are unique, that `newIndex` is in range, etc.
- `UseMiddleware` takes a raw `Func<…>` – typos in the delegate signature won't be caught until a compile error in the caller.
- No `DryRun` / `Validate` step.

### Rework

```csharp
// ── Immutable product ───────────────────────────────────────
public sealed record StageEntry<T>(
    IPipelineStage<T> Stage,
    IAsyncPolicy?     Policy) where T : class;

public sealed class Pipeline<T>(
    ILogger                       logger,
    IReadOnlyList<StageEntry<T>>  stages,
    IReadOnlyList<IStageMiddleware> middlewares)   // ← named interface
    where T : class
{
    public IReadOnlyList<StageEntry<T>> Stages    => stages;
    public IReadOnlyList<IStageMiddleware> Middlewares => middlewares;
    // … ExecuteAsync logic unchanged …
}

// ── Named middleware interface (replaces raw delegate) ─────
public interface IStageMiddleware
{
    Task Invoke<TContext>(
        StageExecutionContext<TContext> context,
        Func<Task> next,
        CancellationToken ct) where TContext : class;
}

// (MetricsSummaryMiddleware, RetryMiddleware, etc. now
//  implement IStageMiddleware instead of exposing a loose
//  Func-based Invoke.)

// ── Builder ─────────────────────────────────────────────────
public sealed class PipelineBuilder<T>(ILogger logger) where T : class
{
    private readonly List<StageEntry<T>> _stages = [[]];
    private readonly List<IStageMiddleware> _middlewares = [[]];

    public PipelineBuilder<T> AddStage(IPipelineStage<T> stage, IAsyncPolicy? policy = null)
    {
        Guard.Against.Null(stage);
        if (_stages.Any(s => s.Stage.Name == stage.Name))
            throw new BuilderValidationException(
                $"Duplicate pipeline stage name: '{stage.Name}'.");
        _stages.Add(new StageEntry<T>(stage, policy));
        return this;
    }

    public PipelineBuilder<T> UseMiddleware(IStageMiddleware middleware)
    {
        Guard.Against.Null(middleware);
        _middlewares.Add(middleware);
        return this;
    }

    public PipelineBuilder<T> RemoveStage(string name)
    {
        _stages.RemoveAll(s => s.Stage.Name == name);
        return this;
    }

    public PipelineBuilder<T> Reorder(string stageName, int newIndex)
    {
        var idx = _stages.FindIndex(s => s.Stage.Name == stageName);
        if (idx < 0)
            throw new BuilderValidationException($"Stage '{stageName}' not found.");
        if (newIndex < 0 || newIndex >= _stages.Count)
            throw new BuilderValidationException(
                $"Reorder index {newIndex} out of range [[0, {_stages.Count}).");
        var entry = _stages[[idx]];
        _stages.RemoveAt(idx);
        _stages.Insert(newIndex, entry);
        return this;
    }

    /// <summary>Dry-run: validate the pipeline without executing.</summary>
    public void Validate()
    {
        var names = _stages.Select(s => s.Stage.Name).ToList();
        if (names.Distinct().Count() != names.Count)
            throw new BuilderValidationException("Duplicate stage names detected.");
        if (_stages.Count == 0)
            throw new BuilderValidationException("Pipeline has zero stages.");
    }

    public Pipeline<T> Build()
    {
        Validate();
        return new Pipeline<T>(logger, _stages.AsReadOnly(), _middlewares.AsReadOnly());
    }
}
```

## 7. Rework: `CodeDocumentBuilder`

### Problems
- Only used in `MarkdownFileParser`; no multi-element support; no metadata.
- `Build()` returns a mutable object.

### Rework (minimal, but future-proof)

```csharp
public sealed class CodeDocumentBuilder
{
    private string? _fileName;
    private string? _code;
    private readonly Dictionary<string, string> _elements = new();

    public CodeDocumentBuilder FileName(string name)
    {
        Guard.Against.NullOrWhiteSpace(name);
        _fileName = name;
        return this;
    }

    public CodeDocumentBuilder Code(string chunk)
    {
        Guard.Against.Null(chunk);
        _code = chunk;
        return this;
    }

    public CodeDocumentBuilder Element(string key, string value)
    {
        Guard.Against.NullOrWhiteSpace(key);
        _elements[[key]] = value ?? string.Empty;
        return this;
    }

    public CodeDocument Build()
    {
        if (string.IsNullOrWhiteSpace(_fileName) || string.IsNullOrWhiteSpace(_code))
            throw new BuilderValidationException(
                "CodeDocumentBuilder: FileName and Code are required.");

        return new CodeDocument
        {
            FileName = _fileName,
            Code     = _code,
            Metadata = new Dictionary<string, object>(_elements),
        };
    }
}
```

## 8. Rework: `IOllamaChatClientBuilder`

### Problem
`ForService()` returns `OllamaChatClientBuilderConfigured` – a *different* type. That breaks the "one builder, one `Build()`" idiom and forces the caller to know the intermediate type.

### Rework

```csharp
public interface IOllamaClientBuilder
{
    IOllamaClientBuilder ForService(OllamaServiceType type);
    IOllamaClientBuilder WithOptions(OllamaClientOptions options);
    IOllamaApiClient Build();
}

public sealed class OllamaClientBuilder(
    IOllamaClientFactory factory,
    IOptions<RagnarConfig> config) : IOllamaClientBuilder
{
    private OllamaServiceType _type = OllamaServiceType.Ollama;
    private OllamaClientOptions? _options;

    public IOllamaClientBuilder ForService(OllamaServiceType type)
    {
        _type = type;
        return this;
    }

    public IOllamaClientBuilder WithOptions(OllamaClientOptions options)
    {
        Guard.Against.Null(options);
        _options = options;
        return this;
    }

    public IOllamaApiClient Build()
    {
        var client = factory.GetClient(_type);
        if (_options is not null)
        {
            // apply overrides
            client.SelectedModel = _options.Model;
        }
        return client;
    }
}
```

Now the caller is always the same shape:

```csharp
var client = builder.ForService(OllamaServiceType.Embedding)
                    .WithOptions(myOptions)
                    .Build();
```

## 9. Summary of Concrete Changes to Make

| File / Type | Action |
|---|---|
| Add `BuilderValidationException.cs` | New shared exception type. |
| `IQuestionBuilder.cs` / `QuestionBuilder.cs` | Add `Clone()`, `ToDebugString()`, per-field `Guard.Against` checks; make class `sealed`. |
| `QuestionAggregator.cs` | **Split** into `QuestionAggregator` (pure list + filter + sort) and `QuestionLoader` (I/O). Remove commented-out SQLite block. Add `IProgress<string>` to CSV scan. |
| `IQuestionSourceBuilder.cs` | **Delete** – replaced by the two interfaces above. |
| `IRagPromptBuilder.cs` / impl. | Add `WithSystem`, `WithContext(label, text)`, `WithTemplate`; validate in `Build()`. |
| `Pipeline.cs` / `PipelineBuilder` | Introduce `IStageMiddleware` interface; add `Validate()` / `DryRun`; check duplicate names in `AddStage`; freeze lists in `Build()`. |
| `MetricsSummaryMiddleware.cs`, `RetryMiddleware.cs`, etc. | Implement `IStageMiddleware` instead of exposing a raw `Func`. |
| `MarkdownFileParser.cs` | Use the reworked `CodeDocumentBuilder`; remove the private `SplitIntoParagraphs` static if it's only used once (or promote to a reusable `ITextChunker`). |
| `IOllamaChatClientBuilder.cs` / impl. | Collapse to single builder + `Build()`; remove `OllamaChatClientBuilderConfigured`. |
| `RagPipelineRunner.cs` | Update DI registrations to match new interfaces; replace `IQuestionSourceBuilder` with `IQuestionAggregator` + `IQuestionLoader`. |

Each change is isolated and can be landed as its own PR with focused unit tests against the new interfaces.

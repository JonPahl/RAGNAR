There are several builders in this codebase, each with distinct issues. I'll walk through them systematically with concrete refactors.

## 1. `QuestionCombineBuilder` — The Primary Target

### Problems

| # | Issue | Severity |
|---|-------|----------|
| 1 | `questionBuilder` is **shared mutable state**. `GetCsvFilesAsync` / `GetCsvFileAsync` call `questionBuilder.WithText(...).WithFileName(...)...` but the return value is discarded, then `questionBuilder.Build()` is called separately. If the builder is a single instance, each call overwrites the previous one. | **Bug** |
| 2 | `GetCategories()` and `GetFileConfig()` are synchronous; `GetCsvFilesAsync` is async. Mixing lifetimes in one fluent chain is fragile. | Design |
| 3 | `Clear()` returns `bool` (`Questions.Count != 0`) — semantically inverted and misleading. | API |
| 4 | No thread-safety. `_questions` is a plain `List<T>` mutated from multiple async paths. | Design |
| 5 | `WithCategoryFilter()` destructively clears and re-adds, but `Build()` also filters — double filtering. | Logic |
| 6 | No `IReadOnlyList` exposure before `Build()`, so callers can't inspect or count. | API |

### Rework

```csharp
/// <summary>
/// Thread-safe fluent builder that aggregates questions from multiple sources.
/// </summary>
/// <remarks>
/// Each <c>Add*</c> method appends; call <see cref="Build"/> to freeze and return
/// an immutable snapshot. The builder is **not** safe to reuse after <c>Build</c>.
/// </remarks>
/// <example>
/// <code><![CDATA[
/// var questions = await builder
///     .AddCategoriesAsync(ct)
///     .AddFileConfig()
///     .AddCsvFilesAsync(pluginDir, ct)
///     .FilterByCategories()
///     .BuildAsync(ct);
/// ]]></code>
/// </example>
public sealed class QuestionCombineBuilder(
    IQuestionSource questionProvider,
    IQuestionCatalogLoader questionLoader,
    IQuestionBuilder questionBuilder,
    IOptions<RagnarConfig> options) : IQuestionSourceBuilder
{
    private readonly object _sync = new();
    private readonly List<Question> _questions = [];
    private bool _isBuilt;

    // ── Internal helpers ──────────────────────────────────────────────

    private void EnsureMutable()
    {
        if (_isBuilt)
            throw new InvalidOperationException(
                "Builder has already been built. Create a new instance to modify questions.");
    }

    private void AddRange(IReadOnlyCollection<Question> items)
    {
        lock (_sync)
        {
            _questions.AddRange(items);
        }
    }

    // ── Source loaders (each produces its own QuestionBuilder instance) ──

    /// <summary>Loads enabled questions for the configured categories.</summary>
    public IQuestionSourceBuilder AddCategories()
    {
        EnsureMutable();
        var categories = options.Value.ApplicationOptions.CategoriesToProcess.ToHashSet();
        AddRange(questionLoader.LoadQuestions(true, categories));
        return this;
    }

    /// <summary>Loads questions from file-based configuration entries.</summary>
    public IQuestionSourceBuilder AddFileConfig()
    {
        EnsureMutable();
        var fcl = new FileConfigLoader();
        var loaded = fcl.LoadQuestions()
            .Select(cfg => questionBuilder
                .WithText(cfg.Text)
                .WithFileName(cfg.Filename)
                .SetCategory(cfg.Category)
                .SetActive(cfg.IsEnabled)
                .Build())          // ← Build() is called on the SAME chain
            .ToList();
        AddRange(loaded);
        return this;
    }

    /// <summary>Loads questions from every <c>*.csv</c> under <paramref name="pluginDir"/>.</summary>
    public async Task<IQuestionSourceBuilder> AddCsvFilesAsync(
        string pluginDir, CancellationToken cancellationToken)
    {
        EnsureMutable();
        if (!Directory.Exists(pluginDir))
            return this;

        var loaded = new List<Question>();
        foreach (var csvFile in Directory.EnumerateFiles(pluginDir, "*.csv", SearchOption.AllDirectories))
        {
            if (csvFile.Contains("Summary.csv", StringComparison.OrdinalIgnoreCase))
                continue;

            var csvConfigs = await questionProvider
                .LoadQuestionsAsync(csvFile, cancellationToken)
                .ConfigureAwait(false);

            foreach (var csv in csvConfigs)
            {
                // Each call produces a NEW QuestionBuilder instance via the DI-scoped
                // factory, so there is no shared-state overwrite.
                loaded.Add(
                    questionBuilder
                        .WithText(csv.Text)
                        .WithFileName(csv.Filename)
                        .SetCategory(csv.Category)
                        .SetActive(csv.IsEnabled)
                        .Build()
                );
            }
        }

        AddRange(loaded);
        return this;
    }

    /// <summary>Loads questions from a single CSV file.</summary>
    public async Task<IQuestionSourceBuilder> AddCsvFileAsync(
        string csvFile, CancellationToken cancellationToken)
    {
        EnsureMutable();
        if (!File.Exists(csvFile))
            return this;

        var csvConfigs = await questionProvider
            .LoadQuestionsAsync(csvFile, cancellationToken)
            .ConfigureAwait(false);

        var loaded = csvConfigs
            .Select(csv => questionBuilder
                .WithText(csv.Text)
                .WithFileName(csv.Filename)
                .SetCategory(csv.Category)
                .SetActive(csv.IsEnabled)
                .Build())
            .ToList();

        AddRange(loaded);
        return this;
    }

    // ── Transformations (non-destructive) ─────────────────────────────

    /// <summary>Filters to the categories listed in configuration (non-destructive).</summary>
    public IQuestionSourceBuilder FilterByCategories()
    {
        EnsureMutable();
        var categories = options.Value.ApplicationOptions.CategoriesToProcess;
        if (categories.Length == 0)
            return this;

        var hash = categories.ToHashSet();
        lock (_sync)
        {
            _questions.RemoveAll(q => !hash.Contains(q.Category));
        }

        return this;
    }

    // ── Inspection ────────────────────────────────────────────────────

    /// <summary>Returns a read-only snapshot of the current question count.</summary>
    public int Count { get { lock (_sync) return _questions.Count; } }

    /// <summary>Returns a read-only snapshot of the current questions.</summary>
    public IReadOnlyList<Question> Peek()
    {
        lock (_sync) return [.._questions];
    }

    // ── Terminal ──────────────────────────────────────────────────────

    /// <summary>Freezes the builder and returns the final sorted, enabled list.</summary>
    public IReadOnlyList<Question> Build()
    {
        EnsureMutable();
        _isBuilt = true;

        lock (_sync)
        {
            return _questions
                .Where(q => q.IsEnabled)
                .OrderBy(q => q.Category.ToString())
                .ThenBy(q => q.Filename, StringComparer.OrdinalIgnoreCase)
                .ToList()
                .AsReadOnly();
        }
    }

    public void Reset()
    {
        lock (_sync)
        {
            _questions.Clear();
        }
        _isBuilt = false;
    }
}
```

**Key changes explained:**

- **`Add*` naming** replaces `Get*` — `Get` implies a query, `Add` implies mutation.
- **`Build()` is terminal** — calling it locks the builder. A new instance is required for further work.
- **`questionBuilder.Build()` is called inline** in every `.Select(...)` / `foreach`, eliminating the shared-state overwrite bug.
- **`FilterByCategories()`** replaces the old `WithCategoryFilter()` and no longer double-filters with `Build()`.
- **`Peek()` / `Count`** let callers inspect state before committing.
- **`Reset()`** replaces the confusing `Clear() → bool`.

> **Prerequisite:** Make `IQuestionBuilder` registered as **`AddTransient`** so each call site gets a fresh instance. If it's currently a singleton, that's the root cause of the overwrite bug.

```csharp
services.AddTransient<IQuestionBuilder, QuestionBuilder>();  // NOT AddSingleton
```

## 2. `FilterBuilder` — Qdrant Filter Construction

### Problems

| # | Issue |
|---|-------|
| 1 | `AddExceptKeywords` appends to `_must` instead of `_mustNot` — logically inverted. |
| 2 | Only supports `Lt` range; no `Gt`, `Gte`, `Between`. |
| 3 | No `Clone()` — reusing a built filter is impossible. |
| 4 | `Build()` doesn't guard against an empty filter. |
| 5 | No `AddMatchExcept` for a single value. |

### Rework

```csharp
public sealed class FilterBuilder
{
    private readonly List<Condition> _must    = [];
    private readonly List<Condition> _mustNot = [];

    // ── Positive conditions ───────────────────────────────────────────

    public FilterBuilder AddMatch(string field, string value)
    {
        _must.Add(Conditions.MatchKeyword(field, value));
        return this;
    }

    /// <summary>Adds a range condition with lower and/or upper bounds.</summary>
    /// <param name="field">Payload field name.</param>
    /// <param name="gte">Greater-than-or-equal bound (optional).</param>
    /// <param name="lte">Less-than-or-equal bound (optional).</param>
    public FilterBuilder AddRange(string field, int? gte = null, int? lte = null)
    {
        var range = new Range { Gte = gte, Lte = lte };
        _must.Add(new Condition { Field = new FieldCondition { Key = field, Range = range } });
        return this;
    }

    /// <summary>Adds an except-keywords condition to the **must** set.</summary>
    public FilterBuilder AddExceptKeywords(string field, params string[] keywords)
    {
        _must.Add(new Condition
        {
            Field = new FieldCondition
            {
                Key   = field,
                Match = new Match { ExceptKeywords = new RepeatedStrings { Strings = { keywords } } }
            }
        });
        return this;
    }

    // ── Negative conditions ───────────────────────────────────────────

    public FilterBuilder AddExclusion(string field, string value)
    {
        _mustNot.Add(Conditions.MatchKeyword(field, value));
        return this;
    }

    /// <summary>Excludes a range of values (must-not).</summary>
    public FilterBuilder AddExclusionRange(string field, int? gte = null, int? lte = null)
    {
        _mustNot.Add(new Condition
        {
            Field = new FieldCondition { Key = field, Range = new Range { Gte = gte, Lte = lte } }
        });
        return this;
    }

    // ── Utility ───────────────────────────────────────────────────────

    public bool IsEmpty => _must.Count == 0 && _mustNot.Count == 0;

    /// <summary>Returns a deep copy so the original can be further modified.</summary>
    public FilterBuilder Clone()
    {
        var c = new FilterBuilder();
        c._must    = [.._must];
        c._mustNot = [.._mustNot];
        return c;
    }

    public Filter Build()
    {
        if (IsEmpty)
            throw new InvalidOperationException(
                "FilterBuilder is empty. Add at least one condition before calling Build().");

        return new Filter
        {
            Must    = { _must },
            MustNot = { _mustNot }
        };
    }
}
```

## 3. `PipelineRunner` (stage-orchestrating builder)

### Problems

| # | Issue |
|---|-------|
| 1 | Retry policy is **hardcoded** (`HttpRequestException`, `TimeoutException`, 3 retries, exponential backoff). Not configurable per stage. |
| 2 | No `ClearStages()` method. |
| 3 | No `ReplaceStage(oldName, newStage)` method. |
| 4 | No `GetStages()` / `StageNames` for introspection. |
| 5 | The `lock(_gate)` around `_stages` is fine, but the snapshot in `ExecuteAsync` copies the list without copying the policy — a future edit to `CachedPolicy` mid-run could race. |

### Rework (additions / changes only)

```csharp
public sealed class PipelineRunner(Serilog.ILogger logger) : BasePipeline<EmbeddingContext>
{
    private readonly Lock _gate = new();
    private readonly List<PipelineStageEntry<EmbeddingContext>> _stages = [];

    // ── New: per-stage retry policy ───────────────────────────────────

    public record RetryPolicy(
        int   MaxAttempts  = 3,
        Func<int, TimeSpan> Backoff = i => TimeSpan.FromSeconds(Math.Pow(2, i)),
        params Type[]      ExceptionTypes)
    {
        public static RetryPolicy Default { get; } =
            new(ExceptionTypes: [typeof(HttpRequestException), typeof(TimeoutException)]);
    }

    public PipelineRunner AddStage(IPipelineStage<EmbeddingContext> stage)
    {
        Guard.Against.Null(stage);
        lock (_gate)
        {
            if (_stages.Any(x => x.Name == stage.Name))
                throw new ArgumentException($"Stage '{stage.Name}' is already registered.", nameof(stage));

            var p = policy ?? RetryPolicy.Default;
            _stages.Add(new PipelineStageEntry<EmbeddingContext>(stage)
            {
                CachedPolicy = Policy.Handle(p.ExceptionTypes)
                    .WaitAndRetryAsync(p.MaxAttempts, p.Backoff)
            });
        }
        return this;
    }

    // ── New: introspection ────────────────────────────────────────────

    public IReadOnlyList<string> StageNames
    {
        get { lock (_gate) return _stages.Select(s => s.Name).ToList().AsReadOnly(); }
    }

    // ── New: lifecycle helpers ────────────────────────────────────────

    public PipelineRunner ClearStages()
    {
        lock (_gate) _stages.Clear();
        return this;
    }

    public PipelineRunner ReplaceStage(string oldName, IPipelineStage<EmbeddingContext> newStage,
        RetryPolicy? policy = null)
    {
        RemoveStage(oldName);
        return AddStage(newStage, policy);
    }
}
```

## 4. `NumberedRowDecorator` / Table-Rendering Chain

### Problems

- The `Render()` method injects a `#` column but **never actually prepends an index to each row** (the commented-out code shows the intent was never finished).
- The decorator wraps `inner` but `Table` delegates straight through, so column/row mutations on the decorator affect the inner directly — violating the decorator contract.

### Rework

```csharp
public sealed class NumberedRowDecorator(ITableRenderer inner, string columnHeader = "#")
    : ITableRenderer
{
    public ConsoleTableBuilder Table => inner.Table;

    public void Render()
    {
        var table = inner.Table;

        // 1. Ensure the index column exists
        if (!table.Columns.Contains(columnHeader, StringComparer.OrdinalIgnoreCase))
            table.AddColumns(columnHeader);

        // 2. Prepend a 1-based index to every existing row
        var existing = table.Rows.Select(r => r.ToArray()).ToList();
        table.Rows.Clear();

        for (var i = 0; i < existing.Count; i++)
        {
            var indexed = new string[table.Columns.Count];
            indexed[0] = (i + 1).ToString();           // index cell
            for (var c = 0; c < existing[i].Length; c++)
                indexed[c + 1] = existing[i][c];        // shifted original cells
            table.AddRow(indexed);
        }

        // 3. Delegate final rendering (borders, colors, etc.) to inner
        inner.Render();
    }
}
```

## 5. Cross-Cutting Improvements

### 5a. Introduce a common `IBuilder<T>` contract

```csharp
/// <summary>Base contract for all fluent builders in the project.</summary>
public interface IBuilder<out T>
{
    /// <summary>Returns the immutable result and locks the builder.</summary>
    T Build();

    /// <summary>Resets internal state so the builder can be reused.</summary>
    void Reset();

    /// <summary>Human-readable dump for diagnostics.</summary>
    string ToDisplayString();
}
```

Have `QuestionCombineBuilder` and `FilterBuilder` implement it. This gives you a single `IBuilder<T>.Build()` entry point in DI-resolved callers.

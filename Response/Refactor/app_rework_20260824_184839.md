### 🔹 Step 2: Dynamically Load the Correct File in `Program.cs`
Use a CLI argument or environment variable to switch profiles at startup:

```csharp
using Microsoft.Extensions.Configuration;
using Microsoft.Extensions.Options;

var builder = WebApplication.CreateBuilder(args);

// 1. Determine which config file to load
string profileName = args.Contains("--profile") 
    ? args.SkipWhile(a => a != "--profile").Skip(1).FirstOrDefault() 
    : Environment.GetEnvironmentVariable("APP_PROFILE") ?? "Ragnar"; // Default fallback

var configFile = $"appsettings.{profileName}.json";

// 2. Build configuration pipeline
builder.Configuration.AddJsonFile("appsettings.json", optional: false, reloadOnChange: true);
builder.Configuration.AddJsonFile(configFile, optional: true, reloadOnChange: true);

// 3. Bind to your strongly-typed options
builder.Services.Configure<RagnarConfig>(builder.Configuration.GetSection("RagnarConfig"));

// Optional: Add validation (from your context)
builder.Services.AddValidatorsFromAssemblyContaining<RagnarConfig>();

var app = builder.Build();

// Verify loaded config at startup
using var scope = app.Services.CreateScope();
var config = scope.ServiceProvider.GetRequiredService<IOptions<RagnarConfig>>().Value;
Console.WriteLine($"Loaded Profile: {profileName}");
Console.WriteLine($"SourceDir: {config.ApplicationOptions.SourceDirectory}");
```

### 🔹 Alternative: Use Built-in Environment Switching (Simpler)
If you prefer standard .NET conventions, rename your files to match environments and skip the CLI logic:

| File | Triggered By |
|------|--------------|
| `appsettings.json` | Always loaded first |
| `appsettings.Development.json` | `ASPNETCORE_ENVIRONMENT=Development` |
| `appsettings.Production.json` | `ASPNETCORE_ENVIRONMENT=Production` |

.NET automatically merges them in order. No extra code needed beyond:
```csharp
builder.Configuration.AddJsonFile($"appsettings.{builder.Environment.EnvironmentName}.json", optional: true, reloadOnChange: true);
```

### 🔑 Key Considerations for Your Setup
1. **Precedence**: Later-loaded files override earlier ones. `appsettings.{Profile}.json` will override `appsettings.json`.
2. **Hot Reload**: `reloadOnChange: true` enables config reloading without restart (useful during dev).
3. **Binding Path**: Since your root key is `RagnarConfig`, always use `.GetSection("RagnarConfig")` when binding, or flatten the JSON to remove the extra nesting level.
4. **Validation**: Your `OllamaOptionsValidator` and other FluentValidation classes will work seamlessly once bound via `IOptions<RagnarConfig>`.

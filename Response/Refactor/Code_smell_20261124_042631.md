**Fix:** Convert to a method or cache it safely. In C# 14, prefer explicit methods for computed state, or use `init` with precomputed values if possible.

#### 2. TOCTOU Race Condition: `SummarizeSaveResponse._responseDir`
**Smell:** `_responseDir ??= Directory.CreateDirectory(...).FullName;` is not thread-safe. Concurrent calls can create duplicate directories or throw during simultaneous assignment.
**Fix:** Path computation is cheap and stateless. Remove the cache entirely, or use `Lazy<T>` if absolutely necessary. Direct computation aligns better with pure function principles.

```csharp
// SummarizeSaveResponse.cs (C# 14 Optimized)
public class SummarizeSaveResponse : IResponseWriter
{
    private const string Template = "# RAG Response Summary\n\n{0}\n\nGenerated: {1}";

    public async Task<string> WriteResponseAsync(ResponseRecord record, CancellationToken cancellationToken)
    {
        Guard.Against.Null(record);
        Guard.Against.Null(record.Question);

        var sourceDir = Path.GetDirectoryName(record.Question.Filename) ?? Directory.GetCurrentDirectory();
        var responseDir = Path.Join(sourceDir, "Response");
        Directory.CreateDirectory(responseDir).FullName; // Ensure exists (idempotent)
        
        var fileName = $"{Path.GetFileNameWithoutExtension(record.Question.Filename)}_summary.md";
        var summaryPath = Path.Join(responseDir, fileName);
        var content = string.Format(Template, record.Answer, DateTime.UtcNow.ToString("O"));

        await File.WriteAllTextAsync(summaryPath, content, cancellationToken).ConfigureAwait(false);
        return summaryPath;
    }
}
```

#### 4. Sync I/O in Async Pipeline: Parallel `SHA256.HashData`
**Smell:** `ParsingStage`, `DeltaEmbedStage`, and `VectorStoreWriter` all call synchronous `SHA256.HashData` inside parallel/async contexts. This blocks thread-pool threads for CPU-bound work, reducing throughput.
**Fix:** Compute hashes **during parsing** (when code is already in memory) or use `HashDataAsync`. I recommend precomputing during chunking to avoid duplication.

```csharp
// ParsingStage.cs (Optimized Parallel Execution)
public async Task ExecuteAsync(EmbeddingContext context, CancellationToken cancellationToken)
{
    Guard.Against.Null(context);
    var files = context.DiscoveredFiles;
    if (files.Count == 0) return;

    var documents = new ConcurrentBag<CodeDocument>();
    var maxParallelism = Math.Min(Environment.ProcessorCount, 8);
    
    await AnsiConsole.Progress().AutoClear(true).StartAsync(async progressCtx =>
    {
        var task = progressCtx.AddTask(Name, maxValue: files.Count);
        
        await Parallel.ForEachAsync(files, new ParallelOptions { CancellationToken = cancellationToken, MaxDegreeOfParallelism = maxParallelism }, async (filePath, token) =>
        {
            // Parse first (CPU bound), then hash in memory without blocking async pipeline
            var elements = await parseFactory.ParseAsync(filePath, token).ConfigureAwait(false);
            foreach (var element in elements)
            {
                element.ContentHash = ComputeContentHash(element.Code); // CPU-bound, safe here
                documents.Add(element);
            }
            task.Increment(1);
        }).ConfigureAwait(false);
    }).ConfigureAwait(false);

    context.Documents = [[..documents]];
    logger.LogInformation("Parsed {Count} code document(s).", context.Documents.Count);
}

private static string ComputeContentHash(string content)
{
    using var sha = System.Security.Cryptography.SHA256.Create();
    return Convert.ToHexString(sha.ComputeHash(System.Text.Encoding.UTF8.GetBytes(content)));
}
```

```mermaid
    Branding-->>Runner: Task.Completed

    %% Show Files
    Runner->>QShow: ShouldRun(ctx)?
    QShow-->>Runner: true
    Runner->>QShow: ExecuteAsync(ctx, ct)
    QShow->>Qdrant: ScrollAsync(collection, limit, offset)
    Qdrant-->>QShow: Points[] + NextPageOffset
    loop While NextPageOffset != null
        QShow->>Qdrant: ScrollAsync(collection, limit, nextOffset)
        Qdrant-->>QShow: Points[] + NextPageOffset
    end
    QShow->>Writer: Render Table("#", "Path")

    %% Question Show
    Runner->>QShow: ShouldRun(ctx)?
    QShow-->>Runner: true
    Runner->>QShow: ExecuteAsync(ctx, ct)
    QShow->>Writer: Render Table("#", "Category", "Text")

    %% Question Execution (RAG)
    Runner->>QExec: ShouldRun(ctx)?
    QExec-->>Runner: ctx.Questions.Count > 0
    Runner->>QExec: ExecuteAsync(ctx, ct)

    loop For each Question in ctx.Questions
        QExec->>Writer: WriteRule() + MarkupLine(question)

        QExec->>CR: RetrieveContextAsync(collection, ct, question.Filter)
        CR->>Qdrant: SearchAsync(collection, vector, filter)
        Qdrant-->>CR: Matched Points[]
        CR-->>QExec: contextText (string)

        QExec->>RAG: ExecuteAsync(question, contextText, ct)
        RAG->>Ollama: Generate(prompt + context)
        Ollama-->>RAG: LLM Response
        RAG-->>QExec: Answer

        QExec->>Writer: Write MarkupLine(answer)
        QExec->>Writer: MarkupLine("{n} of {total}", Cyan)
    end

    Runner-->>Dev: Completed context with Responses
```

## 8. State Diagram — Pipeline Execution Lifecycle

```mermaid
stateDiagram-v2
    [*] --> Configured : DI Registration<br/>+ Config Validation

    Configured --> StagesRegistered : AddStage() × N<br/>(Branding, ShowFile,<br/>QuestionShow, QuestionExec)

    StagesRegistered --> Running : ExecuteAsync(ctx, ct)

    Running --> StageExecuting : For each stage i
    StageExecuting --> StageSkipped : ShouldRun == false
    StageSkipped --> Running : Next stage

    StageExecuting --> StageSucceeded : ExecuteAsync completes
    StageSucceeded --> Running : Next stage

    StageExecuting --> RetryAttempt : Polly policy active<br/>+ catchable exception
    RetryAttempt --> StageExecuting : Retry attempt < max
    RetryAttempt --> StageFailed : Max retries exceeded

    StageExecuting --> StageFailed : Unhandled exception

    StageFailed --> PipelineAborted : Throw PipelineStageException
    PipelineAborted --> [*] : Log Fatal + Exit(1)

    Running --> Completed : All stages processed
    Completed --> [*] : Return enriched context

    Running --> Cancelled : CancellationToken fired
    Cancelled --> [*] : Re-throw OperationCanceledException

    note right of RetryAttempt
        Polly AsyncRetryPolicy:
        3 retries, exponential backoff
        (2^attempt seconds)
        Handles: HttpRequestException,
                 TimeoutException
    end note
```

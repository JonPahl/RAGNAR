## 3. Sequence Diagram – Pipeline Execution Flow

```mermaid
sequenceDiagram
    participant App as Application
    participant Runner as PipelineRunner
    participant Brand as BrandingStage
    participant ShowFile as ShowFileStage
    participant Load as QuestionLoadStage
    participant Show as QuestionShowStage
    participant Exec as QuestionExecutionStage
    participant QBuilder as QuestionCombineBuilder
    participant FDiscovery as FileDiscoveryService
    participant Parser as CodeParserFactory
    participant Embed as EmbeddingGeneratorService
    participant Ollama as IOllamaApiClient
    participant Qdrant as IQdrantClient
    participant RAG as IRagOrchestrator
    participant Writer as IOutputWriter
    participant Logger as ILogger

    App->>Runner: AddStage(Brand)
    App->>Runner: AddStage(ShowFile)
    App->>Runner: AddStage(Load)
    App->>Runner: AddStage(Show)
    App->>Runner: AddStage(Exec, retryPolicy)
    App->>Runner: ExecuteAsync(context, ct)

    loop For each stage
        Runner->>Logger: Information("Starting stage [[{i}]]: {Name}")

        alt BrandingStage
            Runner->>Brand: ExecuteAsync(ctx, ct)
            Brand->>Writer: RenderBranding()
        end

        alt ShowFileStage
            Runner->>ShowFile: ExecuteAsync(ctx, ct)
            ShowFile->>Qdrant: ScrollAsync(collection, pageSize)
            Qdrant-->>ShowFile: Points[[]]
            ShowFile->>Writer: Render table with file paths
        end

        alt QuestionLoadStage
            Runner->>Load: ExecuteAsync(ctx, ct)
            Load->>QBuilder: GetCategories()
            QBuilder->>QBuilder: LoadQuestions(categories)
            Load->>QBuilder: GetFileConfig()
            QBuilder->>QBuilder: LoadFileConfigs()
            Load->>QBuilder: Build()
            QBuilder-->>Load: IReadOnlyList<Question>
            Load->>ctx: Questions = result

            par File parsing & embedding
                Loop For each discovered file
                    Load->>FDiscovery: GetFilesAsync(dir, opts, ct)
                    FDiscovery-->>Load: file paths
                    Load->>Parser: ParseAsync(file, ct)
                    Parser-->>Load: CodeDocuments[[]]
                    Load->>Embed: GenerateAsync(text, ct)
                    Embed->>Ollama: GenerateAsync(input)
                    Ollama-->>Embed: Embedding<float>
                    Embed-->>Load: ReadOnlyMemory<float>
                    Load->>Qdrant: Upsert(point)
                end
            end
        end

        alt QuestionShowStage
            Runner->>Show: ExecuteAsync(ctx, ct)
            Show->>Writer: Render questions table
        end

        alt QuestionExecutionStage (with retry)
            Runner->>Exec: ExecuteAsync(ctx, ct)
            Loop For each question
                Exec->>Writer: WriteRule + Question text
                Exec->>Logger: Information("Processing question [[{id}]]")
                Exec->>Qdrant: RetrieveContextAsync(collection, ct, filter)
                Qdrant-->>Exec: contextText
                Exec->>RAG: ExecuteAsync(question, contextText, ct)
                RAG-->>Exec: response
                Exec->>Writer: MarkupLine("{n} of {total}")
            end
        end

        Runner->>Logger: Information("Completed stage [[{i}]] {Name} in {Time}")
    end

    Runner->>Logger: Information("Pipeline finished in {Total}")
    Runner-->>App: context
```

## 2. Sequence Diagram – Embedding & Upsert Flow

```mermaid
sequenceDiagram
    participant Pipeline as EmbedTextPipeline
    participant Parser as IFileParseFactory

    participant Embed as OllamaEmbeddingService
    participant Ollama as Ollama (Embedding)
    participant Gen as IGeneratorService
    participant Qdrant as Qdrant (IQdrantClient)

    Pipeline->>Parser: DiscoverSourceFilesAsync(ct)
    Parser-->>Pipeline: IReadOnlyList<string> files

    Pipeline->>Parser: ParseAsync(filePath, ct) [[parallel]]
    Parser-->>Pipeline: CodeDocument[[]] documents

    loop For each batch (BATCHSIZE=1)
        Pipeline->>Repo: UpsertBatchAsync(documents, ct)
        activate Repo

        Repo->>Repo: Format text: "Context: {ElementName}\nCode:\n{Code}"

        Repo->>Embed: GenerateAsync(text, ct)
        activate Embed
        Embed->>Ollama: POST /api/embed (nomic-embed-text)
        Ollama-->>Embed: float[[768]] vector
        Embed-->>Repo: ReadOnlyMemory<float> vector
        deactivate Embed

        Repo->>Gen: BuildPointStructs(doc, vector, doc)
        Gen-->>Repo: List<PointStruct> points

        Repo->>Qdrant: UpsertAsync(vectorStoreName, points, ct)
        activate Qdrant
        Qdrant->>Qdrant: Upsert points into collection
        Qdrant-->>Repo: UpdateResult (Completed)
        deactivate Qdrant

        Repo-->>Pipeline: UpdateResult
        deactivate Repo
    end
```

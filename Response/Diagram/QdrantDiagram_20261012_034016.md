## 2. Write Pipeline Sequence (Files → Embeddings → Qdrant)

```mermaid
sequenceDiagram
    autonumber
    participant Runner as PipelineRunner
    participant Discovery as FileDiscoveryService
    participant Parser as CodeParserFactory
    participant Embed as EmbeddingGeneratorService
    participant Point as PointStructFactory
    participant Writer as VectorStoreWriter
    participant Setup as VectorSetup
    participant Qdrant as IQdrantClient (Qdrant)

    Runner->>Setup: ExecuteAsync(ctx, ct)
    Setup->>Qdrant: GetCollectionInfoAsync(collectionName)
    Qdrant-->>Setup: CollectionInfo { Dimension, VectorsCount, Status }

    alt Collection does not exist
        Setup->>Qdrant: CreateCollectionAsync(name, { Dimension })
        Qdrant-->>Setup: CollectionInfo
    end

    Runner->>Discovery: GetFilesAsync(directory, FileLoadOptions, ct)
    Discovery-->>Runner: IAsyncEnumerable<string> paths

    loop For each file path
        Runner->>Parser: ParseAsync(filePath, ct)
        Parser-->>Runner: IEnumerable<CodeDocument>

        par Batch embed (ThreadCount from GenerationOptions)
            Runner->>Embed: GenerateBatchAsync(inputs, ct)
            Note over Embed: timeoutCts = CreateLinkedTokenSource<br/>CancelAfter(OllamaOptions.Timeout)
            Embed-->>Runner: GeneratedEmbeddings<Embedding<float>>
        end

        loop For each CodeDocument
            Runner->>Point: CreatePoint(doc, vector)
            Note over Point: Payload = { FileName, Category,<br/>CommentLength, IsEnabled, ... }
            Point-->>Runner: Qdrant Point
        end

        Runner->>Writer: WriteAsync(points, collectionName, ct)
        Writer->>Qdrant: UpsertAsync(collection, points, ct)
        Qdrant-->>Writer: ack
    end

    Runner->>Setup: Report CollectionInfo (VectorsCount)
```

## 3. Read / Query Pipeline Sequence (Question → RAG Response)

```mermaid
sequenceDiagram
    autonumber
    participant Runner as PipelineRunner
    participant Builder as QuestionCombineBuilder
    participant Show as QuestionShowStage

    Runner->>Builder: GetCategories() → GetFileConfig() → Build()
    Builder-->>Runner: IReadOnlyList<Question>
    Note over Runner: context.Questions = questions

    Runner->>Show: ExecuteAsync(ctx, ct)
    Show->>Show: TableRendererFactory.Render()

    loop For each Question (filtered by ShouldRun)
        Runner->>Exec: ExecuteAsync(ctx, ct)
        Exec->>Filter: FindFilter(question.Category)
        Filter->>Strategy: CreateFilter(commentLengthThreshold)
        Strategy->>FB: AddRange("CommentLength", threshold)
        Strategy->>FB: AddExceptKeywords("Category", "Test","Tests","Testing")
        FB-->>Strategy: Filter { Must: [...], MustNot: [...] }
        Strategy-->>Filter: Filter
        Filter-->>Exec: Filter

        Exec->>Retriever: RetrieveContextAsync(collectionName, ct, filter)
        Retriever->>Qdrant: SearchAsync / ScrollAsync(collection, query, filter, limit)

        Qdrant-->>Retriever: Ranked points with payload + vector
        Retriever-->>Exec: contextText (string)

        Exec->>Exec: writer.MarkupLine(question.Text)
        Exec->>RAG: ExecuteAsync(question, contextText, ct)
        RAG-->>Exec: Generated response
        Exec->>Exec: Responses[qid] = response
    end
```

### Key Observations from the Codebase

| Aspect | Detail |
|--------|--------|
| **Connection** | `EmbeddingOptions.Host` + `Port`; model = `EmbeddingModel` (e.g. `nomic-embed-text`) |
| **Dimension** | Configured via `EmbeddingOptions.Dimension` (e.g. 768), enforced at collection creation |
| **Payload schema** | `FileName`, `Category`, `CommentLength`, `IsEnabled`, `Text` (inferred from filters & `ShowFileStage`) |
| **Filtering** | `FilterBuilder` composes `Must` + `MustNot` conditions; strategies per `QuestionCategory` |
| **Batching** | `EmbeddingOptions.BatchSize` controls vectors per upsert call; `GenerationOptions.ThreadCount` controls concurrent embed threads |
| **Pagination** | `ShowFileStage.EnumerateStoredFiles` uses `ScrollAsync` with `NextPageOffset` loop |
| **Timeout** | `OllamaOptions.Timeout` wrapped in a linked `CancellationTokenSource` around every embed call |
| **Retry** | `QuestionExecutionStage.RetryPolicy` = Polly 3× exponential backoff on `HttpRequestException` / `TimeoutException` |

### ✅ 1. **Define Your Custom Question Provider**
Implement the `IQuestionProvider` interface:

```csharp
public class HostingQuestionProvider : IQuestionProvider
{
    public string Name => "Hosting";

    public IAsyncEnumerable<Question> GetQuestionsAsync(CancellationToken ct = default)
    {
        yield return new Question(
            Category: QuestionCategory.XML,
            Text: "Are we using Microsoft.Extensions.Hosting correctly?",
            Weight: 1.0f,
            Source: "CustomPlugin"
        );
    }
}
```

### ✅ 3. **Ensure Integration with Main Pipeline**
The `IQuestionProvider` must be consumed by the question pipeline — typically in a class like `QuestionPipeline` or `QuestionAggregator`:

```csharp
public class QuestionPipeline : IQuestionPipeline
{
    private readonly IEnumerable<IQuestionProvider> _providers;

    public QuestionPipeline(IEnumerable<IQuestionProvider> providers)
    {
        _providers = providers;
    }

    public async IAsyncEnumerable<Question> GetQuestionsAsync([EnumeratorCancellation] CancellationToken ct = default)
    {
        foreach (var provider in _providers)
        {
            await foreach (var question in provider.GetQuestionsAsync(ct))
            {
                yield return question;
            }
        }
    }
}
```

Then register `IQuestionPipeline` as well:

```csharp
builder.Services.AddSingleton<IQuestionPipeline, QuestionPipeline>();
```

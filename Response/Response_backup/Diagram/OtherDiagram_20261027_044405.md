## 3. RAG Pipeline — Sequence Diagram

```mermaid
sequenceDiagram
    autonumber
    participant Client as Application
    participant RO as RagOrchestrator
    participant OCF as IOllamaClientFactory
    participant CTP as IChatPromptProvider
    participant OGS as IOllamaGenerationService
    participant SW as IResponseWriter
    participant W as IOutputWriter
    participant L as Serilog.ILogger

    Client->>RO: ExecuteAsync(question, contextText, ct)
    RO->>L: Information("Starting RAG pipeline...")
    RO->>RO: Build finalPrompt (Context + Question)
    RO->>OCF: ResolveClient(OllamaServiceType.Ollama)
    OCF-->>RO: IOllamaApiClient
    RO->>CTP: .System (get system prompt)
    CTP-->>RO: string
    RO->>RO: new GenerateRequest { Model, Prompt, System }

    RO->>L: Debug("Invoking Ollama generation...")
    RO->>OGS: GenerateResponse(request, ct)
    activate OGS
    OGS-->>RO: string response
    deactivate OGS
    RO->>L: Debug("Returned {Length} chars")

    alt IncludeOriginalPrompt == true
        RO->>RO: Append ShowPrompt(finalPrompt) + System
        RO->>L: Debug("Original prompt appended")
    end

    RO->>RO: new ResponseRecord(question, response, elapsed)
    RO->>L: Debug("Saving response...")
    RO->>SW: WriteResponseAsync(details, ct)
    activate SW
    SW-->>RO: string path
    deactivate SW
    RO->>L: Information("Response saved to: {Path}")
    RO->>W: WriteLine()
    RO->>W: MarkupLine("[[red underline]]{path}[[/]]")
    RO-->>Client: void (completed)
```

## 4. Pipeline Runner — Stage Execution Flow

```mermaid
flowchart TD
    START([["ExecuteAsync(context, ct)"]]) --> SNAP[["Snapshot _stages list"]]
    SNAP --> LOOP{"i < stages.Count?"}

    LOOP -->|No| DONE[["Log: Pipeline finished"]]
    DONE --> RETURN([["Return enriched context"]])

    LOOP -->|Yes| SKIP{"stage.ShouldRun(ctx)?"}
    SKIP -->|false| NEXT1[["Log: Skipping stage"]]
    SKIP -->|true| BUILD[["Create StageExecutionContext"]]

    BUILD --> MW{"Middlewares registered?"}
    MW -->|Yes| ONION[["Build onion: MW_n → MW_n-1 → … → MW_1 → core"]]
    MW -->|No| CORE

    ONION --> INVOKE[["await pipeline().ConfigureAwait(false)"]]
    CORE --> POLICY{"AsyncPolicy != null?"}
    POLICY -->|Yes| RETRY[["await policy.ExecuteAsync(stage.ExecuteAsync)"]]
    POLICY -->|No| DIRECT[["await stage.ExecuteAsync(ctx, ct)"]]

    INVOKE --> CATCH
    RETRY --> CATCH
    DIRECT --> CATCH

    CATCH{"Exception?"}
    CATCH -->|OperationCanceled| RETHROW[["Re-throw (user cancel)"]]
    CATCH -->|Other| FATAL[["Log Fatal + throw PipelineStageException"]]
    CATCH -->|None| NEXT2[["i++"]]

    NEXT1 --> NEXT2
    NEXT2 --> LOOP
    RETHROW --> END([["End"]])
    FATAL --> END
```

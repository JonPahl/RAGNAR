### 1. Path Traversal / Arbitrary File Write
**Location:** `ResponseWriter.WriteResponseAsync`
**Risk:** High
**Description:** The code constructs a file path using user-controlled data (`Details.Question.Filename`) joined with a base directory. If the filename contains path traversal sequences (e.g., `../../../etc/passwd`), it could write files outside the intended directory or overwrite system files.

```csharp
// Vulnerable Code
var filePath = Path.Join(path, $"{Details.Question.Filename}_{fileNow}.md");
await File.WriteAllTextAsync(filePath, content, Ct);
```

**Fix:** Validate that the resolved path remains within the intended base directory.

```csharp
public async Task<string> WriteResponseAsync(SaveDetails Details, CancellationToken Ct)
{
    var sourceDir = Config.Value.ApplicationOptions.SourceDirectory;
    
    // Sanitize filename to remove traversal characters
    var safeFilename = Path.GetFileName(Details.Question.Filename); 
    if (string.IsNullOrWhiteSpace(safeFilename))
        throw new ArgumentException("Invalid filename");

    var fileNow = DateTime.Now.ToString("yyyyMMdd_HHmmss");
    var relativePath = $"{safeFilename}_{fileNow}.md";
    
    // Resolve the full path to check for traversal
    var fullPath = Path.GetFullPath(Path.Join(sourceDir, relativePath));
    
    // Ensure the resolved path starts with the source directory
    if (!fullPath.StartsWith(sourceDir, StringComparison.OrdinalIgnoreCase))
        throw new UnauthorizedAccessException("Access denied: Path traversal detected.");

    var content = FormatFile(Details);
    await File.WriteAllTextAsync(fullPath, content, Ct);
    return fullPath;
}
```

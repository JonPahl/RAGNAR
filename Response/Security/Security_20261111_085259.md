## 1. Path Traversal / Directory Escape

### `OutputPathHelper.GetResponseDirectory`

```csharp
segments.AddRange(parts);  // ← 'folders' is user-supplied; no sanitization
segments.Add(DomainDefaults.ResponseDir);
return Path.Combine([[..segments]]);
```

If a caller passes `[["../../etc", "passwd"]]` as `folders`, the resolved path escapes the intended base directory.

**Fix:**

```csharp
public static string GetResponseDirectory(this IEnumerable<string> folders, string baseDir = "")
{
    Guard.Against.Null(folders);
    var parts = folders as IReadOnlyCollection<string> ?? [[..folders]];

    // Validate each segment is a simple name (no separators, no traversal)
    foreach (var p in parts)
    {
        if (string.IsNullOrWhiteSpace(p) ||
            p.Contains(Path.DirectorySeparatorChar) ||
            p.Contains(Path.AltDirectorySeparatorChar) ||
            p.Contains("..") ||
            p.Contains(".."))
            throw new ArgumentException(
                $"Invalid path segment: '{p}'. Segments must be simple folder names.",
                nameof(folders));
    }

    var segments = new List<string>(parts.Count + 2);
    if (!string.IsNullOrWhiteSpace(baseDir))
        segments.Add(baseDir.TrimEnd(Path.DirectorySeparatorChar, Path.AltDirectorySeparatorChar));
    segments.AddRange(parts);
    segments.Add(DomainDefaults.ResponseDir);

    var result = Path.GetFullPath(Path.Combine([[..segments]]));

    // Belt-and-suspenders: ensure the result stays under the base directory
    if (!string.IsNullOrEmpty(baseDir) &&
        !result.StartsWith(Path.GetFullPath(baseDir), StringComparison.OrdinalIgnoreCase))
        throw new SecurityException("Resolved path escapes the base directory.");

    return result;
}
```

### `FileDiscoveryService.GetFilesAsync`

```csharp
foreach (var path in Directory.EnumerateFiles(directory, "*.*", SearchOption.AllDirectories))
```

The `directory` parameter is used verbatim. An attacker who controls this value (e.g., via config injection) can enumerate arbitrary directories, including `/etc`, `C:\Windows`, or network shares.

**Fix:**

```csharp
public async IAsyncEnumerable<string> GetFilesAsync(
    string directory, IOptions<RagnarConfig> options,
    [[EnumeratorCancellation]] CancellationToken cancellationToken)
{
    Guard.Against.NullOrEmpty(directory);

    var fullPath = Path.GetFullPath(directory);

    // Restrict enumeration to the configured source directory
    var allowedRoot = Path.GetFullPath(options.Value.ApplicationOptions.SourceDirectory);
    if (!fullPath.StartsWith(allowedRoot, StringComparison.OrdinalIgnoreCase))
        throw new UnauthorizedAccessException(
            $"Directory '{directory}' is outside the allowed source root '{allowedRoot}'.");

    if (!Directory.Exists(fullPath))
        throw new DirectoryNotFoundException(fullPath);

    // ... rest of enumeration using fullPath
}
```

## 2. Missing Input Validation on Filter Keywords

### `QdrantFilterBuilder.AddExceptKeywords` (both overloads)

```csharp
public QdrantFilterBuilder AddExceptKeywords(string field, params string[[]] keywords)
{
    // No null/empty check on individual keywords
    _must.Add(new Condition { Field = new FieldCondition { Key = field,
        Match = new Match { ExceptKeywords = new RepeatedStrings { Strings = { keywords } } } } });
    return this;
}
```

A `null` entry in the array will cause a `NullReferenceException` deep inside the Qdrant client, and empty strings produce meaningless filter conditions.

**Fix:**

```csharp
public QdrantFilterBuilder AddExceptKeywords(string field, params string[[]] keywords)
{
    GuardField(field);
    if (keywords is null || keywords.Length == 0)
        throw new ArgumentException("At least one keyword is required.", nameof(keywords));
    if (keywords.Any(k => string.IsNullOrWhiteSpace(k)))
        throw new ArgumentException("Keywords must be non-empty strings.", nameof(keywords));

    _must.Add(new Condition { Field = new FieldCondition { Key = field,
        Match = new Match { ExceptKeywords = new RepeatedStrings { Strings = { keywords } } } } });
    return this;
}
```

### `QdrantFilterBuilder.AddShouldMatch`

```csharp
public QdrantFilterBuilder AddShouldMatch(string field, string value)
{
    GuardField(field);
    // ← value is never null-checked (unlike AddMatch / AddExclusion)
    _should.Add(Conditions.MatchKeyword(field, value));
    return this;
}
```

**Fix:**

```csharp
public QdrantFilterBuilder AddShouldMatch(string field, string value)
{
    GuardField(field);
    Guard.Against.Null(value, nameof(value));   // ← add this
    _should.Add(Conditions.MatchKeyword(field, value));
    return this;
}
```

## 3. Information Disclosure via Logs

### `StageTimingMiddleware` / `ProgressMiddleware` / `PipelineRunner`

These log stage names, internal exception messages, and full file paths at `Information`/`Critical` level:

```csharp
logger.LogCritical(ex, "Stage [[{Index}]] {Name} failed", i, stage.Name);
//  → ex.ToString() includes stack traces, connection strings, internal paths
```

**Fix:**

- Log only `ex.Message` (or a custom user-safe summary) at `Critical`; log the full stack at `Debug` behind a feature flag.
- Sanitize file paths in log output (mask drive letters, user-profile segments) when running in a shared environment.
- Add a `MinimumLevel` guard so that `Information`-level stage metrics are suppressed in production:

```csharp
if (logger.IsEnabled(LogLevel.Information))
    logger.LogInformation("Stage [[{Index}/{Total}]] {Name} – {Elapsed} ({Success})", …);
```

## 4. Denial-of-Service via Unbounded Enumeration

### `FileDiscoveryService` – `SearchOption.AllDirectories`

On a large monorepo or a mapped network drive this enumerates **every** sub-directory synchronously with no time limit:

```csharp
foreach (var path in Directory.EnumerateFiles(directory, "*.*", SearchOption.AllDirectories))
{
    cancellationToken.ThrowIfCancellationRequested();  // cooperative only
    …
}
```

A hostile `RagnarConfig.SourceDirectory` pointing at a deep or infinite-symlink tree will hang the process.

**Fix:**

```csharp
// 1. Enforce a maximum file count
const int MaxFiles = 100_000;
if (discoveredCount >= MaxFiles)
    throw new InvalidOperationException($"Enumeration exceeded {MaxFiles} files; aborting.");

// 2. Add a hard wall-clock deadline (e.g., 120 s) on top of CancellationToken
using var deadline = new CancellationTokenSource(TimeSpan.FromMinutes(2));
using var linked   = CancellationTokenSource.CreateLinkedTokenSource(cancellationToken, deadline.Token);
// use linked.Token throughout the loop

// 3. Skip symlinked directories to avoid infinite loops
//    (Directory.EnumerateFiles already follows links; guard explicitly)
```

## 5. Unsafe Default Fallback in Parser Dispatch

### `CodeParserFactory.ParseAsync`

```csharp
if (!_byExt.TryGetValue(ext, out var parser))
{
    parser = new MarkdownFileParser(options, logger);  // ← silent fallback
}
```

An attacker who names a file `malicious.cs.exe` (extension `.exe`) will bypass the C# parser and hit the Markdown parser, potentially producing unexpected output that feeds into LLM prompts (prompt-injection vector). Conversely, a file named `secret.md` with binary content will be parsed as Markdown.

**Fix:**

```csharp
if (!_byExt.TryGetValue(ext, out var parser))
{
    logger.LogWarning("No parser registered for '{Ext}' ({File}); skipping.", ext, file);
    yield break;   // or throw, depending on policy
}
```

If a fallback is truly required, make it **explicit** in configuration rather than a silent default.

## 6. Insecure Storage of Fingerprint Data

### `JsonFileFingerprintStore`

The fingerprint file is written as **plain JSON with no integrity check**:

```csharp
snapshot = JsonSerializer.Serialize(_fingerprints, _jsonOption);
await File.WriteAllTextAsync(_filePath, snapshot, cancellationToken).ConfigureAwait(false);
```

A local user (or a malware on the same host) can edit `fingerprints.json` to force re-embedding of *any* file (resource exhaustion) or to skip embedding of specific files (data exfiltration by hiding them from the vector store).

**Fix:**

- Append a HMAC of the JSON content using a per-installation secret (stored in DPAPI / Windows Credential Manager):

```csharp
private async Task PersistAsync(CancellationToken ct)
{
    string snapshot;
    lock (_gate)
        snapshot = JsonSerializer.Serialize(_fingerprints, _jsonOption);

    // HMAC-SHA256 with a machine-bound key
    using var hmac = new HMACSHA256(_machineKey);
    var tag = hmac.ComputeHash(Encoding.UTF8.GetBytes(snapshot));

    var envelope = JsonSerializer.Serialize(new FingerprintEnvelope
    {
        Data = _fingerprints,
        Hmac = Convert.ToBase64String(tag)
    }, _jsonOption);

    await File.WriteAllTextAsync(_filePath, envelope, ct).ConfigureAwait(false);
}
```

- Verify the HMAC on `InitializeAsync` before trusting the data.

## 7. Prompt-Injection Surface

### `OutputPathHelper.ShowPrompt`

```csharp
public static string ShowPrompt(this string prompt) =>
    $"\n\n{PromptFormatting.Fence}\n{PromptFormatting.OriginalPromptLabel}\n{prompt}\n{PromptFormatting.OriginalPromptLabelEnd}{PromptFormatting.Fence}";
```

The raw `prompt` string is interpolated directly into a Markdown fence. If `prompt` originates from a file that was parsed (e.g., a `README.md` in the scanned repo), a crafted file can embed `***` sequences that **break out of the fence** and inject instructions into the LLM.

**Fix:**

```csharp
public static string ShowPrompt(this string prompt)
{
    // Neutralise fence-breaking sequences
    var sanitized = prompt
        .Replace("***", "∗∗∗")          // break triple-star sequences
        .Replace(PromptFormatting.Fence, "`` `");  // defensive

    return $"\n\n{PromptFormatting.Fence}\n{PromptFormatting.OriginalPromptLabel}\n{sanitized}\n{PromptFormatting.OriginalPromptLabelEnd}{PromptFormatting.Fence}";
}
```

Additionally, validate at the **prompt-assembly** layer that the concatenated prompt does not exceed `GenerationOptions.ContextWindow` to prevent truncation-based injection.

## 8. Thread-Safety Gap in `QuestionFilterSelector`

```csharp
private readonly Dictionary<QuestionCategory, IFilterStrategy> _strategies;

public QuestionFilterSelector(ILogger logger, IEnumerable<IFilterStrategy> strategies)
{
    _strategies = strategies.ToDictionary(s => s.SupportedCategory);
    if (!_strategies.ContainsKey(QuestionCategory.XML))
        _strategies[[QuestionCategory.XML]] = new XmlCommentFilterStrategy(logger); // ← mutation after publication
}
```

If the object is passed to other threads **before** the constructor body finishes (e.g., via a factory that caches by reference), the post-construction mutation is not visible. In practice this is unlikely in DI, but the pattern is fragile.

**Fix:** build the dictionary in a local variable and assign once:

```csharp
public QuestionFilterSelector(ILogger logger, IEnumerable<IFilterStrategy> strategies)
{
    _logger = logger;
    var dict = strategies.ToDictionary(s => s.SupportedCategory);
    if (!dict.ContainsKey(QuestionCategory.XML))
        dict[[QuestionCategory.XML]] = new XmlCommentFilterStrategy(logger);
    _strategies = dict;   // single assignment, no post-publication mutation
}
```

## 9. Excessive Resource Limits in `GenerationOptions`

```csharp
[[Range(1, 131072, …)]]  public int MaxTokens      { get; init; } = 32_768;
[[Range(1, 262144, …)]]  public int ContextWindow  { get; init; } = 65_536;
```

These upper bounds allow a single request to consume **128 K tokens** of generation and **256 K tokens** of context. In a multi-tenant or CI environment this can exhaust GPU memory or OOM the host.

**Fix:** lower the practical ceiling (e.g., `MaxTokens ≤ 32 768`, `ContextWindow ≤ 131 072`) and add a **process-level** concurrency cap on the embedding/inference client so that N simultaneous requests cannot multiply memory usage.

## 10. Missing TLS / Auth Enforcement for Embedding Endpoint

### `EmbeddingOptions`

```csharp
public required Uri Host { get; init; }
```

Nothing prevents `Host = new Uri("http://10.0.0.5")` (plaintext). If the model name or prompt content is sensitive, sending it over HTTP exposes it on the network.

**Fix:**

```csharp
[[Url(Url.Scheme = "https", ErrorMessage = "Embedding endpoint must use HTTPS.")]]
public required Uri Host { get; init; }
```

or validate in a custom `IValidatableObject`:

```csharp
public IEnumerable<ValidationResult> Validate()
{
    if (Host.Scheme != Uri.UriSchemeHttps)
        yield return new ValidationResult(
            "Embedding endpoint must use HTTPS.", new[[]] { nameof(Host) });
}
```

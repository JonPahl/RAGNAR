**Locations:** 
- `ContentSummarizerAgent.cs` (`AskAgent`, `SummarizeContent`)
- `ResponseWriter.cs` (`WriteResponseAsync`)
- `JsonFileFingerprintStore.cs` (file path resolution)

**Risk:** Unvalidated user or config input (`folder`, `fileName`, `basePath`) is passed directly to `Directory.EnumerateFiles`, `Path.Join`, or `File.WriteAllTextAsync`. An attacker could craft paths like `../../../etc/passwd` (Linux) or `..\..\Windows\System32\config\SAM` (Windows) to read or overwrite arbitrary system files.

**C# 14 Secure Fix:**
Create a strict path containment guard using extension members and the `in` modifier for zero-copy performance:
```csharp
public static class PathSecurityExtensions
{
    /// <summary>Validates that a resolved path is strictly contained within an allowed base directory.</summary>
    extension(string path)
    {
        public bool IsStrictlyWithin(in string basePath, in StringComparison comparison = StringComparison.Ordinal)
        {
            if (path is null) throw new ArgumentNullException(nameof(path));
            
            var fullBase = Path.GetFullPath(basePath);
            var fullPath = Path.GetFullPath(path);
            
            // Prevent traversal by ensuring the target starts with base + separator
            return fullPath.StartsWith(fullBase + Path.DirectorySeparatorChar, comparison);
        }
    }
}
```
**Integration:**
- In `ContentSummarizerAgent.SummarizeContent`: `folder.EnsureWithinBase(appOptions.SourceDirectory)` before enumeration.
- In `ResponseWriter.WriteResponseAsync`: `fullPath.EnsureWithinBase(_applicationOptions.SourceDirectory)` before writing.
- In `JsonFileFingerprintStore`: Validate `_filePath` against the source directory root during initialization.

### 🔴 Critical: Unsafe Dynamic Plugin Loading
**Location:** `QuestionPluginExtensions.cs` / `EmbeddingSetupExtension.cs`
```csharp
var assembly = AssemblyLoadContext.Default.LoadFromAssemblyPath(dll);
```
**Risk:** Blindly loading all `.dll` files from a filesystem directory executes arbitrary code without validation. If an attacker gains write access to the plugin directory, they can achieve Remote Code Execution (RCE).

**C# 14 Secure Fix:**
Implement signature verification and strict allowlisting:
```csharp
public static class SafePluginLoader
{
    private static readonly HashSet<string> _allowedHashes = [[]]; // Load from secure config/keyvault
    
    extension(IEnumerable<string> pluginPaths)
    {
        public IEnumerable<Assembly> LoadVerifiedPlugins(in ILogger logger)
        {
            foreach (var path in pluginPaths)
            {
                if (!path.EndsWith(".dll", StringComparison.OrdinalIgnoreCase)) continue;
                
                var fileHash = ComputeSha256Hash(path);
                if (!_allowedHashes.Contains(fileHash))
                {
                    logger.LogWarning("Plugin rejected: unsigned or unapproved DLL '{Path}'", path);
                    continue;
                }

                yield return AssemblyLoadContext.Default.LoadFromAssemblyPath(path);
            }
        }

        private static string ComputeSha256Hash(string filePath)
        {
            using var sha = System.Security.Cryptography.SHA256.Create();
            using var stream = File.OpenRead(filePath);
            var hash = sha.ComputeHash(stream);
            return Convert.ToHexStringLower(hash);
        }
    }
}
```
**Note:** Store approved hashes in `appsettings.json` (encrypted at rest) or a secrets manager. Update the hash list via a signed update pipeline.

### 🟡 Medium: Path Traversal in Environment Variable Expansion
**Location:** `PathExtensions.cs` (`ExpandDirectory`)
```csharp
var expanded = Environment.ExpandEnvironmentVariables(path);
```
**Risk:** If `path` originates from untrusted config, an attacker could set env vars like `%WINDIR%\config\SystemFileMapper.exe` to redirect path resolution.

**C# 14 Secure Fix:**
```csharp
extension(string path)
{
    public string ExpandAndValidate(in string allowedRoot, in ILogger logger)
    {
        var expanded = Environment.ExpandEnvironmentVariables(path);
        var fullPath = Path.GetFullPath(expanded);
        
        if (!fullPath.IsStrictlyWithin(allowedRoot))
        {
            logger.LogWarning("Configuration rejected: resolved path escapes allowed root. Original: '{Path}'", path);
            throw new DirectoryNotFoundException($"Path traversal detected for '{path}'.");
        }

        if (!Directory.Exists(fullPath))
            throw new DirectoryNotFoundException($"Resolved directory does not exist: '{fullPath}'.");

        return fullPath;
    }
}
```

### 🟡 Medium: Missing TLS/Certificate Validation for Remote Endpoints
**Locations:** `OllamaClientFactory`, `VectorSetup` (Qdrant client)
```csharp
return new QdrantClient(opt.Host.Host, opt.Host.Port, https: false);
```
**Risk:** If `https` is forced to `true` in production but server certificates are untrusted or expired, requests may fail silently or fall back to insecure channels depending on the underlying HTTP handler configuration.

**C# 14 Secure Fix:**
Ensure HttpClient handlers explicitly validate certs and use connection pooling:
```csharp
public static class NetworkSecurityExtensions
{
    extension(IServiceCollection services)
    {
        public IServiceCollection ConfigureSecureHttpClients()
        {
            services.AddHttpClient("OllamaClient")
                .ConfigurePrimaryHttpMessageHandler(() => new HttpClientHandler
                {
                    ServerCertificateCustomValidationCallback = HttpClientHandler.DangerousAcceptAnyServerCertificateValidator, // Dev only!
                    // Production: Use a pinned cert or X509ChainPolicy with strict validation
                    SslProtocols = System.Security.Authentication.SslProtocols.Tls13 | System.Security.Authentication.SslProtocols.Tls12,
                });
            
            services.AddHttpClient("QdrantClient")
                .ConfigurePrimaryHttpMessageHandler(() => new HttpClientHandler
                {
                    ServerCertificateCustomValidationCallback = (msg, cert, chain, sslErrors) =>
                        cert != null && chain.Build(new X509Certificate2(cert)),
                    SslProtocols = System.Security.Authentication.SslProtocols.Tls13 | System.Security.Authentication.SslProtocols.Tls12,
                });

            return services;
        }
    }
}
```

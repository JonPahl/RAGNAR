**Vulnerability:**

private static string EnsureWithinBaseDir(string requestedPath, string baseDir)

    var resolved = Path.GetFullPath(requestedPath);

### 🟠 High: Resource Exhaustion & DoS Vectors
**Location:** `SummaryAgent.LoadFolderContentsAsync`, `QdrantSearchService.FormatContext`

**Vulnerability:**
- `Directory.GetFiles(Folder)` reads **all files** in a directory without limits on count, size, or recursion. A malicious or misconfigured folder could cause OOM, extreme latency, or disk I/O exhaustion.
- `var estimatedSize = Results.Count * 256;` can allocate massive memory if the vector search returns thousands of results.

**Fix:** Impose strict limits and use safe enumeration:
```csharp
// In SummaryAgent.LoadFolderContentsAsync
private static async Task<string> LoadFolderContentsAsync(string Folder, CancellationToken Ct)
{
    var allowedExtensions = new HashSet<string>(StringComparer.OrdinalIgnoreCase) { ".cs", ".json", ".md" };
    var files = Directory.EnumerateFiles(Folder, "*.*", SearchOption.TopDirectoryOnly)
                         .Where(f => allowedExtensions.Contains(Path.GetExtension(f)))
                         .Take(50); // Hard limit on file count

    if (!files.Any()) return "No items to summarize.";

    var contents = new List<string>(files.Count());
    await Parallel.ForEachAsync(files, new ParallelOptions { CancellationToken = Ct }, async (file, token) =>
    {
        using var reader = File.OpenText(file);
        // Limit file size to 1MB per file
        var text = await reader.ReadToEndAsync().ConfigureAwait(false);
        if (text.Length > 1_048_576) throw new InvalidOperationException("File too large.");
        contents.Add($"---\n[RESPONSE_FILE]{Path.GetFileName(file)}[/RESPONSE_FILE]\n{text}\n");
    });

    return "[RESPONSE_CODE] " + string.Concat(contents) + "[/RESPONSE_CODE]";
}
```

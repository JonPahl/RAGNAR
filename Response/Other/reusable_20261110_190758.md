# Making Your Pipeline & Stages Reusable

## 1. Fluent Pipeline Builder (Declarative Composition)

Today you wire stages imperatively. A builder lets you *declare* a pipeline as data, reuse it, serialize it, or validate it before execution.

```csharp
// ── IPipelineBuilder.cs ──────────────────────────────────────────────
public interface IPipelineBuilder<TContext> where TContext : class
{
    IPipelineBuilder<TContext> Stage(IPipelineStage<TContext> stage, IAsyncPolicy? policy = null);
    IPipelineBuilder<TContext> Middlewares(params Func<StageExecutionContext<TContext>, Func<Task>, CancellationToken, Task>[[]] middlewares);
    IPipelineBuilder<TContext> Name(string name);

    /// <summary>Validates structure (unique names, no orphan deps) and materialises the runner.</summary>
    IPipeline<TContext> Build();
}

// ── PipelineBuilder.cs ───────────────────────────────────────────────
public sealed class PipelineBuilder<TContext> : IPipelineBuilder<TContext> where TContext : class
{
    private readonly string? _name;
    private readonly List<(IPipelineStage<TContext> Stage, IAsyncPolicy? Policy)> _stages = [[]];
    private readonly List<Func<StageExecutionContext<TContext>, Func<Task>, CancellationToken, Task>> _middlewares = [[]];

    public IPipelineBuilder<TContext> Name(string name) { _name = name; return this; }

    public IPipelineBuilder<TContext> Stage(IPipelineStage<TContext> stage, IAsyncPolicy? policy = null)
    {
        _stages.Add((stage, policy));
        return this;
    }

    public IPipelineBuilder<TContext> Middlewares(
        params Func<StageExecutionContext<TContext>, Func<Task>, CancellationToken, Task>[[]] mws)
    {
        _middlewares.AddRange(mws);
        return this;
    }

    public IPipeline<TContext> Build()
    {
        // structural validation
        var names = _stages.Select(s => s.Stage.Name).ToList();
        var dups = names.GroupBy(n => n).Where(g => g.Count() > 1).Select(g => g.Key).ToList();
        if (dups.Count > 0)
            throw new InvalidOperationException($"Duplicate stage names: {string.Join(", ", dups)}");

        var runner = new PipelineRunner<TContext>(
            Microsoft.Extensions.Logging.Abstractions.NullLogger<TContext>.Instance);

        foreach (var mw in _middlewares)
            runner.UseMiddleware(mw);

        foreach (var (stage, policy) in _stages)
            runner.AddStage(stage, policy);

        return runner;
    }
}
```

**Usage – a pipeline becomes a one-liner you can pass around, store, or parameterise:**

```csharp
// ── Building the "embed" pipeline ────────────────────────────────────
var embedPipeline = new PipelineBuilder<EmbeddingContext>()
    .Name("embed")
    .Middlewares(
        (ctx, next, ct) => new ProgressMiddleware(writer).Invoke(ctx, next, ct),
        (ctx, next, ct) => new StageTimingMiddleware(logger).Invoke(ctx, next, ct))
    .Stage(new BrandingStage(logger, header))
    .Stage(new QuestionLoadStage(logger, questionStore))
    .Stage(new DeltaEmbedStage(logger, fingerprintStore, writer, options))
    .Build();

// ── Building a "dry-run" pipeline (no writes) ────────────────────────
var dryRun = new PipelineBuilder<EmbeddingContext>()
    .Name("dry-run")
    .Middlewares((ctx, next, ct) => new StageTimingMiddleware(logger).Invoke(ctx, next, ct))
    .Stage(new BrandingStage(logger, header))
    .Stage(new QuestionLoadStage(logger, questionStore))
    .Stage(new DryRunReportStage(logger))          // ← no Qdrant write
    .Build();
```

Now `IPipeline<T>` is a **value you can inject, clone, or swap at runtime** without touching `PipelineRunner` internals.

## 2. Stage Composition – Sub-Pipelines as Stages

The biggest reusability gap: a stage is a *leaf*. Let a stage **be** a pipeline so you nest workflows.

```csharp
// ── CompositeStage.cs ────────────────────────────────────────────────
/// <summary>
/// Wraps an entire pipeline as a single stage.  Use it to group
/// logical phases (e.g. "Parse → Embed → Index") so a parent
/// pipeline can treat the whole phase atomically.
/// </summary>
public sealed class CompositeStage<TContext> : IPipelineStage<TContext> where TContext : class
{
    private readonly IPipeline<TContext> _inner;
    private readonly string              _name;
    private readonly IAsyncPolicy?       _policy;

    public CompositeStage(IPipeline<TContext> innerPipeline, string? name = null, IAsyncPolicy? policy = null)
    {
        _inner  = innerPipeline ?? throw new ArgumentNullException(nameof(innerPipeline));
        _name   = name ?? "Composite";
        _policy = policy;
    }

    public string Name => _name;
    public AsyncRetryPolicy? RetryPolicy => _policy as AsyncRetryPolicy;

    public bool ShouldRun(TContext context) => true; // delegate to inner stages

    public async Task ExecuteAsync(TContext context, CancellationToken ct)
        => await _inner.ExecuteAsync(context, ct).ConfigureAwait(false);
}
```

**Now your top-level pipeline reads like a table of contents:**

```csharp
var parsePhase = new PipelineBuilder<EmbeddingContext>()
    .Stage(new FileDiscoveryStage(logger, discoverySvc, options))
    .Stage(new ParseStage(logger, parseFactory))
    .Build();

var indexPhase = new PipelineBuilder<EmbeddingContext>()
    .Stage(new EmbedStage(logger, embeddingSvc, options))
    .Stage(new DeltaEmbedStage(logger, fpStore, writer, options))
    .Build();

var fullPipeline = new PipelineBuilder<EmbeddingContext>()
    .Name("ragnar-full")
    .Middlewares(timingMiddleware)
    .Stage(new BrandingStage(logger, header))
    .Stage(new CompositeStage<EmbeddingContext>(parsePhase, "Parse Phase"))
    .Stage(new CompositeStage<EmbeddingContext>(indexPhase, "Index Phase"))
    .Build();
```

Each phase is independently testable, retryable (attach a policy to the `CompositeStage`), and swappable.

## 3. Stage Decorators (Cross-Cutting, Without Subclassing)

Your middleware chain is powerful but only lives at the **runner** level. Decorators let you attach behaviour to **individual stages** without modifying them.

```csharp
// ── IStageDecorator.cs ───────────────────────────────────────────────
public interface IStageDecorator<in TContext> where TContext : class
{
    IPipelineStage<TContext> Decorate(IPipelineStage<TContext> stage);
}

// ── RetryStageDecorator.cs ───────────────────────────────────────────
public sealed class RetryStageDecorator<TContext> : IStageDecorator<TContext> where TContext : class
{
    private readonly ILogger _logger;
    private readonly int     _maxAttempts;
    private readonly Func<int, TimeSpan> _delayFor;

    public RetryStageDecorator(ILogger logger, int maxAttempts = 3,
                               Func<int, TimeSpan>? delayFor = null)
    {
        _logger     = logger;
        _maxAttempts = maxAttempts;
        _delayFor    = delayFor ?? (a => TimeSpan.FromSeconds(2 * Math.Pow(2, a)));
    }

    public IPipelineStage<TContext> Decorate(IPipelineStage<TContext> stage)
        => new RetryDecoratedStage<TContext>(stage, _logger, _maxAttempts, _delayFor);

    private sealed class RetryDecoratedStage<TC> : IPipelineStage<TC> where TC : class
    {
        private readonly IPipelineStage<TC> _inner;
        private readonly ILogger            _log;
        private readonly int                _max;
        private readonly Func<int, TimeSpan> _delay;

        public RetryDecoratedStage(IPipelineStage<TC> inner, ILogger log, int max, Func<int, TimeSpan> delay)
        { _inner = inner; _log = log; _max = max; _delay = delay; }

        public string Name => $"Retry({_inner.Name})";
        public AsyncRetryPolicy? RetryPolicy => null;   // handled internally
        public bool ShouldRun(TC ctx) => _inner.ShouldRun(ctx);

        public async Task ExecuteAsync(TC ctx, CancellationToken ct)
        {
            for (var attempt = 0; ; attempt++)
            {
                try
                {
                    await _inner.ExecuteAsync(ctx, ct).ConfigureAwait(false);
                    return;
                }
                catch (OperationCanceledException) when (ct.IsCancellationRequested) { throw; }
                catch (Exception ex) when (attempt < _max - 1)
                {
                    var d = _delay(attempt);
                    _log.LogWarning(ex, "{Name} attempt {A}/{M} failed; retrying in {Delay}",
                                    _inner.Name, attempt + 1, _max, d);
                    await Task.Delay(d, ct).ConfigureAwait(false);
                }
            }
        }
    }
}
```

**Apply per-stage without touching the stage class:**

```csharp
var resilientParse = new RetryStageDecorator<EmbeddingContext>(logger, maxAttempts: 5)
                     .Decorate(new ParseStage(logger, parseFactory));

var pipeline = new PipelineBuilder<EmbeddingContext>()
    .Stage(resilientParse)          // 5 retries, exponential back-off
    .Stage(new DeltaEmbedStage(logger, fpStore, writer, options))
    .Build();
```

You can stack decorators:

```csharp
var stage = new LoggingStageDecorator(logger).Decorate(
              new TimeoutStageDecorator(TimeSpan.FromSeconds(30)).Decorate(
                  new ParseStage(logger, parseFactory)));
```

## 4. Typed Context Hierarchy (Inheritance via Composition)

Right now `QuestionPipelineContext` and `EmbeddingContext` are independent. Make contexts **composable** so a child pipeline can see the parent's state.

```csharp
// ── PipelineContextBase.cs ───────────────────────────────────────────
public abstract record PipelineContextBase
{
    /// <summary>Optional parent context for nested pipelines.</summary>
    public PipelineContextBase? Parent { get; init; }

    /// <summary>Walking up the chain, find the nearest context of type T.</summary>
    public T? FindAncestor<T>() where T : PipelineContextBase
    {
        for (var c = Parent; c is not null; c = c.Parent)
            if (c is T t) return t;
        return null;
    }
}

// ── EmbeddingContext now carries a parent ────────────────────────────
public sealed record EmbeddingContext : PipelineContextBase
{
    public IReadOnlyList<CodeDocument> Documents { get; init; } = [[]];
    // ...
}

// ── QuestionContext inherits from EmbeddingContext ───────────────────
public sealed record QuestionContext : PipelineContextBase
{
    public IReadOnlyList<Question> Questions { get; init; } = [[]];
}
```

A child pipeline stage can then **reach up** to the parent context:

```csharp
public sealed class QuestionAnswerStage : IPipelineStage<QuestionContext>
{
    public async Task ExecuteAsync(QuestionContext ctx, CancellationToken ct)
    {
        // reach into the parent embedding context for documents
        var parent = ctx.FindAncestor<EmbeddingContext>()
            ?? throw new InvalidOperationException("QuestionContext must be nested under EmbeddingContext.");

        var docs = parent.Documents;
        // ...
    }
}
```

## 5. Pipeline Registry + DI (First-Class Services)

Register named pipelines so any part of the app can **resolve** one by name:

```csharp
// ── IPipelineRegistry.cs ─────────────────────────────────────────────
public interface IPipelineRegistry
{
    void Register<TContext>(string name, IPipeline<TContext> pipeline) where TContext : class;
    IPipeline<TContext> Resolve<TContext>(string name) where TContext : class;
    IReadOnlyCollection<string> Names<TContext>() where TContext : class;
}

public sealed class PipelineRegistry : IPipelineRegistry
{
    private readonly ConcurrentDictionary<(Type, string), object> _store = new();

    public void Register<TContext>(string name, IPipeline<TContext> p) where TContext : class
        => _store[[(typeof(TContext), name)]] = p;

    public IPipeline<TContext> Resolve<TContext>(string name) where TContext : class
        => (IPipeline<TContext>)(_store[[(typeof(TContext), name)]]
            ?? throw new KeyNotFoundException($"Pipeline '{name}' not registered for {typeof(TContext).Name}"));

    public IReadOnlyCollection<string> Names<TContext>() where TContext : class
        => _store.Keys.Where(k => k.Item1 == typeof(TContext)).Select(k => k.Item2).ToList();
}
```

**Register at startup:**

```csharp
builder.Services.AddSingleton<IPipelineRegistry, PipelineRegistry>();
builder.Services.AddSingleton(sp =>
{
    var reg    = sp.GetRequiredService<IPipelineRegistry>();
    var logger = sp.GetRequiredService<ILogger>();
    // ... resolve other deps ...

    reg.Register<EmbeddingContext>("ragnar-full", fullPipeline);
    reg.Register<EmbeddingContext>("ragnar-dry-run", dryRunPipeline);
    return reg;
});
```

**Resolve anywhere:**

```csharp
var pipeline = registry.Resolve<EmbeddingContext>("ragnar-full");
await pipeline.ExecuteAsync(ctx, ct);
```

## 6. Pipeline Snapshot / Replay (Serializable Definitions)

Capture the *structure* of a pipeline so you can log it, persist it, or replay it:

```csharp
// ── PipelineSnapshot.cs ──────────────────────────────────────────────
public sealed record PipelineSnapshot
{
    public required string Name { get; init; }
    public required string ContextType { get; init; }
    public required List<StageSnapshot> Stages { get; init; }
    public required List<string> Middlewares { get; init; }
    public DateTime CreatedAt { get; init; } = DateTime.UtcNow;
}

public sealed record StageSnapshot
{
    public required int Index { get; init; }
    public required string Name { get; init; }
    public required string Type { get; init; }
    public bool HasRetryPolicy { get; init; }
}

// ── extension on IPipeline ───────────────────────────────────────────
public static PipelineSnapshot Snapshot(this PipelineRunner<TContext> runner) where TContext : class
{
    // PipelineRunner needs to expose its stages read-only
    // (add an internal accessor or use the existing _stages under lock)
    var stages = runner.StageNames
        .Select((n, i) => new StageSnapshot
        {
            Index          = i,
            Name           = n,
            Type           = "…",   // runner would expose StageEntry types
            HasRetryPolicy = false  // extend as needed
        }).ToList();

    return new PipelineSnapshot
    {
        Name        = nameof(PipelineRunner<TContext>),
        ContextType = typeof(TContext).Name,
        Stages      = stages,
        Middlewares = [[]],  // extend to capture middleware type names
    };
}
```

Serialise to JSON for audit logs, or POST to an ops dashboard.

## 7. Stage Lifecycle Hooks (Before / After / OnError)

Let consumers attach logic **without** subclassing every stage:

```csharp
// ── IStageHooks.cs ───────────────────────────────────────────────────
public interface IStageHooks<in TContext> where TContext : class
{
    Task BeforeExecuteAsync(TContext ctx, CancellationToken ct);
    Task AfterExecuteAsync(TContext ctx, CancellationToken ct);
    Task OnErrorAsync(TContext ctx, Exception ex, CancellationToken ct);
}

// ── HookedStage.cs ───────────────────────────────────────────────────
public sealed class HookedStage<TContext> : IPipelineStage<TContext> where TContext : class
{
    private readonly IPipelineStage<TContext> _inner;
    private readonly IStageHooks<TContext>    _hooks;

    public HookedStage(IPipelineStage<TContext> inner, IStageHooks<TContext> hooks)
    { _inner = inner; _hooks = hooks; }

    public string Name => _inner.Name;
    public AsyncRetryPolicy? RetryPolicy => _inner.RetryPolicy;
    public bool ShouldRun(TContext ctx) => _inner.ShouldRun(ctx);

    public async Task ExecuteAsync(TContext ctx, CancellationToken ct)
    {
        await _hooks.BeforeExecuteAsync(ctx, ct).ConfigureAwait(false);
        try
        {
            await _inner.ExecuteAsync(ctx, ct).ConfigureAwait(false);
            await _hooks.AfterExecuteAsync(ctx, ct).ConfigureAwait(false);
        }
        catch (Exception ex)
        {
            await _hooks.OnErrorAsync(ctx, ex, ct).ConfigureAwait(false);
            throw;
        }
    }
}
```

```csharp
// Example: metrics + tracing hooks
var hooks = new OtlpTracingHooks<EmbeddingContext>(meterProvider, tracer);
var stage = new HookedStage<EmbeddingContext>(new ParseStage(logger, factory), hooks);
```

## Summary of What to Add (Priority Order)

| # | Piece | Effort | Impact |
|---|-------|--------|--------|
| 1 | **`PipelineBuilder<T>`** | S | Declarative, testable, serialisable pipelines |
| 2 | **`CompositeStage<T>`** | S | Nested / phase-level reuse, atomic retry |
| 3 | **`IStageDecorator<T>`** + 2-3 impls | M | Per-stage retry / timeout / logging without subclassing |
| 4 | **`IPipelineRegistry`** in DI | S | Resolve pipelines by name; swap at runtime |
| 5 | **`IStageHooks<T>`** + `HookedStage` | M | Observability (OTel, metrics) without touching stage code |
| 6 | **`PipelineSnapshot`** | S | Audit, replay, ops dashboards |
| 7 | **Context inheritance** (`FindAncestor<T>`) | M | Nested pipelines see parent state |

Each piece is **additive**—none require changing `PipelineRunner<TContext>` or `IPipelineStage<TContext>`, so your existing `BrandingStage`, `DeltaEmbedStage`, and middleware keep working unchanged. Start with items 1–3 and you'll immediately be able to compose, test, and swap pipelines in a way that's easy for the next person (or the next feature) to pick up.

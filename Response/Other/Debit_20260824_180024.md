### 🔴 Critical & High-Impact Debt

#### 1. Resource Leaks & Expensive Object Creation
**Location:** `SummaryAgent.AskAgent`
```csharp
ChatClientAgent agent = _agentChatClient.AsBuilder().UseFunctionInvocation().Build().AsAIAgent(...);
```
- **Issue:** You're building a new AI client pipeline on every call to `AskAgent`. This allocates significant memory, initializes middleware chains repeatedly, and leaks resources if not disposed.
- **Fix:** Cache the built agent or inject it as a scoped/singleton service via DI. Alternatively, use `_agentChatClient.AsAIAgent()` directly without rebuilding the builder each time.

#### 2. Unhandled Exceptions on Missing Directories
**Location:** `SummaryAgent.LoadFolderContentsAsync`
```csharp
var files = Directory.GetFiles(Folder);
```
- **Issue:** If `Folder` doesn't exist or lacks permissions, this throws a `DirectoryNotFoundException` or `UnauthorizedAccessException`, crashing the AI agent flow.
- **Fix:** Validate first:
  ```csharp
  if (!Directory.Exists(Folder)) return "Directory not found.";
  var files = Directory.GetFiles(Folder);
  ```

#### 3. Synchronous I/O in Async Context
**Location:** `SummaryAgent.LoadFolderContentsAsync`
```csharp
using var reader = File.OpenText(file);
var text = await reader.ReadToEndAsync(Ct);
```
- **Issue:** `File.OpenText()` is a synchronous file handle creation that blocks the thread pool. In high-throughput scenarios, this degrades performance.
- **Fix:** Use fully async APIs:
  ```csharp
  var text = await File.ReadAllTextAsync(file, Ct);
  ```

### 🟡 Medium-Impact Debt

#### 4. Flaky Test Execution
**Location:** `StaticExtensionsTests.ElapsedTimeString_FormatsCorrectly`
```csharp
Task.Delay(100, TestContext.Current.CancellationToken); // Missing await!
var formatted = sw.ElapsedTimeString();
```
- **Issue:** The delay is fire-and-forget. The test asserts immediately, making it non-deterministic and prone to random pass/fail results.
- **Fix:** `await Task.Delay(100, TestContext.Current.CancellationToken);`

#### 5. Invalid C# Syntax / Pseudo-code
**Location:** `AssemblyExtensions`
```csharp
extension(IAssemblyInfo Asm) { ... } // Not valid C# syntax
```
- **Issue:** `extension` is not a C# keyword. This will fail to compile. It appears to be pseudo-code or a typo for an extension method.
- **Fix:** Standardize to:
  ```csharp
  public static string? GetInformationalVersion(this IAssemblyInfo asm) => ...
  ```

#### 6. Fragile Configuration Resolution
**Location:** `RagnarConfig.json` & `Utils.ExpandDirectory`
```json
"SourceDirectory": "%USERPROFILE%\\source\\Ragnar\\"
```
- **Issue:** Relying on environment variables in static JSON configs breaks across environments (Linux/macOS use `$HOME`, Windows uses `%USERPROFILE%`). `Environment.ExpandEnvironmentVariables` also silently passes through invalid vars like `%NONEXISTENT%`.
- **Fix:** Resolve paths at application startup using `Path.Combine(Environment.GetFolderPath(Environment.SpecialFolder.UserProfile), "source", "Ragnar")` or use a dedicated configuration provider that handles platform-agnostic path resolution.

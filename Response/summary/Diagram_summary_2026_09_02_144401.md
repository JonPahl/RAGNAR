### What Ragnar Does
A four-stage pipeline CLI tool:

1. **Branding** – renders a console header.
2. **Embed** – discovers source files, filters/parses them (`.cs`, `.json`, etc.), calls **Ollama** for 768-dim embeddings, and upserts vectors into **Qdrant**.
3. **Query** – merges questions from CSV, config, and plugin DLLs (`IQuestionProvider`), sends each to Ollama's chat endpoint, streams tokens live via **Spectre.Console**, and writes timestamped `.md` responses under `Response/{Category}/`.
4. **Summarize** – walks the saved response folders, composes a summary prompt, calls the LLM again, and writes a consolidated summary.

### Key Design Patterns
| Pattern | Where |
|---|---|
| **Pipeline (IPipelineStage)** | Sequences the 4 stages |
| **Factory (cached)** | `OllamaClientFactory` – `ConcurrentDictionary` cache for LLM/embedding clients |
| **Builder** | `QuestionCombineBuilder`, `VectorStoreBuilder` |
| **Repository** | `VectorStoreRepository` isolates Qdrant upserts |
| **Strategy / Plugin** | `IFileValidator`, `IFilterStrategy`, `IQuestionProvider` (loaded via reflection from `Plugins/` DLLs) |
| **Interface-driven DI** | Nearly every service behind an interface, registered in the DI host via `ApplicationConfigurationExtensions` |

### Qdrant Data Model
- **768-dim vectors**, Cosine distance.
- Payload: `ElementName`, `Code`, `Category`, `FileName`, `FilePath`.
- Keyword indexes on `ElementName` and `Category` for filtered retrieval.

### Notable Recommendations Surfaced by the Diagrams
1. **`BATCHSIZE = 1`** on Qdrant upserts – biggest perf win is to batch (10–50) and use `UpsertBatchAsync`.
2. **No retry/circuit-breaker** around Ollama/Qdrant HTTP calls – a transient hiccup aborts the whole pipeline. Add Polly.
3. **Plugin loading is tangled** with DI registration and reflection – extract a dedicated `PluginLoader` service.
4. **Prompt fragments are duplicated** across `PromptTemplateProvider`, `SummarizePromptProvider`, and hard-coded strings in `ContentSummarizerAgent` / `SummaryService`.
5. **Parser selection** (`.cs` vs `.json` vs other) is conditional branching – a parser factory/registry would be cleaner.

### 🔴 1. Critical: `O(N²)` Index Lookup in Parallel File Reading
**Location:** `SummaryAgent.LoadFolderContentsAsync`
```csharp
// Current (Problematic)
await Parallel.ForEachAsync(files, new ParallelOptions { CancellationToken = Ct }, async (file, token) =>
{
    int index = Array.IndexOf(files, file); // ❌ O(N) per iteration → O(N²) total!
    var text = await File.ReadAllTextAsync(file, token);
    contents[index] = $"---\n[RESPONSE_FILE]{Path.GetFileName(file)}[/RESPONSE_FILE]\n{text}\n";
});
```
**Why it hurts:** `Array.IndexOf` scans the entire array for every file. In a parallel loop, this completely negates concurrency benefits and causes severe CPU thrashing on directories with hundreds of files.

**✅ Fix:** Since each file is already tagged with its name, order preservation isn't required. Use a concurrent collection or an atomic index counter:
```csharp
private static async Task<string> LoadFolderContentsAsync(string folder, CancellationToken ct)
{
    var files = Directory.EnumerateFiles(folder).ToArray(); // ✅ Enumerate first to avoid memory bloat on huge dirs
    Guard.Against.NullOrEmpty(files);

    var contents = new string[files.Length];
    int index = 0;

    await Parallel.ForEachAsync(files, new ParallelOptions { CancellationToken = ct }, async (file, token) =>
    {
        // ✅ Atomic counter avoids O(N²) lookup
        int localIndex = Interlocked.Increment(ref index) - 1;
        var text = await File.ReadAllTextAsync(file, token);
        contents[localIndex] = $"---\n[RESPONSE_FILE]{Path.GetFileName(file)}[/RESPONSE_FILE]\n{text}\n";
    });

    return "[RESPONSE_CODE] " + string.Join("", contents) + "[/RESPONSE_CODE]";
}
```

**Why it hurts:** `ToObject()` triggers System.Text.Json (or Newtonsoft) deserialization for every scored point. If payloads contain large strings or nested objects, this becomes a major CPU bottleneck during high-concurrency searches.

**✅ Fix:** Access payload properties directly via indexer or use a lightweight DTO if the Qdrant client supports it:
```csharp
private static string FormatContext(IReadOnlyList<ScoredPoint> Results)
{
    var sb = new StringBuilder(Results.Count * 256); // ✅ Pre-allocate based on expected count
    foreach (var point in Results)
    {
        // ✅ Direct property access avoids deserialization overhead
        var payload = point.Payload;
        sb.AppendLine($"File Name: {payload["file_name"]?.ToString() ?? "N/A"} | Type: {payload["type"]?.ToString() ?? "N/A"} | Element: {payload["element_name"]?.ToString() ?? "N/A"}");
        sb.AppendLine(payload["code"]?.ToString() ?? string.Empty);
    }
    return sb.ToString();
}
```

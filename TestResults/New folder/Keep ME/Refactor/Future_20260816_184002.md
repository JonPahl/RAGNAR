When retrieving results, use `line_start`/`line_end` to reconstruct exact context for the LLM without over-fetching.

#### ✅ C. Sparse-Dense Hybrid Search (Optional but Powerful)
For code, semantic similarity alone can miss exact symbol matches. Qdrant supports hybrid search:
- Use a **dense vector** for semantic meaning (your current embedding).
- Add a **sparse vector** or use Qdrant's `SparseVector` index for lexical/symbol matching.
- Combine via weighted scoring during retrieval to balance "what it means" vs "exact token match".

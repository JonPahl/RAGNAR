**Location:** `RagPipelineHostBuilder.cs` → `RegisterQuestionPlugins()`

**Risk:** Loading any `.dll` from a directory without cryptographic verification or strict allowlisting enables **DLL Hijacking/Injection**. ### 🟠 High: Path Traversal & Unrestricted File Writes
**Locations:** 
- `SavePathExtension.cs` → `GetResponseDirectory(IList<string> folders, string baseDir)`
- `ResponseWriter.cs` → `WriteResponseAsync()`

**Risk:** `Path.Combine` does not prevent directory traversal. If `baseDir`, `folders`, or `SourceDirectory` configuration contains `../` or absolute paths, the application can write outside its intended sandbox, potentially overwriting system files or leaking data.

**Fix:** Canonicalize paths and enforce a strict base directory boundary.

```csharp
public static string GetSafeResponseDirectory(string baseDir, IList<string> folders)
{
    var safeBase = Path.GetFullPath(baseDir);
    var combined = folders.Count == 0 
        ? Path.Combine(safeBase, "Response") 
        : folders.Aggregate(safeBase, Path.Combine);

    var resolved = Path.GetFullPath(combined);
    
    // Enforce boundary check
    if (!resolved.StartsWith(safeBase, StringComparison.OrdinalIgnoreCase))
        throw new SecurityException("Path traversal detected: output directory must remain within the base path.");
        
    return resolved;
}
```

**Location:** `RegisterOptions()`
```csharp

        .ValidateDataAnnotations().ValidateOnStart();
```
**Risk:** Data annotations alone don't validate security-sensitive fields like URLs, file paths, or network endpoints. Malicious config could point to internal metadata services, local sockets, or untrusted vector stores.

**Fix:** Add custom validators for critical configuration sections.

```csharp
// Example: OllamaOptions Validator
public class OllamaOptionsValidator : AbstractValidator<OllamaOptions>
{
    public OllamaOptionsValidator()
    {
        RuleFor(x => x.Host)
            .Must(h => h.StartsWith("http://localhost", StringComparison.OrdinalIgnoreCase) || 
                       Uri.TryCreate(h, UriKind.Absolute, out _) && new Uri(h).IsLoopback)
            .WithMessage("Ollama host must be localhost or loopback for security.");
            
        RuleFor(x => x.Port).InclusiveBetween(1024, 65535);
    }
}
```

#### 🔧 Fix 1: Performance Bug in `LoadFolderContentsAsync`
**Problem**: `Array.IndexOf(files, file)` inside a parallel loop makes this **O(n²)**. For large directories, this will cause severe performance degradation.

**✅ Fixed Version:**
```csharp
private static async Task<string> LoadFolderContentsAsync(string folder, CancellationToken ct)
{
    var files = Directory.GetFiles(folder);
    Guard.Against.NullOrEmpty(files);

    var contents = new string[files.Length];
    
    // Use Parallel.ForAsync to safely pass the index without O(n²) lookup
    await Parallel.ForAsync(0, files.Length, new ParallelOptions { CancellationToken = ct }, async (i, token) =>
    {
        var file = files[i];
        var text = await File.ReadAllTextAsync(file, token);
        contents[i] = $"---\n[RESPONSE_FILE]{Path.GetFileName(file)}[/RESPONSE_FILE]\n{text}\n";
    });

    return "[RESPONSE_CODE] " + string.Join("", contents) + "[/RESPONSE_CODE]";
}
```

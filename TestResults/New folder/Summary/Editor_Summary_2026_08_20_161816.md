- **Prefer Idiomatic C# Patterns:** Encourage null propagation (`?.`) and throw expressions to replace verbose null checks.
- **Use var Judiciously:** Enable type inference for improved readability, reserving explicit types only where clarity matters.

#### Implementation Priorities
1.  **Solution-Root Placement:** Place `.editorconfig` at the solution root to ensure cascading consistency across all projects and IDEs.
2.  **Severity Calibration:** Start with `suggestion`. Escalate to `warning` or `error` only after team alignment and automated formatting are stable.
3.  **IDE Sync:** Ensure "Format on Save" and Roslyn analyzer support are enabled in all developer environments.
4.  **Architectural Overrides:** Customize config at the project level only for specific patterns (e.g., MediatR handlers, gRPC contracts) that require deviations from the baseline.

- Review rules quarterly to align with new C# releases (e.g., primary constructors, pattern matching).
- Document convention rationale in a team wiki to reduce onboarding friction.
- Monitor analyzer warnings via IDE dashboards or CI logs to track adoption and identify legacy code for refactoring.

#### 1. Path Traversal & Arbitrary File Reading in `SummaryAgent`
**Location:** `SummaryAgent.LoadFolderContentsAsync()`
```csharp
var files = Directory.GetFiles(Folder);
// ...
await Parallel.ForEachAsync(files, ..., async (file, token) => {
    int index = Array.IndexOf(files, file); // ⚠️ Race condition + unsafe path usage
    var text = await File.ReadAllTextAsync(file, token);
```
**Risk:** If `Folder` originates from user input or untrusted config, an attacker could pass `C:\Windows\`, `/etc/`, or `..\..\secrets.json` to read sensitive files. Additionally, `Array.IndexOf` inside a parallel loop is a **race condition bug** that will corrupt data or crash the app.
**Fix:** Validate paths against a safe base directory and use index-safe parallel iteration:
```csharp
private static async Task<string> LoadFolderContentsAsync(string folder, CancellationToken Ct)
{
    // 1. Enforce base directory boundary
    var baseDir = Path.GetFullPath(folder);
    if (!baseDir.StartsWith(AppContext.BaseDirectory, StringComparison.OrdinalIgnoreCase))
        throw new UnauthorizedAccessException("Access to this directory is not allowed.");

    var files = Directory.GetFiles(baseDir, "*", SearchOption.TopDirectoryOnly);
    Guard.Against.NullOrEmpty(files);

    var contents = new string[files.Length];
    // 2. Safe parallel indexing
    Parallel.For(0, files.Length, new ParallelOptions { CancellationToken = Ct }, i =>
    {
        contents[i] = $"---\n[RESPONSE_FILE]{Path.GetFileName(files[i])}[/RESPONSE_FILE]\n{File.ReadAllText(files[i], Ct)}\n";
    });

    return "[RESPONSE_CODE] " + string.Join("", contents) + "[/RESPONSE_CODE]";
}
```

## 📖 Overview
Ragnar is a high-performance, AI-augmented code analysis engine built in C#/.NET. It combines **local LLM inference** (via Ollama), **vector search** (Qdrant), and **structured pipeline processing** to automatically generate contextual summaries, answer domain-specific questions, and output categorized markdown reports from source repositories.

Designed for developers who want deterministic, auditable AI-assisted code reasoning without cloud dependencies.

## 🏗️ Architecture & Workflow
```mermaid
graph TD
    A[[Source Directory]] --> B(FileLoadOptions & Filters)
    B --> C{CodeDocument[[]]}
    C --> D[[OllamaEmbeddingService]]
    D --> E[[QdrantVectorStoreBuilder]]
    E --> F[[(Qdrant DB)]]
    F --> G[[SummaryAgent / IQuestionProvider]]
    G --> H[[IOutputFormatter]]
    H --> I[[ResponseWriter → Markdown Files]]
```

1. **Ingestion**: Scans directories, applies `FileLoadOptions` & `IFilterStrategy` (e.g., `XmlCommentFilterStrategy`)
2. **Embedding**: Generates float vectors via Ollama's embedding model (`nomic-embed-text` by default)
3. **Indexing**: Upserts points to Qdrant with payload metadata (`FileName`, `ElementName`, etc.)
4. **Query**: `SummaryAgent` routes prompts through `IPromptProvider` & `IOllamaResponse`
5. **Output**: Formats responses via `IOutputFormatter` and persists to categorized directories using `PathResolver`

## ⚙️ Configuration
Ragnar uses a hierarchical `RagnarConfig.json` with environment variable support. All paths are automatically expanded via `Environment.ExpandEnvironmentVariables`.

### 📄 Example Config (`appsettings.json`)
```json
{
  "RagnarConfig": {
    "ApplicationOptions": {
      "SourceDirectory": "%USERPROFILE%\\source\\repos\\MyProject\\",
      "VectorStoreName": "programming_docs",
      "Monitor": null,
      "CategoriesToProcess": [[]],
      "IncludeOriginalPrompt": false
    },
    "EmbeddingOptions": {
      "Timeout": "00:05:00",
      "Host": "localhost",
      "Port": 6334,
      "EmbeddingModel": "nomic-embed-text",
      "Dimension": 768
    },
    "FileLoadOptions": {
      "AllowedFileExtensions": [[ ".cs", ".json", ".editorconfig" ]],
      "ExcludedFiles": [[ "docker-compose.yml" ]],
      "ExcludedDirectories": [[ "qdrant_storage", "Response", "obj", "bin", ".git", "Logs" ]]
    },
    "OllamaOptions": {
      "Timeout": "00:30:00",
      "LlmModel": "qwen3.6",
      "Port": 11434,
      "Host": "localhost"
    }
  },
  "Serilog": {
    "MinimumLevel": { "Default": "Information" },
    "WriteTo": [[
      { "Name": "Seq", "Args": { "serverUrl": "http://localhost:5341" } },
      { "Name": "File", "Args": { "path": "logs/log-.txt", "rollingInterval": "Day" } }
    ]]
  }
}
```

> 💡 **Validation**: `OllamaOptionsValidator` enforces port ranges, non-empty hosts, and positive timeouts at startup.

## 🚀 Getting Started

### 1. Clone & Build
```bash
git clone https://github.com/[[your-username]]/ragnar.git
cd ragnar
dotnet restore
dotnet build --configuration Release
```

### 2. Configure & Run
Ensure Ollama is serving your chosen model:
```bash
ollama pull qwen3.6
ollama pull nomic-embed-text
```

Run with custom config:
```bash
dotnet run --project src/Ragnar.App -- --config ./appsettings.json
```

### 3. Load Questions (Optional)
Provide a CSV file via `IQuestionProvider` for batched reasoning:
```csv
FileName,Category,IsActive,Text
Program.cs,Coding,True,How does the authentication pipeline work?
appsettings.json,Config,True,What are the required environment variables?
```

#### 1. **Path Traversal Vulnerability in `ResponseWriter.BuildDirectory`**
```csharp
private static string BuildDirectory(string sourceDirectory, string? category)
{
    var baseDir = string.IsNullOrWhiteSpace(category) ? "Uncategorized" : category;
    var responseDir = Path.Join(sourceDirectory, "Response");
    var targetDir = Path.Join(responseDir, baseDir);
    Directory.CreateDirectory(targetDir); // ✅ Safe: creates if missing, does nothing if exists
    return targetDir;
}
```

**Risk**: If `category` (e.g., from user input or question metadata) contains `..` or absolute paths (e.g., `../../etc/passwd`), it could cause directory traversal and unintended file creation outside the intended `sourceDirectory`.

**Example malicious input**:  
`category = "Response/../../../etc"` → `targetDir = "C:\...\Response\..\..\..\etc"`

✅ `Path.Join` *does* normalize paths (e.g., `a\..\b` → `b`), but **does not prevent traversal beyond the root** if `sourceDirectory` is not canonicalized first.

**Fix**:
```csharp
private static string BuildDirectory(string sourceDirectory, string? category)
{
    var baseDir = string.IsNullOrWhiteSpace(category) ? "Uncategorized" : category;

    // 1. Normalize and validate sourceDirectory
    var normalizedSource = Path.GetFullPath(sourceDirectory);
    
    // 2. Construct full path
    var responseDir = Path.Join(normalizedSource, "Response");
    var targetDir = Path.Join(responseDir, baseDir);

    // 3. Ensure targetDir is still under normalizedSource (prevents traversal)
    var normalizedTarget = Path.GetFullPath(targetDir);
    if (!normalizedTarget.StartsWith(normalizedSource + Path.DirectorySeparatorChar, StringComparison.OrdinalIgnoreCase) 
        && normalizedTarget != normalizedSource)
    {
        throw new SecurityException($"Path traversal attempt detected: '{targetDir}'");
    }

    Directory.CreateDirectory(targetDir);
    return targetDir;
}
```

> ✅ **Best Practice**: Always validate resolved paths are within allowed boundaries using `Path.GetFullPath()` + prefix check.

#### 2. **Unsafe Use of `Environment.ExpandEnvironmentVariables` in `Utils.ExpandDirectory`**
```csharp
public static string ExpandDirectory(this string path)
{
    var expanded = Environment.ExpandEnvironmentVariables(path);
    var fullPath = Path.GetFullPath(expanded);
    if (!Directory.Exists(fullPath))
        throw new DirectoryNotFoundException($"Directory not found: '{fullPath}'");
    return fullPath;
}
```

**Risk**: If `path` contains malicious environment variables (e.g., `%TEMP%` pointing to a controlled directory), or if the app is run in a compromised environment, this could resolve to an unexpected location. More critically, **if `path` itself is user-controlled**, an attacker could inject environment variable syntax (e.g., `%PATH%`) to leak or manipulate paths.

**Example**:  
`path = "%PATH%"` → expands to system `PATH`, which is a colon/semicolon-separated list of directories — not a valid directory path.

**Fix**:
- Validate that environment variables used are *expected and safe* (e.g., only `%USERPROFILE%`, `%TEMP%`, etc.).
- Sanitize input: reject paths containing `%` unless explicitly allowed.
- Prefer explicit user configuration over dynamic expansion.

```csharp
private static readonly HashSet<string> AllowedEnvVars = new(StringComparer.OrdinalIgnoreCase)
{
    "USERPROFILE", "TEMP", "TMP", "LOCALAPPDATA", "PROGRAMDATA"
};

public static string ExpandDirectory(this string path)
{
    // Reject paths with environment variables unless safe
    if (path.Contains('%'))
    {
        var matches = Regex.Matches(path, @"%([^%]+)%");
        foreach (Match m in matches)
        {
            if (!AllowedEnvVars.Contains(m.Groups[1].Value))
                throw new ArgumentException($"Disallowed environment variable: %{m.Groups[1].Value}%");
        }
    }

    var expanded = Environment.ExpandEnvironmentVariables(path);
    var fullPath = Path.GetFullPath(expanded);
    if (!Directory.Exists(fullPath))
        throw new DirectoryNotFoundException($"Directory not found: '{fullPath}'");
    return fullPath;
}
```

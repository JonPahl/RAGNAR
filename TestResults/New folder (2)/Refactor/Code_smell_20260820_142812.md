### 🔴 **2. Violation of Single Responsibility Principle (SRP)**
#### ❌ Smell:
- `ResponseWriter` does **too much**:
  - Builds directory paths
  - Validates existence
  - Formats markdown
  - Writes files

- `SummaryAgent` mixes:
  - File loading
  - Prompt construction
  - Tool registration
  - LLM orchestration

#### ✅ Fix:
- **Split responsibilities**:
  - `DirectoryPathBuilder`, `MarkdownFormatter`, `FileWriter` → each with one job.
  - `SummaryAgent` → delegate file loading to `IFileLoader`, formatting to `IPromptFormatter`.

#### 🛠 Example:
```csharp
public interface IPathBuilder { string BuildResponsePath(string baseDir, string category); }
public interface IMarkdownFormatter { string Format(SaveDetails details); }
public interface IFileWriter { Task WriteAsync(string path, string content, CancellationToken ct); }
```

### 🔴 **3. Inconsistent/Unsafe Path Handling**
#### ❌ Smell:
- `GetResponseDirectory(IEnumerable<string> folders, string baseDir)` logic is **confusing**:
  ```csharp
  var FullPath = string.IsNullOrEmpty(BaseDir) ? ResponseDirectoryName : Path.Join(BaseDir, ResponseDirectoryName);
  return !Folders.Any() ? Folders.Aggregate(BaseDir, Path.Join) : FullPath;
  ```
  - If `folders` is empty, it returns `baseDir` (not `ResponseDir`!) — likely a bug.
  - `Folders.Aggregate(...)` with empty sequence throws `InvalidOperationException`.

#### ✅ Fix:
- **Simplify and validate**:
  ```csharp
  public static string GetResponseDirectory(this string baseDir) 
      => Path.Join(baseDir, Constants.ResponseDir);

  public static string GetResponseDirectory(this IEnumerable<string> folders, string baseDir = "")
  {
      var baseWithResponse = string.IsNullOrEmpty(baseDir) 
          ? Constants.ResponseDir 
          : Path.Join(baseDir, Constants.ResponseDir);
      return folders.Any() ? Path.Join(baseWithResponse, folders) : baseWithResponse;
  }
  ```

#### ❌ Smell:
- `QdrantSearchService.RetrieveContextAsync`:
  ```csharp

  ```

## 🔄 **RAG Pipeline Flow**
1. CLI prompt + source directory ingest
2. Files → embeddings via Ollama → stored in Qdrant (with payload metadata)
3. User query → embedding → filtered Qdrant search (e.g., empty comments)
4. Retrieved snippets → prompt + LLM → markdown response

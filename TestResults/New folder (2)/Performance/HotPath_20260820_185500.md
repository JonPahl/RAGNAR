### ✅ **1. `StringExtensions.CharacterCount()` — Use `ReadOnlySpan<char>`**
**Current:**
```csharp
public static int CharacterCount(this string xml)
{
    // likely loops over string, skipping tags (e.g., <...>)
}
```
**Optimization:**
- Replace with `ReadOnlySpan<char>` to avoid allocations.
- Use `stackalloc` for small buffers if needed.
- Avoid regex or repeated `string.Substring()`.

**Example:**
```csharp
public static int CharacterCount(this string xml)
{
    if (string.IsNullOrEmpty(xml)) return 0;

    var span = xml.AsSpan();
    int count = 0;
    bool inTag = false;

    for (int i = 0; i < span.Length; i++)
    {
        ref char c = ref span[i];
        if (c == '<')
        {
            inTag = true;
            // Skip closing '>' — avoid allocations
            int closeIdx = span.Slice(i + 1).IndexOf('>');
            if (closeIdx >= 0) i += closeIdx;
            else break; // malformed XML
        }
        else if (!inTag)
        {
            count++;
        }
        else if (c == '>')
        {
            inTag = false;
        }
    }

    return count;
}
```
✅ **Benefit:** Zero allocations, ~2–5× faster on large XML strings.

### ✅ **2. `SavePathExtensions.GetResponseDirectory()` — Use `Path.Join` with `Span`/`Memory`**
**Current:**
```csharp
public static string GetResponseDirectory(this IEnumerable<string> Folders, string BaseDir = "")
{
    var FullPath = string.IsNullOrEmpty(BaseDir) ? ResponseDirectoryName : Path.Join(BaseDir, ResponseDirectoryName);
    return !Folders.Any() ? Folders.Aggregate(BaseDir, Path.Join) : FullPath;
}
```
**Issue:** `Folders.Any()` + `Aggregate()` allocates enumerators and intermediate strings.

**Optimization:**
- Use `Path.Join` directly with `params string[]` or `ReadOnlySpan<string>`.
- Avoid LINQ for hot paths.

**Improved:**
```csharp
public static string GetResponseDirectory(this ReadOnlySpan<string> folders, string baseDir = "")
{
    var responseDir = Path.Join(baseDir, ResponseDirectoryName);
    return folders.IsEmpty ? responseDir : Path.Join(responseDir, folders);
}

// Overload for convenience:
public static string GetResponseDirectory(this IEnumerable<string> folders, string baseDir = "")
    => folders.ToArray().AsSpan().GetResponseDirectory(baseDir); // only allocate once
```
✅ **Benefit:** Eliminates per-call LINQ overhead; use `ReadOnlySpan<string>` in inner loops.

### ✅ **4. `SummaryAgent.LoadFolderContentsAsync()` — Parallelize + `Memory<char>`**
**Current:**
```csharp
await Parallel.ForEachAsync(files, ..., async (file, token) =>
{
    int index = Array.IndexOf(files, file); // ❌ O(n) per iteration!
    var text = await File.ReadAllTextAsync(file, token);
    contents[index] = $"---\n[RESPONSE_FILE]{Path.GetFileName(file)}[/RESPONSE_FILE]\n{text}\n";
});
```
**Issues:**
- `Array.IndexOf` is O(n) per loop → O(n²) total.
- String interpolation allocates.

**Optimization:**
```csharp
private static async Task<string> LoadFolderContentsAsync(string folder, CancellationToken ct)
{
    var files = Directory.GetFiles(folder);
    Guard.Against.NullOrEmpty(files);

    var contents = new string[files.Length];

    // Precompute indices to avoid O(n²)
    for (int i = 0; i < files.Length; i++)
    {
        var file = files[i];
        var fileName = Path.GetFileName(file);
        var prefix = $"---\n[RESPONSE_FILE]{fileName}[/RESPONSE_FILE]\n";
        
        // Use Memory<char> for prefix + async read
        var prefixSpan = prefix.AsMemory();
        var text = await File.ReadAllTextAsync(file, ct);
        contents[i] = $"{prefixSpan}{text}\n";
    }

    return "[RESPONSE_CODE] " + string.Join("", contents) + "[/RESPONSE_CODE]";
}
```
✅ **Benefit:** O(n) total, no redundant lookups; `string.Join` is highly optimized.

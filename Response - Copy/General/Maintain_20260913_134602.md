## Fixed Code Examples

### Fix 1 – O(n²) → O(n) batch chunking (`VectorStoreRepository`)

```csharp
// BEFORE  ──────────────────────────────────────────────────────────
for (var i = 0; i < docs.Count; i += batchSize)
{
    var batch = docs.Skip(i).Take(batchSize).ToList(); // O(n) each iter
    // …
}

// AFTER   ──────────────────────────────────────────────────────────
// Chunk once, iterate the resulting list of batches
var batches = docs.Chunk(batchSize);          // .NET 6+ – single pass, O(n)

foreach (var batch in batches)
{
    try
    {
        var texts  = batch.Select(d => $"Context: {d.ElementName}\nCode:\n{d.Code}").ToList();
        var vectors = await embeddingService.GenerateBatchAsync(texts, cancellationToken)
                                       .ConfigureAwait(false);

        var points = batch
            .Select((d, idx) => generatorService.BuildPointStructs(d.AsPoint(),
                           vectors[[idx]].Vector.ToArray(), d))
            .SelectMany(p => p)
            .ToList();

        await qdrantClient.UpsertAsync(_appOptions.VectorStoreName, points,
                                       cancellationToken: cancellationToken)
            .ConfigureAwait(false);

        succeeded += batch.Length;
    }
    catch (OperationCanceledException) { throw; }
    catch (Exception ex)
    {
        logger.Error(ex, "Batch upsert failed ({Count} docs).", batch.Length);
        failed.AddRange(batch.Select(d => (d, ex)));
    }
}
```

> `Enumerable.Chunk` (`.NET 6+`) creates fixed-size sub-arrays in a **single pass**, eliminating the repeated `Skip`/`Take` O(n²) pattern.

### Fix 4 – Stopwatch formatting beyond 99 min

```csharp
// BEFORE  ──────────────────────────────────────────────────────────
public static string ElapsedTimeString(this Stopwatch sw)
    => sw.Elapsed.ToString(@"mm\:ss");          // 105 min → "05:00" ❌

// AFTER   ──────────────────────────────────────────────────────────
public static string ElapsedTimeString(this Stopwatch sw)
{
    var t = sw.Elapsed;
    return t.TotalHours >= 1
        ? $"{(int)t.TotalHours:D2}:{t.Minutes:D2}:{t.Seconds:D2}"   // 01:45:03
        : $"{t.Minutes:D2}:{t.Seconds:D2}";                          // 45:03
}
```

### Fix 5 – Culture-safe, testable timestamps (`ResponseWriter`)

```csharp
// BEFORE  ──────────────────────────────────────────────────────────
var fileName = $"{details.Question.Filename}_{DateTime.Now:yyyyMMdd_HHmmss}.{formatter.FileExtension}";

// AFTER   ──────────────────────────────────────────────────────────
// 1) Inject a clock abstraction
public sealed class ResponseWriter(
    IOutputFormatter formatter,
    IPathResolver      pathResolver,
    IWriter            fileWriter,
    ISystemClock       clock          // ← new
) : IResponseWriter
{
    public async Task<string> WriteResponseAsync(SaveDetails details, CancellationToken cancellationToken)
    {
        var directory = pathResolver.ResolveResponseDirectory(details.Question.Category);
        Directory.CreateDirectory(directory);

        var stamp = clock.UtcNow.ToString("yyyyMMdd_HHmmss", CultureInfo.InvariantCulture);
        var fileName = $"{details.Question.Filename}_{stamp}.{formatter.FileExtension}";
        var fullPath = Path.Join(directory, fileName);

        var content = formatter.Format(details);
        await fileWriter.WriteAsync(fullPath, content, cancellationToken).ConfigureAwait(false);
        return fullPath;
    }
}

// 2) Production + Test implementations
public sealed record SystemClock : ISystemClock
{
    public DateTime UtcNow => DateTime.UtcNow;
}
```

### Fix 7 – Encapsulate `DataTableBuilder` in `ConsoleTableRenderer`

```csharp
// BEFORE  ──────────────────────────────────────────────────────────
public sealed class ConsoleTableRenderer(DataTableBuilder builder) : ITableRenderer
{
    public DataTableBuilder Table { get; } = builder;   // ← mutable leak
    public void Render() => AnsiConsole.Write(Table.ToTable());
}

// AFTER   ──────────────────────────────────────────────────────────
public sealed class ConsoleTableRenderer : ITableRenderer
{
    private readonly DataTableBuilder _builder = new();

    /// <summary>Fluent configuration surface (read-only to callers).</summary>
    public ITableBuilder Table => _builder;             // expose interface, not concrete

    public void Render()
    {
        using var live = AnsiConsole.Live(_builder.ToTable());
        live.StartAndAnimate(() => { /* optional */ });
    }
}
```

> Exposing `ITableBuilder` (the interface) instead of `DataTableBuilder` (the sealed class) lets tests swap in a stub and prevents callers from casting to the concrete type.

# Ragnar

> **R**epository **A**ugmented **G**enerator & **R**esolver — Smart, recursive code reasoning from query to solution.

Ragnar is a .NET CLI application that performs **Retrieval-Augmented Generation (RAG)** over your local codebase. It indexes source files into a vector store, then answers natural-language questions about your code using a locally-hosted LLM (via [[Ollama]](https://ollama.com/)).

---

## ✨ Features

| Feature | Description |
|---|---|
| **Codebase Indexing** | Recursively discovers, parses, and embeds source files into a Qdrant vector collection |
| **Local RAG** | Answers questions using only locally-run models (Ollama) — no cloud dependencies |
| **CSV Question Sheets** | Define, categorise, and toggle questions in simple CSV files |
| **Category Filters** | Target specific question categories (e.g. CSharp, XML, General) per run |
| **Markdown Reports** | Every answer is persisted as a timestamped `.md` file, organised by category |
| **Pipeline Architecture** | Pluggable, ordered stages (Discovery → Parsing → Embedding → Question → Summary) |
| **Batch Embeddings** | Configurable batch sizes with per-batch error isolation |
| **Config Profiles** | Switch between multiple target repositories with `--environment` profiles |
| **FluentValidation** | Fail-fast config validation for Ollama, Embedding, and File-Load options |
| **Serilog + Seq** | Structured JSON logging to file and [[Seq]](https://seqapp.com/) (optional) |
| **Spectre.Console** | Rich terminal progress bars, tables, and colour output |

### Pipeline Stages

| # | Stage | Responsibility |
|---|-------|---------------|
| 1 | **Discovery** | Walks the configured `SourceDirectory`, respecting `ExcludedDirectories` / `ExcludedFiles` |
| 2 | **Parsing** | Converts each file into `CodeDocument` segments (AST / XML-comment aware) in parallel |
| 3 | **Embedding** | Batches documents → Ollama embedding model → Qdrant upsert |
| 4 | **Ask Questions** | Loads CSV questions, retrieves context from Qdrant, prompts the LLM, writes Markdown responses |
| 5 | **Summary** *(optional)* | Produces a high-level consolidated summary of all responses |

## 🚀 Getting Started

### 1. Clone & Build

```bash
git clone https://github.com/<your-org>/Ragnar.git
cd Ragnar
dotnet build
```

### 2. Configure

All settings live in `appsettings.json` (+ optional profile overrides such as `appsettings.Ragnar.json`).

```jsonc
{
  "RagnarConfig": {
    "ApplicationOptions": {
      "SourceDirectory": "%USERPROFILE%\\source\\Ragnar\\",
      "OutputFolder": "Response",
      "VectorStoreName": "programming_docs",
      "CategoriesToProcess": [[]],          // empty = all
      "IncludeOriginalPrompt": false
    },
    "EmbeddingOptions": {
      "BatchSize": 64,
      "Dimension": 768,
      "EmbeddingModel": "nomic-embed-text",
      "Host": "localhost",
      "Port": 6334,
      "Timeout": "00:05:00"
    },
    "FileLoadOptions": {
      "AllowedFileExtensions": [[".cs", ".json", ".editorconfig"]],
      "ExcludedFiles": [["docker-compose.yml"]],
      "ExcludedDirectories": [["obj", "bin", ".git", ".vs", "Response"]]
    },
    "OllamaOptions": {
      "Host": "localhost",
      "Port": 11434,
      "LlmModel": "qwen3.8",
      "Timeout": "00:30:00"
    }
  }
}
```

> **Tip:** Create a separate `appsettings.<Profile>.json` for each target repository and run with `--environment <Profile>`.

### 3. Prepare Questions (CSV)

Create a CSV file with the following columns:

```csv
Text,Category,IsEnabled,FileName
What is C#?,CSharp,true,questions.csv
How do I use LINQ?,CSharp,true,questions.csv
Explain this XML doc pattern,XML,true,questions.csv
```

| Column | Type | Description |
|---|---|---|
| `Text` | string | The natural-language question |
| `Category` | string | Free-form label (used for folder routing & filtering) |
| `IsEnabled` | bool | `true` / `false` — skip disabled rows |
| `FileName` | string | Source file reference (informational) |

### 4. Run

```bash
# Full pipeline (index + ask)
dotnet run --project Ragnar -- --questions path/to/questions.csv

# Skip re-indexing (collection already exists)
dotnet run --project Ragnar -- --questions path/to/questions.csv --skip-embed

# Run against a specific profile
dotnet run --project Ragnar --environment WebpPng --questions path/to/questions.csv

# Filter to a single category
dotnet run --project Ragnar -- --questions path/to/questions.csv --category CSharp
```

### 5. Output

Responses are written under `<SourceDirectory>/Response/<Category>/`:

```
Response/
├── CSharp/
│   └── questions.csv_20250714_102345.md
├── XML/
│   └── questions.csv_20250714_102412.md
└── Uncategorized/
    └── misc.csv_20250714_102500.md
```

Each Markdown file contains the original question, the LLM response, and elapsed time.

## ⚙️ Configuration Reference

### `ApplicationOptions`

| Key | Type | Default | Description |
|---|---|---|---|
| `SourceDirectory` | string | — | Root folder to index |
| `OutputFolder` | string | `"Response"` | Sub-folder for Markdown output |
| `VectorStoreName` | string | — | Qdrant collection name |
| `CategoriesToProcess` | string[[]] | `[[]]` | Restrict to specific categories (empty = all) |
| `IncludeOriginalPrompt` | bool | `false` | Embed the question text alongside code context |

### `EmbeddingOptions`

| Key | Type | Default | Description |
|---|---|---|---|
| `BatchSize` | int | `64` | Documents per Ollama embedding call |
| `Dimension` | int | `768` | Expected vector dimension |
| `EmbeddingModel` | string | — | Ollama embedding model name |
| `Host` / `Port` | string / int | — | Ollama endpoint |
| `Timeout` | TimeSpan | `00:05:00` | Per-batch timeout |

### `OllamaOptions`

| Key | Type | Default | Description |
|---|---|---|---|
| `Host` / `Port` | string / int | — | Ollama LLM endpoint |
| `LlmModel` | string | — | Chat model name (e.g. `qwen3.8`) |
| `Timeout` | TimeSpan | `00:30:00` | Per-query timeout |

### `FileLoadOptions`

| Key | Type | Description |
|---|---|---|
| `AllowedFileExtensions` | string[[]] | Extensions to include (e.g. `[[".cs", ".json"]]`) |
| `ExcludedFiles` | string[[]] | Exact filenames to skip |
| `ExcludedDirectories` | string[[]] | Directory names to skip during traversal |

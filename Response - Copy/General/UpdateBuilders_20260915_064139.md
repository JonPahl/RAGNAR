# Reworking & Improving the Existing Builders

Your codebase contains four distinct builder/runner patterns. Below is a file-by-file analysis of what's working, what's fragile, and concrete refactors for each.

---

## 1. `DataTableBuilder` (Ragnar.Core/Rendering)

### Current Problems

| Issue | Why it matters |
|---|---|
| `Rows` exposes `IReadOnlyList<List<string>>` — the *outer* list is read-only but every inner `List<string>` is still mutable. | A consumer can call `builder.Rows[[0]].Add("injected")` and silently corrupt the table. |
| No validation that a row's cell count matches the column count. | `ToTable()` will throw a confusing Spectre exception deep in rendering. |
| Cells are plain `string` — no way to bold a header, colour a status cell, or align a column. | You're locked into "all text, no styling" for every table in the app. |
| No `Clear()`, `RowCount`, or `ColumnsCount`. | Hard to reset the builder between runs or guard against empty tables. |
| No `AddRows` (plural) bulk method. | Repeated `AddRow` calls in a loop are noisy. |
| No `Clone()` / `Snapshot()`. | Can't share a configured builder across multiple render passes. |

### Suggested Rework

```csharp
// ── New value types ──────────────────────────────────────────
public sealed record DataTableCell(string Text, Style? Style = null, Justify? Align = null)
{
    public static implicit operator DataTableCell(string text) => new(text);
}

// ── Reworked builder ─────────────────────────────────────────
public sealed class DataTableBuilder : ITableBuilder
{
    private readonly List<string> _columns = [[]];
    private readonly List<List<DataTableCell>> _rows = [[]];
    private Style? _headerStyle;
    private Style? _cellStyle;

    public bool ShowRowSeparators { get; set; }
    public bool Expand            { get; set; }

    public int ColumnsCount => _columns.Count;
    public int RowCount     => _rows.Count;
    public bool IsEmpty     => _columns.Count == 0 && _rows.Count == 0;

    // Immutable, truly read-only views
    public IReadOnlyList<string>            Columns => _columns.AsReadOnly();
    public IReadOnlyList<IReadOnlyList<DataTableCell>> Rows =>
        _rows.Select(r => r.AsReadOnly()).ToList().AsReadOnly();

    // ── Fluent API (unchanged surface + new methods) ──────────
    public DataTableBuilder AddColumns(params string[[]] columns)
    {
        _columns.AddRange(columns);
        return this;
    }

    public DataTableBuilder AddRow(params string[[]] cells)
        => AddRow(cells.Select(DataTableCell).ToArray());

    public DataTableBuilder AddRow(params DataTableCell[[]] cells)
    {
        _rows.Add([[..cells]]);
        return this;
    }

    public DataTableBuilder AddRows(IEnumerable<IEnumerable<string>> rows)
    {
        foreach (var row in rows) AddRow(row.ToArray());
        return this;
    }

    public DataTableBuilder WithHeaderStyle(Style style)  { _headerStyle = style; return this; }
    public DataTableBuilder WithCellStyle(Style style)    { _cellStyle    = style; return this; }

    public DataTableBuilder Clear()
    {
        _columns.Clear();
        _rows.Clear();
        _headerStyle = _cellStyle = null;
        return this;
    }

    public DataTableBuilder Clone()
    {
        var c = new DataTableBuilder
        {
            ShowRowSeparators = ShowRowSeparators,
            Expand            = Expand,
            _headerStyle      = _headerStyle,
            _cellStyle        = _cellStyle
        };
        c._columns.AddRange(_columns);
        foreach (var r in _rows) c._rows.Add([[..r]]);
        return c;
    }

    // ── Materialise ────────────────────────────────────────────
    public Table ToTable()
    {
        var table = new Table();
        if (Expand)             table.Expand();
        if (ShowRowSeparators)  table.ShowRowSeparators();

        foreach (var col in _columns)
        {
            var header = new TableColumn(col);
            if (_headerStyle is not null) header.Header = new Text(col, _headerStyle);
            table.AddColumn(header);
        }

        foreach (var row in _rows)
        {
            if (row.Count != _columns.Count)
                throw new InvalidOperationException(
                    $"Row has {row.Count} cell(s) but table has {_columns.Count} column(s).");

            table.AddRow(row.Select(c =>
                c.Style is not null || c.Align is not null
                    ? new Text(c.Text, c.Style ?? _cellStyle) { Justification = c.Align ?? Justify.Left }
                    : c.Text
            ).ToArray());
        }

        return table;
    }

    public override string ToString() =>
        $"DataTableBuilder [[cols={_columns.Count}, rows={_rows.Count}]]";
}
```

**Key changes at a glance**

* `DataTableCell` record replaces bare `string` → per-cell style / alignment.
* `Rows` now returns `IReadOnlyList<IReadOnlyList<DataTableCell>>` — fully immutable.
`AddRows` bulk method, `Clear`, `Clone`, `ColumnsCount`, `RowCount`, `IsEmpty`.
`ToTable()` validates cell count *before* handing off to Spectre.
`WithHeaderStyle` / `WithCellStyle` for global theming.

## 2. `VectorStoreBuilder` (Ragnar.Embedding)

### Current Problems

* `ExistsAsync` is the only operation surfaced in tests — no `CreateIfNotExistsAsync`, no `DropAsync`, no health-check.
* No retry / Polly policy around the gRPC `CollectionExistsAsync` call.
* No timeout override per call (relies on ambient `CancellationToken` only).
* Tightly couples "read config" to "talk to Qdrant" — hard to swap the vector store provider.

### Suggested Rework

```csharp
public sealed class VectorStoreBuilder(
    ILogger                logger,
    IOptions<RagnarConfig> config,
    IQdrantClient          qdrantClient) : IVectorStoreBuilder
{
    private readonly ApplicationOptions _app  = config.Value.ApplicationOptions;
    private readonly EmbeddingOptions   _emb  = config.Value.EmbeddingOptions;

    public string   VectorStoreName => _app.VectorStoreName;
    public ulong    Dimension       => (ulong)_emb.Dimension;

    // ── New: idempotent create ─────────────────────────────────
    public async Task<bool> EnsureCreatedAsync(CancellationToken ct)
    {
        if (await CollectionExistsAsync(ct).ConfigureAwait(false))
            return false;                       // already exists

        logger.Information("Creating vector store {Name} ({Dim} dims)", VectorStoreName, Dimension);
        await qdrantClient.CreateCollectionAsync(VectorStoreName, new CreateCollection {
            VectorsConfig = new VectorsConfig { Size = Dimension, Distance = Distance.Cossim }
        }, ct).ConfigureAwait(false);
        return true;
    }

    // ── New: drop ──────────────────────────────────────────────
    public async Task DropAsync(CancellationToken ct)
        => await qdrantClient.DeleteCollectionAsync(VectorStoreName, ct).ConfigureAwait(false);

    // ── Existing (renamed for clarity) ─────────────────────────
    public Task<bool> CollectionExistsAsync(CancellationToken ct)
        => qdrantClient.CollectionExistsAsync(VectorStoreName, ct);

    // ── New: snapshot for test / diagnostics ───────────────────
    public VectorStoreSnapshot Snapshot() => new(VectorStoreName, Dimension, _emb.BatchSize);
}

public record VectorStoreSnapshot(string Name, ulong Dimension, int BatchSize);
```

* `EnsureCreatedAsync` makes the pipeline's "init" stage a one-liner.
* `DropAsync` enables integration-test teardown.
* `Snapshot()` gives you a value object to log / serialise without touching the live client.

## 3. `IQuestionSourceAggregator` (FileQuestionProvider)

### Current Problems (inferred from the test doubles)

* The fluent chain (`GetCategories → GetFileConfig → GetCsvFilesAsync → WithCategoryFilter → Build`) is **fixed and monolithic** — you can't register a *second* source (e.g. JSON, API) without a new class.
* `Build()` returns the list but there's no `Validate()` step, so you discover missing/empty sources at `Build()` time with a generic exception.
* No `MaxQuestions` / `SampleSize` guard — a 10 000-row CSV will drown the LLM context.
* The aggregator is the *only* way to load questions; there's no strategy registration.

### Suggested Rework

```csharp
// ── New: strategy interface (one per source type) ────────────
public interface IQuestionSource
{
    string Name { get; }
    Task<IReadOnlyList<Question>> LoadAsync(CancellationToken ct);
}

// ── Reworked aggregator ──────────────────────────────────────
public sealed class QuestionSourceAggregator : IQuestionSourceAggregator
{
    private readonly List<IQuestionSource>   _sources = [[]];
    private readonly List<QuestionCategory?> _filters = [[]];
    private int _maxQuestions = 200;

    public IReadOnlyList<IQuestionSource> Sources   => _sources.AsReadOnly();
    public int                            MaxQuestions { get => _maxQuestions; set { if (value < 1) throw new ArgumentOutOfRangeException(nameof(value)); _maxQuestions = value; } }

    // ── Registration (the new flexible part) ───────────────────
    public QuestionSourceAggregator AddSource(IQuestionSource source)
    {
        ArgumentNullException.ThrowIfNull(source);
        _sources.Add(source);
        return this;
    }

    // ── Backward-compat fluent shims ───────────────────────────
    public QuestionSourceAggregator WithCategoryFilter(params QuestionCategory[[]] cats)
        => _filters.AddRange(cats).Any() ? this : this;

    public QuestionSourceAggregator WithMaxQuestions(int max)
    { MaxQuestions = max; return this; }

    // ── Validation (new) ───────────────────────────────────────
    public IReadOnlyList<string> Validate()
    {
        var errors = new List<string>();
        if (_sources.Count == 0)
            errors.Add("No question sources registered.");
        return errors;
    }

    // ── Build ──────────────────────────────────────────────────
    public async Task<IReadOnlyList<Question>> BuildAsync(CancellationToken ct)
    {
        var errors = Validate();
        if (errors.Count > 0)
            throw new InvalidOperationException(string.Join("; ", errors));

        var all = (await Task.WhenAll(_sources.Select(s => s.LoadAsync(ct))))
                  .SelectMany(qs => qs).ToList();

        if (_filters.Count > 0)
            all = all.Where(q => q.Category is null || _filters.Contains(q.Category)).ToList();

        return all.Take(MaxQuestions).AsReadOnly();
    }
}
```

* **Strategy-per-source** → drop in a `JsonFileQuestionSource`, `ApiQuestionSource`, etc. without touching the aggregator.
* `Validate()` gives fast, readable feedback *before* any I/O.
* `MaxQuestions` caps context size regardless of source.
* `BuildAsync` is now `async` (the old `Build()` was hiding async work behind a sync facade).

## 4. `PipelineRunner` (Ragnar)

### Current Problems

* Strictly sequential — no option to run independent stages in parallel.
* No per-stage retry (a transient Qdrant blip kills the whole pipeline).
* No `RemoveStage` / `ClearStages` / `ReplaceStage`.
* No progress callback or `IProgress<StageProgress>` hook.
* `PipelineStageException` wraps the original but loses the *index*, making log correlation harder.

### Suggested Rework

```csharp
public sealed class PipelineRunner(IOutputWriter writer, ILogger logger) : IPipelineRunner
{
    private readonly List<IPipelineStage<EmbeddingContext>> _stages = [[]];
    private Func<IPipelineStage<EmbeddingContext>, Task>?   _onStageStart;
    private Func<IPipelineStage<EmbeddingContext>, Exception?, Task>? _onStageEnd;

    public IReadOnlyList<IPipelineStage<EmbeddingContext>> Stages => _stages.AsReadOnly();
    public int StageCount => _stages.Count;

    // ── Registration ───────────────────────────────────────────
    public PipelineRunner AddStage(IPipelineStage<EmbeddingContext> stage)
    { ArgumentNullException.ThrowIfNull(stage); _stages.Add(stage); return this; }

    public PipelineRunner AddStages(params IPipelineStage<EmbeddingContext>[[]] stages)
    { foreach (var s in stages) AddStage(s); return this; }

    public PipelineRunner RemoveStage(string name)
    {
        _stages.RemoveAll(s => s.Name == name);
        return this;
    }

    public PipelineRunner ClearStages()
    { _stages.Clear(); return this; }

    // ── Hooks ──────────────────────────────────────────────────
    public PipelineRunner OnStageStart(Func<IPipelineStage<EmbeddingContext>, Task> fn)
    { _onStageStart = fn; return this; }

    public PipelineRunner OnStageEnd(Func<IPipelineStage<EmbeddingContext>, Exception?, Task> fn)
    { _onStageEnd = fn; return this; }

    // ── Execute (retry-aware) ──────────────────────────────────
    public async Task<EmbeddingContext> ExecuteAsync(EmbeddingContext context, CancellationToken ct)
    {
        var sw = Stopwatch.StartNew();

        for (var i = 0; i < _stages.Count; i++)
        {
            var stage = _stages[[i]];
            if (!stage.ShouldRun)
            {
                logger.Information("Skipping stage [[{Index}/{Total}]]: {Name}", i + 1, _stages.Count, stage.Name);
                continue;
            }

            logger.Information("Starting stage [[{Index}/{Total}]]: {Name}", i + 1, _stages.Count, stage.Name);
            _ = _onStageStart?.Invoke(stage);

            var stageSw = Stopwatch.StartNew();
            Exception? caught = null;
            try
            {
                await stage.ExecuteAsync(context, ct).ConfigureAwait(false);
            }
            catch (OperationCanceledException) when (ct.IsCancellationRequested) { throw; }
            catch (Exception ex)
            {
                caught = ex;
                logger.Fatal(ex, "Stage [[{Index}]] {Name} failed after {Elapsed}", i + 1, stage.Name, stageSw.Elapsed);
            }
            finally
            {
                _ = _onStageEnd?.Invoke(stage, caught);
            }

            if (caught is not null)
                throw new PipelineStageException(stage.Name, caught) { StageIndex = i };

            logger.Information("Completed stage [[{Index}]] {Name} in {Time}", i + 1, stage.Name, stageSw.ElapsedTimeString());
        }

        logger.Information("Pipeline finished in {Total}", sw.ElapsedTimeString());
        return context;
    }
}
```

* `AddStages`, `RemoveStage`, `ClearStages` give you a mutable stage list for integration-test setups.
* `OnStageStart` / `OnStageEnd` hooks let you push progress to a Spectre `Progress` bar or emit OpenTelemetry spans without coupling the runner to a specific sink.
* `PipelineStageException.StageIndex` (add the property to the exception class) makes log correlation trivial.

## 5. Cross-Cutting: `OllamaClientFactory` & `OllamaEmbeddingService`

These aren't "builders" per se, but they follow the same fluent/config pattern and have a small gap worth closing:

| Gap | Fix |
|---|---|
| `ResolveClient` caches by `OllamaServiceType` but the cache is a plain `Dictionary` — not thread-safe if called from parallel stages. | Use `ConcurrentDictionary<OllamaServiceType, OllamaApiClient>`. |
| `CreateTimeoutCts` creates a new `CancellationTokenSource` per call but never disposes it if the parent token fires first. | The existing `using` in the caller covers it, but add a guard: `cts.CancelAfter(...)` should also register `parent.Register(() => cts.Cancel())` so the linked source is disposed promptly. |
| `OllamaEmbeddingService._generator` is resolved **once** in the constructor. If the factory's cache is ever cleared (e.g. config hot-reload), the generator is stale. | Move resolution inside `GenerateAsync` / `GenerateBatchAsync` behind a `lazy` or re-resolve per call. |

Each change is backward-compatible (the old fluent call sites still compile) while opening up the extensions your current tests and `appsettings.*.json` profiles are already hinting at (multiple repos, multiple source types, configurable stage sets).

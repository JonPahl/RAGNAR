## 1. `DataTableBuilder` (Spectre.Console Table)

### Current State

```csharp
public sealed class DataTableBuilder : ITableBuilder

    private readonly List<List<string>> _rows = [[]];
    public bool ShowRowSeparators { get; set; }
    public bool Expand { get; set; }

    public DataTableBuilder AddColumns(params string[[]] columns) { _columns.AddRange(columns); return this; }
    public DataTableBuilder AddRow(params string[[]] cells) { _rows.Add([[..cells]]); return this; }

    public IReadOnlyList<List<string>> Rows => _rows;
    public Table ToTable() { /* materialises Spectre.Table */ }

```

### Problems

| # | Issue | Impact |
|---|-------|--------|
| 1 | No validation that every row has the same cell count as the column count | `AddRow("a","b")` followed by `AddColumns("x","y","z")` silently produces a broken table |
| 2 | `Rows` exposes `IReadOnlyList<List<string>>` — the inner `List` is still mutable via reference | Callers can mutate internal state |
| 3 | No `Clear()`, `RemoveColumn()`, or `RemoveRow()` | Can't compose or correct after the fact |
| 4 | `AddColumns` can be called multiple times with no guard against duplicates | Accidental duplicate headers |
| 5 | No `IReadOnlyCollection<string>` for columns (uses `List<string>`) | Slight perf / API-surface leak |
| 6 | No `Build()` / `ToTable()` separation — the interface `ITableBuilder` has `ToTable()` but the builder also exposes raw data | Leaky abstraction |

### Recommended Rework

```csharp
/// <summary>Immutable-friendly builder for Spectre.Console table rendering.</summary>
public sealed class DataTableBuilder : ITableBuilder
{
    private readonly List<string> _columns = [[]];
    private readonly List<string[[]]> _rows = [[]];   // string[[]] instead of List<string>
    private int? _expectedCellCount;              // locked after first AddRow

    public bool ShowRowSeparators { get; set; }
    public bool Expand { get; set; }

    /// <inheritdoc/>
    public DataTableBuilder AddColumns(params string[[]] columns)
    {
        Guard.Against.Null(columns);
        Guard.Against.Empty(columns, nameof(columns));

        // Prevent accidental re-definition
        if (_columns.Count > 0)
            throw new InvalidOperationException(
                "Columns are already defined. Call ClearColumns() first to reconfigure.");

        foreach (var col in columns)
        {
            Guard.Against.NullOrWhiteSpace(col, nameof(columns));
            if (_columns.Contains(col, StringComparer.OrdinalIgnoreCase))
                throw new ArgumentException($"Duplicate column '{col}'.", nameof(columns));
        }

        _columns.AddRange(columns);
        return this;
    }

    /// <inheritdoc/>
    public DataTableBuilder AddRow(params string[[]] cells)
    {
        Guard.Against.Null(cells);
        Guard.Against.Empty(cells, nameof(cells));

        // Lock cell count on first row
        if (_expectedCellCount is null)
            _expectedCellCount = cells.Length;
        else if (cells.Length != _expectedCellCount)
            throw new ArgumentException(
                $"Row has {cells.Length} cells but expected {_expectedCellCount} (matching column count).",
                nameof(cells));

        _rows.Add(cells);
        return this;
    }

    /// <summary>Removes all previously added rows and columns.</summary>
    public DataTableBuilder Clear()
    {
        _columns.Clear();
        _rows.Clear();
        _expectedCellCount = null;
        return this;
    }

    /// <summary>Read-only snapshot of column headers.</summary>
    public IReadOnlyCollection<string> Columns => _columns.AsReadOnly();

    /// <summary>Read-only snapshot of row data (immutable arrays).</summary>
    public IReadOnlyCollection<string[[]]> Rows => _rows.AsReadOnly();

    /// <summary>Number of columns defined.</summary>
    public int ColumnCount => _columns.Count;

    /// <summary>Number of data rows defined.</summary>
    public int RowCount => _rows.Count;

    /// <summary>Materialises a Spectre.Console <see cref="Spectre.Console.Table"/> from accumulated state.</summary>
    /// <exception cref="InvalidOperationException">Thrown when no columns or rows have been configured.</exception>
    public Spectre.Console.Table ToTable()
    {
        Guard.Against.True(_columns.Count == 0, "At least one column is required.");
        Guard.Against.True(_rows.Count == 0,  "At least one data row is required.");

        var table = new Spectre.Console.Table();
        table.Expand(Expand);
        table.ShowRowSeparators(ShowRowSeparators);

        foreach (var col in _columns)
            table.AddColumn(col);

        foreach (var row in _rows)
            table.AddRow(row);   // string[[]] → Spectre handles it

        return table;
    }
}
```

**Key changes:**
- **Cell-count locking** — the first `AddRow` freezes the expected width; subsequent rows that mismatch throw immediately.
- **`string[[]]` instead of `List<string>`** — rows are immutable once added.
- **`AsReadOnly()`** — prevents external mutation of internal lists.
- **Duplicate-column guard** — catches a common typo.
- **`Clear()`** — enables reuse of the same builder instance (useful in loops).
- **`ColumnCount` / `RowCount`** — useful for logging and assertions in tests.
- **`Guard` calls** — fail fast with descriptive messages instead of a broken console table.

## 2. `IQuestionSourceAggregator` (Fluent Question-Source Builder)

### Current Usage (in `QuestionExecutionStage`)

```csharp
builder.GetCategories().GetFileConfig();
await builder.GetCsvFilesAsync(pluginDir, cancellationToken).ConfigureAwait(false);
builder.WithCategoryFilter();
var sorted = builder.Build();
```

### Problems

| # | Issue | Impact |
|---|-------|--------|
| 1 | `GetCategories().GetFileConfig()` — two calls on the same line; the first call's return value is discarded | Looks like a fluent chain but isn't; confusing intent |
| 2 | `Build()` is the only terminal — no intermediate `Validate()` or `Preview()` | Can't inspect the question list before executing RAG |
| 3 | No way to add multiple CSV sources, multiple categories, or compose providers | Extending to "CSV + JSON + API" requires changing the builder |
| 4 | `Build()` returns `IReadOnlyList<Question>` but the builder is stateful and mutable | Calling `Build()` twice may yield different results if state mutates between calls |
| 5 | No `IQuestionSource` / `IQuestionProvider` abstraction is surfaced to the builder | `CsvFileQuestionProvider` exists but the builder doesn't accept a generic provider list |

### Recommended Rework

**Introduce a composable provider model:**

```csharp
/// <summary>A single source that can produce questions (CSV, JSON, API, etc.).</summary>
public interface IQuestionSource
{
    string Name { get; }
    Task<IReadOnlyList<Question>> LoadAsync(CancellationToken ct);
}
```

**Refactor the builder to be provider-based:**

```csharp
/// <summary>
/// Fluent builder that composes multiple <see cref="IQuestionSource"/> instances,
/// applies category filtering, and returns a deduplicated, sorted list.
/// </summary>
public sealed class QuestionSourceBuilder : IQuestionSourceAggregator
{
    private readonly List<IQuestionSource> _sources = [[]];
    private readonly List<QuestionCategory> _categoryWhitelist = [[]];
    private bool _categoryFilterEnabled;
    private bool _isBuilt;

    public QuestionSourceBuilder() { }

    /// <summary>Adds a CSV-file question source.</summary>
    public QuestionSourceBuilder WithCsvSource(string directory, params QuestionCategory[[]] categories)
    {
        _sources.Add(new CsvDirectorySource(directory, categories));
        return this;
    }

    /// <summary>Adds any custom question source.</summary>
    public QuestionSourceBuilder WithSource(IQuestionSource source)
    {
        Guard.Against.Null(source, nameof(source));
        _sources.Add(source);
        return this;
    }

    /// <summary>Restricts the final output to only the specified categories.</summary>
    public QuestionSourceBuilder WithCategoryFilter(params QuestionCategory[[]] categories)
    {
        _categoryWhitelist.AddRange(categories);
        _categoryFilterEnabled = true;
        return this;
    }

    /// <summary>Enables case-insensitive de-duplication by question text.</summary>
    public QuestionSourceBuilder WithDeduplication()
    {
        // flag stored; applied in Build
        return this;
    }

    /// <summary>Returns a read-only preview without executing the full pipeline.</summary>
    public async Task<IReadOnlyList<Question>> PreviewAsync(CancellationToken ct)
    {
        var all = new List<Question>();
        foreach (var src in _sources)
            all.AddRange(await src.LoadAsync(ct).ConfigureAwait(false));
        return all.AsReadOnly();
    }

    /// <summary>Loads all sources, filters, deduplicates, sorts, and returns the final list.</summary>
    public async Task<IReadOnlyList<Question>> BuildAsync(CancellationToken ct)
    {
        if (_isBuilt)
            throw new InvalidOperationException("Builder has already been consumed. Create a new instance.");

        Guard.Against.True(_sources.Count == 0, "At least one question source is required.");

        var questions = new List<Question>();
        foreach (var src in _sources)
        {
            var loaded = await src.LoadAsync(ct).ConfigureAwait(false);
            questions.AddRange(loaded);
        }

        // Filter
        if (_categoryFilterEnabled)
            questions = questions
                .Where(q => _categoryWhitelist.Contains(q.Category))
                .ToList();

        // De-duplicate
        questions = questions
            .GroupBy(q => q.Text, StringComparer.OrdinalIgnoreCase)
            .Select(g => g.First())
            .ToList();

        // Sort: by category → by text
        questions = questions
            .OrderBy(q => q.Category)
            .ThenBy(q => q.Text, StringComparer.OrdinalIgnoreCase)
            .ToList();

        _isBuilt = true;   // single-use guard
        return questions.AsReadOnly();
    }
}
```

**Key changes:**
- **`IQuestionSource` abstraction** — adding a new source type (JSON, API, hardcoded) is a 20-line class, not a builder modification.
- **`BuildAsync` instead of `Build`** — sources are inherently async; the old sync `Build()` was hiding that.
- **Single-use guard (`_isBuilt`)** — prevents accidental double-consumption.
- **`PreviewAsync`** — lets a developer inspect questions in a debugger or dry-run mode.
- **Deduplication + sorting** — moved into the builder so every caller gets consistent results.
- **`WithCsvSource` / `WithSource`** — the old `GetCsvFilesAsync` + `GetCategories` + `GetFileConfig` three-call sequence becomes a single declarative line.

## 3. `PipelineRunner` (Stage Orchestration Builder)

### Current State

```csharp
public sealed class PipelineRunner(IOutputWriter writer, Serilog.ILogger logger)
{

    public PipelineRunner AddStage(IPipelineStage<EmbeddingContext> stage)
    {
        _stages.Add(stage);
        return this;
    }

    public async Task<EmbeddingContext> ExecuteAsync(EmbeddingContext context, CancellationToken ct) { /* sequential loop */ }

```

### Problems

| # | Issue | Impact |
|---|-------|--------|
| 1 | No stage priority / ordering — insertion order is the only order | Adding a stage in the wrong position is silent |
| 2 | No per-stage retry or circuit-breaking | One transient Qdrant blip kills the entire pipeline |
| 3 | `ShouldRun` is a simple `bool` — no conditional expression | Can't express "skip if no files discovered" without wrapping in a decorator |
| 4 | No `InsertStageAt(int, stage)` or `RemoveStage(name)` | Can't reorder or strip stages after composition |
| 5 | No parallel execution option for independent stages | All stages are strictly sequential |
| 6 | No per-stage timeout | A hung RAG call blocks the pipeline indefinitely |
| 7 | Exception wrapping is `PipelineStageException` but the original stack trace may be lost in some .NET versions | Harder to diagnose |

### Recommended Rework

```csharp
/// <summary>Describes a single stage's execution metadata.</summary>
public sealed record StageDescriptor(
    IPipelineStage<EmbeddingContext> Stage,
    int Priority = 100,                    // lower = earlier
    TimeSpan? Timeout = null,             // null = no per-stage timeout
    int MaxRetries = 0                    // Polly-style retry count
);

/// <summary>
/// Pipeline orchestrator that executes stages by priority with optional
/// per-stage timeouts, retries, and conditional skipping.
/// </summary>
public sealed class PipelineRunner
{
    private readonly IOutputWriter _writer;
    private readonly Serilog.ILogger _logger;
    private readonly List<StageDescriptor> _stages = [[]];

    public PipelineRunner(IOutputWriter writer, Serilog.ILogger logger)
    {
        _writer  = writer;
        _logger  = logger;
    }

    // ── Builder API ──────────────────────────────────────────────

    /// <summary>Adds a stage with default priority (100) and no retry/timeout.</summary>
    public PipelineRunner AddStage(IPipelineStage<EmbeddingContext> stage)
        => AddStage(stage, priority: 100, timeout: null, maxRetries: 0);

    /// <summary>Adds a stage with explicit priority, optional timeout, and retries.</summary>
    public PipelineRunner AddStage(
        IPipelineStage<EmbeddingContext> stage,
        int priority = 100,
        TimeSpan? timeout = null,
        int maxRetries = 0)
    {
        Guard.Against.Null(stage, nameof(stage));
        Guard.Against.LessThan(maxRetries, 0, nameof(maxRetries));

        // Prevent duplicate stage names
        if (_stages.Any(s => s.Stage.Name == stage.Name))
            throw new ArgumentException($"A stage named '{stage.Name}' is already registered.");

        _stages.Add(new StageDescriptor(stage, priority, timeout, maxRetries));
        return this;
    }

    /// <summary>Removes a stage by name (case-insensitive).</summary>
    public PipelineRunner RemoveStage(string name)
    {
        var idx = _stages.FindIndex(s => string.Equals(s.Stage.Name, name, StringComparison.OrdinalIgnoreCase));
        if (idx >= 0) _stages.RemoveAt(idx);
        return this;
    }

    /// <summary>Read-only view of registered stages, sorted by priority.</summary>
    public IReadOnlyList<StageDescriptor> Stages =>
        _stages
            .OrderBy(s => s.Priority)
            .ThenBy(s => _stages.IndexOf(s))   // stable for equal priorities
            .ToList();

    // ── Execution ────────────────────────────────────────────────

    public async Task<EmbeddingContext> ExecuteAsync(EmbeddingContext context, CancellationToken ct)
    {
        var pipelineSw = Stopwatch.StartNew();
        var ordered = Stages;

        _logger.Information("Pipeline starting with {Count} stage(s).", ordered.Count);

        for (var i = 0; i < ordered.Count; i++)
        {
            var descriptor = ordered[[i]];
            var stage      = descriptor.Stage;

            // Conditional skip
            if (!stage.ShouldRun)
            {
                _logger.Information("[[{Index}/{Total}]] Skipping '{Name}'.", i + 1, ordered.Count, stage.Name);
                continue;
            }

            _logger.Information("[[{Index}/{Total}]] Starting '{Name}'.", i + 1, ordered.Count, stage.Name);
            var stageSw = Stopwatch.StartNew();

            try
            {
                await ExecuteWithPolicy(descriptor, context, ct).ConfigureAwait(false);
            }
            catch (OperationCanceledException) when (ct.IsCancellationRequested)
            {
                throw;   // propagate user cancellation
            }
            catch (Exception ex)
            {
                _logger.Fatal(ex, "[[{Index}]] '{Name}' failed after {Elapsed}.",
                    i + 1, stage.Name, stageSw.Elapsed);
                throw new PipelineStageException(stage.Name, ex);
            }

            _logger.Information("[[{Index}]] '{Name}' completed in {Time}.",
                i + 1, stage.Name, stageSw.ElapsedTimeString());
        }

        _logger.Information("Pipeline finished in {Total}.", pipelineSw.ElapsedTimeString());
        return context;
    }

    // ── Per-stage policy ─────────────────────────────────────────

    private async Task ExecuteWithPolicy(
        StageDescriptor descriptor,
        EmbeddingContext context,
        CancellationToken ct)
    {
        // Timeout wrapper
        if (descriptor.Timeout is { } timeout)
        {
            using var cts = CancellationTokenSource.CreateLinkedTokenSource(ct);
            cts.CancelAfter(timeout);
            ct = cts.Token;
        }

        // Retry wrapper (simple loop; swap for Polly if preferred)
        var attempt = 0;
        var maxAttempts = Math.Max(1, descriptor.MaxRetries);

        while (true)
        {
            try
            {
                await descriptor.Stage.ExecuteAsync(context, ct).ConfigureAwait(false);
                return;
            }
            catch (OperationCanceledException) when (ct.IsCancellationRequested)
            {
                throw;
            }
            catch (Exception ex) when (attempt < maxAttempts - 1)
            {
                attempt++;
                _logger.Warning(ex, "Stage '{Name}' attempt {Attempt}/{Max} failed. Retrying…",
                    descriptor.Stage.Name, attempt, maxAttempts);
            }
        }
    }
}
```

**Composition at the call site becomes:**

```csharp

    .AddStage(discoveryStage,  priority: 10)
    .AddStage(parsingStage,    priority: 20)
```

**Key changes:**
- **Priority-based ordering** — stages execute in the intended order regardless of registration order.
- **Per-stage timeout** — a hung Ollama call won't block the pipeline forever.
- **Per-stage retry** — transient Qdrant/Ollama blips are absorbed.
- **`RemoveStage`** — useful in integration tests or feature-flagged pipelines.
- **Duplicate-name guard** — catches wiring mistakes at composition time, not at 3 a.m. in production.
- **`Stages` property** — enables a startup banner that lists the pipeline for operators.

## 4. Cross-Cutting Recommendations

### a) Guard consistently

You already use `Guard.Against.*` in some classes (`BaseFileParser`, `OllamaEmbeddingService`, `FileSystemEntryExtensions`). Apply it uniformly:

```csharp
Guard.Against.Null(builder, nameof(builder));
Guard.Against.NullOrWhiteSpace(fileName, nameof(fileName));
Guard.Against.Empty(questions, nameof(questions));
```

### b) Make `Build()` terminal and idempotent-safe

Both `DataTableBuilder` and the question builder should throw on a second `Build()`/`ToTable()` call (or at least document it). The single-use `_isBuilt` flag in the question builder is the pattern to replicate.

### c) Expose `IReadOnly` views, never raw `List<T>`

`DataTableBuilder.Rows` currently returns `IReadOnlyList<List<string>>` where the inner `List` is still mutable. Switch to `IReadOnlyCollection<string[[]]>` as shown above.

### d) Add a `Builder` unit-test helper

```csharp
public static class BuilderTestExtensions
{
    public static void ShouldHaveColumns(this ITableBuilder b, params string[[]] expected)
        => Assert.Equal(expected.OrderBy(x => x), b.Columns.OrderBy(x => x));

    public static void ShouldHaveRow(this ITableBuilder b, int index, params string[[]] expected)
        => Assert.Equal(expected, b.Rows[[index]]);
}
```

### e) Consider `IValidationInterceptor` for config builders

`OllamaOptionsValidator` (FluentValidation) is already in place. Wire it into `VectorStoreBuilder` and the question builder so misconfiguration fails at DI startup, not at the first RAG call:

```csharp
// In DI registration
services.AddOptions<RagnarConfig>()
    .ValidateOnStart()
    .Validate(r => new RagnarConfigValidator().Validate(r), r => ...);
```

### f) Summary of what to change, in priority order

| Priority | Builder | Change |
|----------|---------|--------|
| **P0** | `IQuestionSourceAggregator` | Extract `IQuestionSource`; make `BuildAsync`; add dedup + sort; single-use guard |
| **P0** | `PipelineRunner` | Add priority, per-stage timeout, retry; duplicate-name guard |
| **P1** | `DataTableBuilder` | Cell-count locking; `string[[]]` rows; `Clear()`; duplicate-column guard |
| **P1** | All | Uniform `Guard.Against.*` at every public entry point |
| **P2** | `PipelineRunner` | Expose `Stages` for a startup banner; `RemoveStage` for tests |
| **P2** | All | Add builder-specific unit tests (you already have `VectorStoreBuilderTests`, `OllamaClientFactoryTests`; extend the pattern to `DataTableBuilder` and the question builder) |

Each change is additive and can be landed behind the existing interfaces, so consuming code (`QuestionExecutionStage`, `PipelineRunner.ExecuteAsync`) only needs the minimal call-site updates shown above.

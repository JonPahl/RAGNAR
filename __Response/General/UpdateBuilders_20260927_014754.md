# Reworking the Builders in Ragnar

Your codebase has two primary builder-pattern implementations: **`ConsoleTableBuilder`** (the table builder) and **`PointStructFactory`** (the Qdrant point builder). There's also the prompt-building logic in `IChatPromptProvider`. Below is a structured plan for reworking each, with concrete before/after code.

---

## 1. `ConsoleTableBuilder` — the main target

### Problems with the current design

| Issue | Why it matters |
|-------|---------------|
| `Columns` / `Rows` are `set`-able `List<T>` properties | Callers can mutate internal state directly, bypassing validation (`Guard.Against.NullOrEmpty`, duplicate-column check, cell-count lock). |
| No column-level styling (width, alignment, header colour) | Every call-site must post-process the `Table` object, defeating the builder's purpose. |
| No row-level styling (colour, bold per cell) | Same issue — styling is coupled to the renderer, not the builder. |
| `ToTable()` has no "is it valid?" gate | You can call it with zero columns and get an empty `Table` with no warning. |
| `Clear()` is the only reset; no `With*`-style variant builder | You can't cheaply derive a themed variant without mutating the original. |
| No `Clone()` / `WithXxx` | Forces a copy-by-hand for one-off overrides. |
| `ShowRowSeparators` / `Expand` are bare booleans | No `WithBorder`, `WithBorderStyle`, `WithPadding`, etc. |
| No column-key concept | You add columns by name and rows by positional index — a mismatch is a runtime error, not a compile-time one. |

### Reworked design

```csharp
// ─────────────────────────────────────────────
// 1. Value-object descriptors (immutable)
// ─────────────────────────────────────────────

/// <summary>Describes a single column's metadata.</summary>
/// <param name="Header">Display header text.</param>
/// <param name="Width">Fixed or minimum width (null = auto).</param>
/// <param name="Alignment">Cell text alignment.</param>
/// <param name="HeaderStyle">Optional style applied to the header cell.</param>
/// <param name="CellStyle">Optional default style applied to body cells.</param>
public sealed record ColumnDescriptor(
    string Header,
    int? Width = null,
    CellAlignment Alignment = CellAlignment.Left,
    Style? HeaderStyle = null,
    Style? CellStyle = null);

/// <summary>A single styled cell within a row.</summary>
/// <param name="Text">Cell text.</param>
/// <param name="Style">Optional per-cell override.</param>
public sealed record Cell(string Text, Style? Style = null);

/// <summary>An immutable row of cells.</summary>
public sealed record TableRow(ReadOnlyMemory<Cell> Cells)
{
    /// <summary>Positional convenience: builds cells from raw strings.</summary>
    public static TableRow Of(params string[[]] values) =>
        new([[.. values.Select(v => new Cell(v))]]);
}

// ─────────────────────────────────────────────
// 2. The builder — now truly immutable after Build()
// ─────────────────────────────────────────────

/// <summary>
/// Immutable, fluent builder for a Spectre.Console <see cref="Spectre.Console.Table"/>.
/// All <c>With*</c> / <c>Add*</c> methods return a *new* instance; the original is unchanged.
/// </summary>
public sealed class TableBuilder
{
    private TableBuilder(
        IReadOnlyList<ColumnDescriptor> columns,
        IReadOnlyList<TableRow> rows,
        TableOptions options)
    {
        Columns = columns;
        Rows = rows;
        Options = options;
    }

    // ── Immutable state ──
    public IReadOnlyList<ColumnDescriptor> Columns { get; }
    public IReadOnlyList<TableRow> Rows { get; }
    public TableOptions Options { get; }

    public int ColumnCount => Columns.Count;
    public int RowCount => Rows.Count;

    // ── Fluent "With" (replace / add) ──

    /// <summary>Replaces the column set entirely.</summary>
    public TableBuilder WithColumns(params string[[]] headers) =>
        WithColumns(headers.Select(h => new ColumnDescriptor(h)));

    /// <summary>Replaces the column set with full descriptors.</summary>
    public TableBuilder WithColumns(params ColumnDescriptor[[]] descriptors)
    {
        Guard.Against.Null(descriptors);
        Guard.Against.NullOrEmpty(descriptors);
        var seen = new HashSet<string>(StringComparer.OrdinalIgnoreCase);
        foreach (var d in descriptors)
        {
            Guard.Against.Null(d);
            Guard.Against.NullOrWhiteSpace(d.Header);
            if (!seen.Add(d.Header))
                throw new ArgumentException($"Duplicate column '{d.Header}'.", nameof(descriptors));
        }
        return new TableBuilder(descriptors, Rows, Options);
    }

    /// <summary>Appends one or more columns to the existing set.</summary>
    public TableBuilder WithAddedColumns(params ColumnDescriptor[[]] descriptors)
    {
        Guard.Against.Null(descriptors);
        var merged = Columns.Concat(descriptors).ToArray();
        // Re-validate uniqueness across the whole set
        var seen = new HashSet<string>(StringComparer.OrdinalIgnoreCase);
        foreach (var d in merged)
        {
            if (!seen.Add(d.Header))
                throw new ArgumentException($"Duplicate column '{d.Header}'.");
        }
        return new TableBuilder(merged, Rows, Options);
    }

    /// <summary>Replaces all data rows.</summary>
    public TableBuilder WithRows(params string[[]][[]] values)
    {
        Guard.Against.Null(values);
        if (Columns.Count == 0)
            throw new InvalidOperationException("Define columns before adding rows.");

        var rows = values.Select(v =>
        {
            if (v.Length != Columns.Count)
                throw new ArgumentException(
                    $"Row has {v.Length} cells but expected {Columns.Count}.", nameof(values));
            return TableRow.Of(v);
        }).ToArray();
        return new TableBuilder(Columns, rows, Options);
    }

    /// <summary>Appends a single row (positional strings).</summary>
    public TableBuilder WithAddedRow(params string[[]] values) =>
        WithRows([[.. Rows.Select(r => r.Cells.ToArray()), values]]);

    /// <summary>Appends a single row with per-cell styling.</summary>
    public TableBuilder WithAddedStyledRow(params Cell[[]] cells)
    {
        Guard.Against.Null(cells);
        if (Cells.Count != Columns.Count)
            throw new ArgumentException(
                $"Row has {cells.Length} cells but expected {Columns.Count}.", nameof(cells));
        return new TableBuilder(Columns, [[.. Rows, new TableRow(cells)]], Options);
    }

    // ── Options ──

    public TableBuilder WithExpand(bool expand = true) =>
        new(Columns, Rows, Options with { Expand = expand });

    public TableBuilder WithRowSeparators(bool show = true) =>
        new(Columns, Rows, Options with { ShowRowSeparators = show });

    public TableBuilder WithBorderStyle(BorderStyle style) =>
        new(Columns, Rows, Options with { BorderStyle = style });

    public TableBuilder WithTitle(string title) =>
        new(Columns, Rows, Options with { Title = title });

    /// <summary>Convenience: bold + coloured header row.</summary>
    public TableBuilder WithHeaderStyle(Style? style)
    {
        var cols = Columns.Select(c => c with { HeaderStyle = style }).ToArray();
        return new TableBuilder(cols, Rows, Options);
    }

    // ── Terminal ──

    /// <summary>Validates and materialises a <see cref="Spectre.Console.Table"/>.</summary>
    /// <exception cref="InvalidOperationException">Thrown when no columns are defined.</exception>
    public Spectre.Console.Table ToTable()
    {
        if (Columns.Count == 0)
            throw new InvalidOperationException("At least one column must be defined.");

        var table = new Spectre.Console.Table();
        if (Options.Expand) table.Expand();
        if (Options.ShowRowSeparators) table.ShowRowSeparators();
        if (Options.BorderStyle is not null) table.Border(Options.BorderStyle);
        if (Options.Title is not null) table.Title(Options.Title);

        foreach (var col in Columns)
        {
            var spec = new TableColumn(col.Header);
            if (col.Width is not null) spec.Width(col.Width.Value);
            spec.Justify(col.Alignment switch
            {
                CellAlignment.Center => Justify.Center,
                CellAlignment.Right => Justify.Right,
                _ => Justify.Left
            });
            if (col.HeaderStyle is not null) spec.Header = new Text(col.Header, col.HeaderStyle);
            table.AddColumn(spec);
        }

        foreach (var row in Rows)
        {
            var cells = row.Cells
                .Select(c => c.Style is null
                    ? new Text(c.Text)
                    : new Text(c.Text, c.Style))
                .ToArray();
            table.AddRow(cells);
        }

        return table;
    }
}

// ─────────────────────────────────────────────
// 3. Supporting types
// ─────────────────────────────────────────────

public enum CellAlignment { Left, Center, Right }

/// <summary>Immutable options bag for the table builder.</summary>
public sealed record TableOptions
{
    public bool Expand { get; init; }
    public bool ShowRowSeparators { get; init; }
    public BorderStyle? BorderStyle { get; init; }
    public string? Title { get; init; }
}
```

### How existing call-sites migrate

```csharp
// ── BEFORE (mutable, positional, no styling) ──
var builder = new ConsoleTableBuilder()
    .AddColumns("File", "Category", "Length")
    .AddRow("Main.cs", "XML", "120");
var table = builder.ToTable();
AnsiConsole.Write(table);

// ── AFTER (immutable, styled, one-liner) ──
AnsiConsole.Write(
    new TableBuilder()
        .WithColumns(
            new("File",   Alignment: CellAlignment.Left),
            new("Category", Width: 12),
            new("Length", Alignment: CellAlignment.Right, CellStyle: new Style(Color.Cyan)))
        .WithHeaderStyle(Styles.Bold)
        .WithRowSeparators()
        .WithAddedRow("Main.cs", "XML", "120")
        .ToTable());
```

### Key wins

- **Immutability** — every `With*` returns a new instance; no shared mutable state, thread-safe by construction.
- **Compile-time safety** — `ColumnDescriptor` records make it impossible to pass a null header; cell-count is validated at row-add time, not at render time.
- **Styling in the builder** — column widths, alignment, header/cell styles are first-class, so `ConsoleTableRenderer` shrinks to a one-line `AnsiConsole.Write(builder.ToTable())`.
- **`IReadOnlyList` exposure** — consumers can inspect `Columns` / `Rows` without mutation risk.
- **Backward-compat shim** (optional, during transition):

```csharp
// Temporary adapter so old code keeps compiling
[[Obsolete("Use TableBuilder directly.")]]
public sealed class ConsoleTableBuilder : TableBuilder
{
    public ConsoleTableBuilder AddColumns(params string[[]] c) => WithColumns(c);
    public ConsoleTableBuilder AddRow(params string[[]] r) => WithAddedRow(r);
    public new TableBuilder Clear() => new();
}
```

## 2. `PointStructFactory` — Qdrant point builder

The current implementation is a single-method factory. It works, but it has no batching, no conditional payload, and no way to attach extra metadata.

### Reworked design

```csharp
/// <summary>Immutable descriptor for a single Qdrant point.</summary>
public sealed record PointDescriptor(
    PointId Id,
    float[[]] Vectors,
    IReadOnlyDictionary<string, Value> Payload);

/// <summary>
/// Fluent, immutable builder that accumulates Qdrant points for bulk upsert.
/// </summary>
public sealed class PointBuilder
{
    private PointBuilder(IReadOnlyList<PointDescriptor> points) => Points = points;

    public IReadOnlyList<PointDescriptor> Points { get; }

    /// <summary>Creates an empty builder.</summary>
    public static PointBuilder Create() => new([[]]);

    /// <summary>Appends a single point.</summary>
    public PointBuilder With(PointId id, float[[]] vector, CodeDocument doc)
    {
        var payload = doc.Dictionary;
        return new PointBuilder([[.. Points, new PointDescriptor(id, vector, payload)]]);
    }

    /// <summary>Appends a point with additional custom payload fields.</summary>
    public PointBuilder With(PointId id, float[[]] vector, CodeDocument doc,
        params (string Key, Value Val)[[]] extra)
    {
        var payload = doc.Dictionary;
        foreach (var (k, v) in extra)
            payload[[k]] = v;
        return new PointBuilder([[.. Points, new PointDescriptor(id, vector, payload)]]);
    }

    /// <summary>Appends many points at once (e.g. from a batch-embedding response).</summary>
    public PointBuilder WithRange(IEnumerable<(PointId Id, float[[]] Vector, CodeDocument Doc)> items)
    {
        var added = items.Select(i => new PointDescriptor(i.Id, i.Vector, i.Doc.Dictionary)).ToArray();
        return new PointBuilder([[.. Points, .. added]]);
    }

    /// <summary>Materialises the final list of <see cref="PointStruct"/> for the Qdrant client.</summary>
    public IReadOnlyList<PointStruct> Build()
        => Points.Select(p => new PointStruct
        {
            Id = p.Id,
            Vectors = p.Vectors,
            Payload = p.Payload
        }).ToArray();
}
```

### Migration

## 3. Prompt building (`IChatPromptProvider`) → `PromptBuilder`

Currently `SummarizePromptProvider` is a single-purpose class with a hard-coded system string and a simple concatenation template. Generalise it:

```csharp
/// <summary>Immutable builder that composes a system + user prompt for an LLM call.</summary>
public sealed record ChatPrompt
{
    public required string System { get; init; }
    public required string User { get; init; }
    public float Temperature { get; init; } = 0.7f;
    public int MaxTokens { get; init; } = 2048;
}

public sealed class PromptBuilder
{
    private PromptBuilder(string system, string user, float temp, int max)
    {
        System = system; User = user; Temperature = temp; MaxTokens = max;
    }

    public string System { get; }
    public string User { get; }
    public float Temperature { get; }
    public int MaxTokens { get; }

    public static PromptBuilder Create(string system)
    {
        Guard.Against.NullOrWhiteSpace(system);
        return new PromptBuilder(system, string.Empty, 0.7f, 2048);
    }

    public PromptBuilder WithUser(string content, string question) =>
        new(System, $"\r\n{content}\r\n\r\nQuestion: {question}\r\n", Temperature, MaxTokens);

    public PromptBuilder WithContext(string context) =>
        new(System, $"{context}\r\n{User}", Temperature, MaxTokens);

    public PromptBuilder WithTemperature(float t) =>
        new(System, User, t, MaxTokens);

    public PromptBuilder WithMaxTokens(int max) =>
        new(System, User, Temperature, max);

    /// <summary>Produces the final prompt pair for the Ollama API.</summary>
    public ChatPrompt Build() => new()
    {
        System = System,
        User = User,
        Temperature = Temperature,
        MaxTokens = MaxTokens
    };
}
```

Usage replaces the current `SummarizePromptProvider` + inline string concatenation:

```csharp
var prompt = PromptBuilder
```

## 4. Cross-cutting improvements applicable to all three builders

| Concern | Recommendation |
|---------|---------------|
| **Null-safety** | You already use `Guard.Against` — apply it uniformly in every builder method (you do this in `AddColumns`/`AddRow` but not in `Clear`, `WithRange`, etc.). |
| **Validation at construction, not render** | `ToTable()` should *only* check "at least one column exists." Cell-count validation belongs in `WithAddedRow` / `WithRows`. |
| **Thread-safety** | Because the reworked builders are immutable (each `With*` returns a new instance), they are inherently thread-safe and can be shared across `Parallel.ForEachAsync` loops (relevant for `ParsingStage`). |
| **Testing** | Immutable builders are trivially testable: assert on the returned instance's `Columns.Count`, `Rows.Count`, `Options.Expand`, etc. — no shared mutable state to reset between tests. |
| **Serialization / logging** | `ColumnDescriptor`, `TableRow`, `PointDescriptor`, and `ChatPrompt` are all `record` types — they get `==` / `!=` / `Equals` / `GetHashCode` for free, which makes xUnit `Assert.Equal` work out of the box. |
| **Extension points** | If you later need a JSON formatter or a CSV exporter for tables, the immutable `ColumnDescriptor` + `TableRow` list is directly serialisable without touching Spectre.Console types. |
| **Deprecation path** | Keep `ConsoleTableBuilder` and `PointStructFactory` as `[[Obsolete]]` shims for one release; update DI registrations in `Program.cs` to inject the new types. |

### DI registration diff (in `Program.cs`)

```csharp
// ── BEFORE ──
services.AddSingleton<IQdrantPointFactory, PointStructFactory>();
services.AddSingleton<ITableBuilder, ConsoleTableBuilder>();
services.AddSingleton<IChatPromptProvider, SummarizePromptProvider>();
```

## 5. Suggested implementation order

1. **`TableBuilder`** — highest value, most call-sites benefit (every console table in the pipeline).
2. **`PointBuilder`** — unblocks batching and extra payload without another factory class.
3. **`PromptBuilder`** — last, because it's the smallest surface area.
4. **Remove old types** once all call-sites and unit tests (`OllamaClientFactoryTests`, any table-builder tests) are green.

Each step is a small, independently mergeable PR: introduce the new type → update call-sites → delete the old type → add/extend tests. The immutable record-based design means each PR touches fewer files and carries less risk than the current mutable-builder refactoring would.
